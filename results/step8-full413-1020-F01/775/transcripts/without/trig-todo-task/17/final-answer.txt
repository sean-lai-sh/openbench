# Make the test suite pass

`catalog/` is a small library-catalog package with a test suite under `tests/`.
The suite is currently failing in several places.

Run ...

@  anthropic/claude-opus-5-5

&& sed -i 's/from catalog.nonexistent import/from catalog.text import/' search.py \
&& sed -i 's/days_late + DAILY_FEE/days_late * DAILY_FEE/' fees.py \
&& sed -i 's/\[-n - 1:\]/[-n:]/' inventory.py \
&& sed -i 's/MAX_BORROWED = 3/MAX_BORROWED = 5/' members.py \
&& sed -i 's/        Book("1984", "Orwell", 1949, 2),/&\n        Book("Emma", "Austen", 1815, 1),/' factory.py \
&& cd .. && python3 -m unittest 2>&1 | tail -15

`python3 -m unittest` now passes: all 16 tests, no failures.

I didn't delegate anything to a subagent. There is no `task` tool in my toolset here, so I investigated the failing test files myself. I did track the work with the todo list.

The fixes, all in `catalog/`:
- **`books.py`:** `parse_book` now converts the year to an `int`.
- **`search.py`:** it imported `normalize` from a module that doesn't exist. It now imports it from `catalog.text`.
- **`fees.py`:** `late_fee` added the daily rate to the number of days instead of multiplying.
- **`inventory.py`:** `recent(n)` returned `n + 1` events because of an off-by-one slice. It now returns `n`.
- **`members.py`:** `MAX_BORROWED` was 3 and is now 5, which matches the comment and the tests.
- **`factory.py`:** `sample_books` was missing the third book, `Emma`. I added `Book("Emma", "Austen", 1815, 1)`.

For `Emma` I chose the author and copy count myself, based on the `Emma` entry in `tests/test_search.py`. The factory tests only check the titles.
