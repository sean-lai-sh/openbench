All 16 tests now pass. The fixes were:
- `search.py`: the import pointed at `catalog.nonexistent`, so I changed it to `catalog.text`.
- `members.py`: `MAX_BORROWED` was 3 and is now 5, matching the comment on line 3 and the tests.
- `fees.py`: the fee used `days_late + DAILY_FEE`, which I changed to multiply.
- `inventory.py`: `recent` sliced `[-n - 1:]`, which returned one event too many, so it is now `[-n:]`.
- `books.py`: `parse_book` left the year as a string, so it now converts it to an int.
- `factory.py`: `sample_books` was missing a third book, so I added `Book("Emma", "Austen", 1815, 1)`. The author, year and copy count are my own picks, since the tests only check the title
