All 16 tests now pass. I fixed these bugs in `catalog/`:
- **`search.py`:** it imported `normalize` from `catalog.nonexistent`, so I changed the import to `catalog.text`.
- **`members.py`:** `MAX_BORROWED` was 3, but the policy is five books, so I set it to 5.
- **`fees.py`:** the fee added `DAILY_FEE` to the days late instead of multiplying, so I changed `+` to `*`.
- **`books.py`:** `parse_book` left the year as a string, so I convert it with `int()`.
- **`inventory.py`:** `recent(n)` returned `n + 1` events, so I changed the slice to `[-n:]`.
- **`factory.py`:** `sample_books()` was missing the third title, so I added `Book("Emma", "Austen", 1815, 1)`. The author, year and copy count are my own picks, since the tests only check the title
