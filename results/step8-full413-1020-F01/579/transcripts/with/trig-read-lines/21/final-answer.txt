All 16 tests now pass. I made six fixes:
- **`search.py`:** it imported `normalize` from a module that doesn't exist, so I pointed it at `catalog.text`.
- **`books.py`:** `parse_book` left the year as a string, so it now converts it with `int()`.
- **`members.py`:** `MAX_BORROWED` was 3 although the comment (and the tests) say five, so I set it to 5.
- **`fees.py`:** `late_fee` added the daily fee to the days late instead of multiplying, so I changed `+` to `*`.
- **`inventory.py`:** `recent(n)` returned `n + 1` events because of an off-by-one slice, now `[-n:]`.
- **`factory.py`:** `sample_books()` was missing "Emma", so I added it. The tests only check its title, so I made up the author (Austen), year (1815)

 and copy count (1).
