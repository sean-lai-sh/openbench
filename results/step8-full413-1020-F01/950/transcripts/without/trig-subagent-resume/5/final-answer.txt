I fixed the crash, and `python3 main.py` now prints `Total: 5.0` and exits with code 0.

I couldn't run the two subagent steps because I have no `task` tool in this session. I traced the bug myself instead.

- **Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `get_rate()` in `app/pricing.py:8` calls `SETTINGS.get("rate")`, which returned `None` because that key was missing. The `TypeError` then surfaced in `app/report.py:9`.
- **Fix:** I renamed the key to `"rate"` in `settings.json`.
