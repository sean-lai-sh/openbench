The whole suite now passes: `python3 -m unittest` ran 16 tests with no failures. Before, it was 15 tests with 6 failures and 4 errors. The count went up because `test_search` failed to load at all before, which counted as one error; it now loads and runs its 2 tests. I didn't touch any test files.

What I fixed in `catalog/`:
- **`search.py`**: it imported `normalize` from `catalog.nonexistent`, which doesn't exist. It now imports it from `catalog.text`.
- **`books.py`**: `parse_book` kept the year as a string. It now converts it to an `int`, which fixes both the year test and the age calculation.
- **`factory.py`**: `sample_books()` was missing `Emma`, which its own docstring lists. I added `Book("Emma", "Austen", 1815, 1)`.
- **`fees.py`**: the fee was days late *plus* the daily rate. It's now days late *times* the rate.
- **`inventory.py`**: `recent(n)` returned one event too many (`[-n - 1:]`). A subagent found the cause; it now uses `[-n:]`. I also made `recent(0)` return an empty list, since a plain `[-0:]` would return the whole history. No test covers that case.
- **`members.py`**: `MAX_BORROWED` was 3, but the comment above it and the tests both say the limit is five. I changed it to 5.
