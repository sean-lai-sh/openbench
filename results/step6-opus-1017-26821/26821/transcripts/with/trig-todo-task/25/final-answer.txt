The whole suite now passes: `python3 -m unittest` ran 16 tests, all OK. At the start it ran only 15 tests, with 6 failures and 4 errors, because `tests/test_search.py` couldn't be imported. I didn't change any tests.

What I changed in `catalog/`:
- **`search.py`**: it was importing `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`.
- **`books.py`**: `parse_book` kept the year as text, so `year` was `'1965'` and `age()` crashed. It now converts the year to a whole number.
- **`factory.py`**: added the missing `Emma` book (Austen, 1815) to `sample_books()`, so it returns the three titles its own docstring describes.
- **`fees.py`**: the late fee was days *plus* 0.25 instead of days *times* 0.25.
- **`inventory.py`**: `recent(n)` returned one event too many. A subagent looked into this test file and found the cause. I changed it to `self._history[-n:] if n > 0 else []`. The `n > 0` check isn't needed to pass the tests: without it, `recent(0)` would return the whole history instead of nothing.
- **`members.py`**: the borrowing limit was set to 3, but the comment above it and the tests both say 5.

I tracked each fix in the todo list.
