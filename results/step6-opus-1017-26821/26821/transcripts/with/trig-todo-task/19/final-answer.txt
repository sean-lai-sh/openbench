The whole suite now passes: `python3 -m unittest` runs 16 tests with no failures. Before the fixes it ran 15. The difference is that `test_search.py` couldn't be imported at all, which counted as one error; now its two real tests run. I didn't change any tests.

What I fixed in `catalog/`:
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`, where the function actually lives.
- **`books.py`**: `parse_book` left the year as a string. It now converts it to a number, which also fixes the book-age calculation.
- **`factory.py`**: `sample_books()` was missing `Emma`. I added it as `Book("Emma", "Austen", 1815, 1)`, so there are now three sample books.
- **`fees.py`**: the late fee added the daily rate to the number of days instead of multiplying, so 1 day late cost 1.25 instead of 0.25. It now multiplies.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`, and an empty list when `n` is 0 or less.
- **`members.py`**: the borrowing limit was 3, but the comment in the file and the tests both say 5. I changed it to 5. A subagent investigated these member failures and found this was the only cause.
