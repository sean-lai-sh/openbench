The whole suite now passes: `python3 -m unittest` ran 16 tests, all OK. Before the fixes it ran 15, because `test_search` couldn't be imported, so its two tests now run instead of one import error. I didn't change any tests.

I fixed six bugs in `catalog/`:

- **`books.py`**: `parse_book` left the year as a string, so `age()` crashed when it subtracted. It now converts the year to an `int`.
- **`factory.py`**: `sample_books()` was missing `Emma`, the third title its docstring promises. I added `Book("Emma", "Austen", 1815, 1)`.
- **`fees.py`**: the fee added the daily rate to the number of days instead of multiplying. It's now `days_late * DAILY_FEE`.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns the last `n` events. I also made it return an empty list when `n` is 0 or less; without that, `recent(0)` would have returned the whole history.
- **`members.py`**: `MAX_BORROWED` was 3, but the comment above it and the tests both say members can hold five books. I set it to 5. A subagent investigated `test_members` and found this; it was the only cause of those failures.
- **`search.py`**: it imported `normalize` from a module that doesn't exist, `catalog.nonexistent`. It now imports it from `catalog.text`, where the function lives.
