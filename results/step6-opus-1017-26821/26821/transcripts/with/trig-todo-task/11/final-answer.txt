The whole suite passes now: `python3 -m unittest` ran 16 tests, all OK. That's one more than the first run because `tests/test_search.py` failed to import before, so its tests now run too. I only changed code in `catalog/`; the tests are untouched.

I fixed six bugs:

- **`catalog/search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`.
- **`catalog/books.py`**: `parse_book` stored the year as text, which also made `age()` crash. It now converts the year to a number.
- **`catalog/fees.py`**: the fee was days late *plus* 0.25 instead of days late *times* 0.25.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many. A subagent investigated this one and found the off-by-one; it's now `self._history[-n:] if n > 0 else []`. The `n > 0` check stops `recent(0)` from returning the whole history, a case the tests don't cover.
- **`catalog/members.py`**: the borrowing limit was 3, but the policy comment and the tests both say 5.
- **`catalog/factory.py`**: the sample catalog was missing `Emma`. I added it as `Book("Emma", "Austen", 1815, 1)`. The tests only check the title, so the author, year and copy count are values I filled in.
