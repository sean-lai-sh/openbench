Fixes in `catalog/`:
- **`search.py`**: it imported `normalize` from a module that doesn't exist, `catalog.nonexistent`. It now imports it from `catalog.text`.
- **`books.py`**: `parse_book` kept the year as a string, so `b.year` and `age()` failed. The year is now converted with `int()`.
- **`factory.py`**: `sample_books()` was missing the third book its docstring describes. I added `Book("Emma", "Austen", 1815, 1)`.
- **`fees.py`**: the fee was calculated as days plus the daily rate. It's now days times the daily rate (`days_late * DAILY_FEE`).
- **`inventory.py`**: `recent(n)` sliced `[-n - 1:]`, which returned one event too many. It's now `[-n:]`. I also made `recent(0)` return an empty list, because `[-0:]` would return the whole history; no test calls it with 0.
- **`members.py`**: `MAX_BORROWED` was 3, but the policy comment and the tests say a member can hold 5 books. It's now 5.
