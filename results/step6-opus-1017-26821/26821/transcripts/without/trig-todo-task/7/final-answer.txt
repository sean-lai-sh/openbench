All 16 tests now pass with `python3 -m unittest`, and I didn't change any test files. Before the fixes the run showed 15 tests; it's 16 now because `tests/test_search.py` failed to import before, so its tests weren't being counted properly.

What I fixed in `catalog/`:
- **`search.py`**: it imported from a module that doesn't exist (`catalog.nonexistent`). It now imports `normalize` from `catalog.text`, where that function actually lives.
- **`books.py`**: `parse_book` now turns the year into a number with `int(year)` instead of leaving it as text.
- **`factory.py`**: added the missing third sample book, `Book("Emma", "Austen", 1815, 1)`.
- **`fees.py`**: the late fee is now days late × the daily fee. Before, it added the two together.
- **`inventory.py`**: `recent(n)` returned one event too many; it now returns exactly the last `n`. I also made `recent(0)` or a negative number return an empty list, because the plain slice would have returned the whole history in that case. No test covers that.
- **`members.py`**: `MAX_BORROWED` changed from 3 to 5, matching the five-book policy in the comment and the tests. A subagent investigated `tests/test_members.py` and found this cause.
