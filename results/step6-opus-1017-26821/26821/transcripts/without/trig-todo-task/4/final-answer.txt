Fixes:
- **`catalog/search.py`**: it imported `normalize` from a module that doesn't exist, `catalog.nonexistent`. It now imports from `catalog.text`.

- **`catalog/factory.py`**: `sample_books()` was missing `Emma`, which its own docstring lists. I added `Book("Emma", "Austen", 1815, 1)`. The tests only check the title, so I chose the author, year and copy count.
- **`catalog/fees.py`**: the fee added the daily rate to the number of days instead of multiplying, so it's now `days_late * DAILY_FEE`.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many. It now returns the last `n`, and an empty list when `n <= 0`.
- **`catalog/members.py`** (subagent's finding): `MAX_BORROWED` was 3, but the comment and the tests say a member can hold 5 books. I changed it to 5.
