The whole suite now passes: `python3 -m unittest` ran 16 tests, all OK. The count went up from 15 because `tests/test_search.py` previously couldn't even load and was counted as a single error; now its 2 tests run. I didn't change any tests.

I gave the `test_search.py` failure to a subagent to investigate. It also checked the other modules, and its findings matched my own reading of the code. There were six bugs, each fixed in `catalog/`:

- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`.
- **`members.py`**: the borrow limit `MAX_BORROWED` was set to 3, but the policy comment and the tests say 5. Changed to 5.
- **`fees.py`**: the fee was days late *plus* 0.25 instead of days late *times* 0.25. Fixed to multiply.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`. I also made it return an empty list when `n` is 0 or less, because the slice would otherwise return the whole history.
- **`books.py`**: `parse_book` stored the year as text, which also broke `age()`. It now stores it as a whole number.
- **`factory.py`**: `sample_books()` was missing the third book. I added `Book("Emma", "Austen", 1815, 1)`. The tests only check the title "Emma", so I took the author, year and copies from the matching book in `test_search.py`.
