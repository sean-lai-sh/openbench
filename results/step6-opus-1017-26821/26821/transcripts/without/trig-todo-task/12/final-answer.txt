What was wrong and how I fixed it:
- **`catalog/search.py`**: it imported `normalize` from `catalog.nonexistent`, which doesn't exist. It now imports from `catalog.text`, where `normalize` is defined.
- **`catalog/books.py`**: `parse_book` left the year as a string. It now converts it with `int(year)`.
- **`catalog/factory.py`**: `sample_books()` only had two books, though its docstring says three. I added `Book("Emma", "Austen", 1815, 1)`.
- **`catalog/fees.py`**: the fee added the daily rate to the days late instead of multiplying. It's now `days_late * DAILY_FEE`.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many (`[-n - 1:]`). It's now `[-n:]`, and returns an empty list when `n` is 0 or less.
- **`catalog/members.py`**: `MAX_BORROWED` was 3, but the code comment and the tests both say members can hold five books. I set it to 5.

Two values I chose myself because the tests don't check them: Emma's author, year and copy count, and what `recent()` returns for `n <= 0`.
