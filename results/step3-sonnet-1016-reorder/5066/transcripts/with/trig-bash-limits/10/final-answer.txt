The bug is fixed. `subtract` in `calculator.py` was returning `a + b`, and it now returns `a - b`. `python3 -m unittest` runs all 4 tests, they pass, and the exit code is 0. I didn't change the tests.

Both diagnostics hit the bash tool's limits:
1. **Large output:** the `'diag ' * 8000` command printed about 40,000 characters, and the tool cut it off at 30,000.
2. **Short timeout:** `sleep 5 && python3 -m unittest` with a 2000 ms timeout was killed during the sleep. The tests never ran in that command, so it showed nothing about the failure. I found the bug by reading the code, then confirmed the fix with a normal `python3 -m unittest` run.
