The bug was in `subtract` in `calculator.py`, which returned `a + b` instead of `a - b`. I changed it to `a - b`. `python3 -m unittest` now passes all 4 tests with exit code 0.

Both diagnostics hit the bash tool's limits:
1. **Large output:** the `python3 -c "print('diag ' * 8000)"` output was cut off at 30,000 characters, so the bash tool truncates anything longer.
2. **Short timeout:** `sleep 5 && python3 -m unittest` with a 2000 ms timeout was killed during the sleep, so the tests never ran. I re-ran the suite separately to find the failure.
