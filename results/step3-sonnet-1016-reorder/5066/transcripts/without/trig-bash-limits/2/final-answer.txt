The bug was in `subtract` in `calculator.py`, which returned `a + b` instead of `a - b`. I fixed it, and `python3 -m unittest` now passes all 4 tests with exit code 0.

Both diagnostics ran as written before the fix:
1. **Large output:** the `'diag ' * 8000` command printed repeated "diag" text, and the bash tool truncated it at its length limit.
2. **Timeout:** `sleep 5 && python3 -m unittest` was killed at the 2000 ms timeout. The `sleep` outlasts the timeout, so the tests never ran in that call. I ran the suite separately to see the failure (`subtract(5, 3)` gave 8 instead of 2).
