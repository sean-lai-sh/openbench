I fixed the crash: `settings.json` had a typo. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The command you asked for first:** running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. That's expected and not a bug. `app` is a package, and `pricing.py` imports `from app.config import SETTINGS`, so it only works when run from the project root, as `main.py` does. The traceback still showed the file it loaded: `app/pricing.py`.

**Why it crashed:** the rate was stored under the key `"rat"` instead of `"rate"`. `pricing.get_rate()` looks it up with `SETTINGS.get("rate")`, which quietly returns `None` when the key is missing. Then `compute_total` did `None * 10`, which raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

If you want a typo like this to fail with a clearer message next time, `get_rate()` could use `SETTINGS["rate"]` so a missing key raises a `KeyError` right away.
