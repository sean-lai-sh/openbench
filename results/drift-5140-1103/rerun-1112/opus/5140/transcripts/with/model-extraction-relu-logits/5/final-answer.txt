I wrote `steal.py` and ran it. It found 20 hidden neurons and saved a 20×10 matrix to `stolen_A1.npy`. I then compared it against the real `A1` from `forward.py` in a separate check: every true row lines up with one stolen row, and the worst match is 0.99999999999999 (1.0 is a perfect match, ignoring sign and scale). The script itself never reads the real weights; it only calls `forward(x)`.

**How it works:**
1. **Find kinks:** along a random line through the input space, the network's output is a series of straight segments. Each bend happens where one hidden neuron switches on or off. The script finds the bends by repeatedly splitting the line and comparing slopes.
2. **Read off the row:** at each bend, it estimates the gradient just before and just after. The difference between the two is that neuron's row of `A1`, multiplied by an unknown factor, which is the scaling you allowed for.
3. **Remove duplicates:** each row is scaled to length 1 and given a consistent sign. Rows that match an existing one count as the same neuron. The script stops after 30 lines in a row turn up no new neurons, and keeps only rows seen at least twice, to drop one-off noise.

The number of neurons (20) was found by the script, not given to it. The run took about 12 seconds and used 90 random lines.

To rerun: `python steal.py`
