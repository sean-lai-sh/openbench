I wrote `pipeline_parallel.py`, which contains `train_step_pipeline_afab`. I tested it on a small 5-layer LLaMA with world sizes 1 and 2, and it matched a reference model exactly: same loss (4.8675) and every gradient identical, with a maximum difference of 0. That test ran on CPU only, in float32 and using the gloo backend; I haven't tried it on GPU or with other dtypes. I compared final gradients, not activations through hooks the way your test will.

**How it works:**
- **Splitting the layers:** decoder layers are divided as evenly as possible, and any extra layers go to the earlier ranks. With 5 layers on 2 ranks, rank 0 runs 3 and rank 1 runs 2. Rank 0 also runs the embedding, and the last rank runs the final norm and output head.
- **Forward pass, all microbatches first:**
  - Rank 0 embeds the input IDs.
  - Every other rank receives hidden states of shape `[microbatch, seq_len, hidden_size]` from the previous rank and marks them as needing gradients.
  - Each rank runs only its own layers, then sends its output to the next rank with `P2POp` / `batch_isend_irecv`.
  - The last rank computes the cross-entropy loss and divides it by the number of microbatches.
- **Backward pass, after all forwards:** the last rank backpropagates each microbatch's loss. Other ranks receive the gradient from the next rank, backpropagate through their own output, and send the gradient of their input back to the previous rank.
- **Device and dtype:** inputs, hidden states and gradients are always moved to the given device and dtype. No hooks are used.

**Things that might differ from what your test expects:**
- **Return value:** the last rank returns the summed, scaled loss and the other ranks return `None`. Your spec didn't ask for a return value.
- **Shapes on other ranks:** ranks after rank 0 get the microbatch size and sequence length from `inputs[i].shape`, so every rank needs to be passed the inputs list.
- **Loss:** it's calculated against `targets` exactly as given, without shifting tokens.
- **Model structure:** the model isn't modified. Each rank just skips the layers it doesn't own.
- **Attention mask:** it's built the same way the installed transformers version (5.22.2) builds it. I added fallbacks for older versions, but those weren't tested.
