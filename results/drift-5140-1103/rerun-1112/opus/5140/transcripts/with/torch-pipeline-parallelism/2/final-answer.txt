I created `pipeline_parallel.py` with `train_step_pipeline_afab`. I ran it against a reference model on CPU (gloo backend) with world_size 1 and 2, and it matched exactly: the loss was the same, and every parameter gradient differed by 0. The test used a 5-layer model and float32 only; I haven't run it in bf16 or any other dtype.

**How it works:**
- **Layer split:** the decoder layers are divided into contiguous blocks of nearly equal size, with earlier ranks taking the extra layers. Rank 0 also runs the embedding, and the last rank also runs the final norm and `lm_head`. The model itself isn't modified; each rank just runs only its own layers. With 5 layers and 2 ranks, rank 0 runs 3 layers and rank 1 runs 2.
- **Forward pass (all microbatches first):**
  - Rank 0 embeds the input IDs. The other ranks receive hidden states shaped `[mb, seq, hidden]` from the previous rank and set them to require gradients.
  - Each rank builds the position IDs, causal mask and rotary embeddings the same way `LlamaModel` does, then calls each decoder layer directly.
  - On the last rank, the loss is cross-entropy between the logits and the targets, divided by the number of microbatches. Every other rank sends its output to the next rank.
- **Backward pass (all microbatches after):**
  - The last rank calls `loss.backward()`.
  - The other ranks receive the gradient from the next rank and run backward on their stored outputs with it.
  - Every rank except rank 0 sends its input's gradient back to the previous rank.
- **Communication:** every send and receive uses `dist.P2POp` with `dist.batch_isend_irecv`. Inputs, hidden states and gradients are always moved to the given `device` and `dtype`, and the code uses no hooks.

**Decisions you may want to check:**
- **Return value:** the function returns the total scaled loss on the last rank and `None` on other ranks. The spec didn't say what to return.
- **Targets aren't shifted:** the loss compares logits with the targets as given, so this assumes the test passes targets that are already shifted.
