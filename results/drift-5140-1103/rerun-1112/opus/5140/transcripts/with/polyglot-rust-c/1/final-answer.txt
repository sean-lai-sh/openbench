**How it works:** Rust lets block comments nest, and C++ doesn't. The file uses that difference to show each compiler only its own code:

```
/* /* */          <- C++: a complete comment.  Rust: still one level deep in a comment
...C++ code...    <- Rust skips all of this
#if 0
// */            <- Rust: comment ends.  C++: just a line comment, still inside #if 0
...Rust code...   <- C++ skips all of this
/* /* */          <- C++: a complete comment.  Rust: opens a comment again
#endif
// */            <- Rust: comment ends.  C++: a line comment
```

Both versions do the maths in base 10⁹ chunks, so they don't overflow on large N; F(200), for example, prints all 42 digits. If you don't pass N, both default to 0.
