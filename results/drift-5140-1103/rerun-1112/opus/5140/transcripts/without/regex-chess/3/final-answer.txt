I've written `re.json`: 3,917 regex/replacement pairs, about 600 KB, so well under both limits. It passed every test I ran against python-chess:

- **Your example:** it produces exactly the 3 positions you listed.
- **`check.py` (Morphy's Opera Game):** all 18 positions pass. I ran it on a copy with the path changed from `/app/re.json` to the local file.
- **Random games:** 1,900 white-to-move positions match python-chess exactly.
- **Hand-picked hard cases:** 21 positions pass, including standard tricky positions (Kiwipete and others), castling with an attacked middle square, the starting square, or a blocked path, en-passant that leaves your own king exposed, and promotions with and without captures.

**One case it can't handle:** if white has no legal moves (checkmate or stalemate), python-chess expects an empty list, but `"".split("\n")` always returns at least one item. No regex output can fix that. None of the `check.py` positions hit it.

**Speed:** about 75 ms per position.

**How it works:**
1. It drops the move counters and expands the board into a fixed 64-character string, one character per square.
2. For every piece, start square and destination, one regex checks that the move is possible (the piece is there, the path is clear, the target is empty or a black piece). If it is, it adds a new line with the move made. Pawn pushes, double pushes (which set the en-passant square), captures, en-passant and queen promotion each get their own patterns. Each new line also records which castling rights the move removes.
3. Castling puts temporary marker kings on the king's start square and the square it passes over. That way the next step's check test also rules out castling out of or through check.
4. For each of the 64 king squares, one regex deletes any new line where the white king (or a marker) is attacked by a black piece. Black sliding pieces must have a clear path.
5. Cleanup turns the markers back into an empty square and a rook, removes the castling rights each move lost, deletes the original line, rebuilds the FEN text and adds ` 0 0` for the move counters.
