I wrote `steal.py`. Running it saves a 20×10 matrix to `stolen_A1.npy`, and that matrix matches the real `A1` up to permuting and scaling the neurons.

**How it works.** `steal.py` only calls `forward(x)`; it never reads the weights.
1. **Finding the bends.** Along a straight line through the input space, the network's output is made of straight pieces. It bends wherever one hidden neuron's input `A1_i·x + b1_i` crosses zero. The script draws random lines and keeps halving each segment until it finds where the slope changes. It pins down each bend exactly by intersecting the straight pieces on either side.
2. **Reading off a row.** At each bend it estimates the gradient just before and just after, using small finite differences in all 10 input directions. The difference between the two gradients is `A2_i · A1_i`, which is row `i` of `A1` times a constant.
3. **Collecting the rows.** It scales each recovered row to unit length and fixes its sign, then merges rows that point the same way. It stops after 30 lines in a row turn up no new neuron. That gave 20 neurons from 31 lines in about 2.5 seconds.

**Check.** Separately from `steal.py`, I compared the result against the real `A1` in `forward.py`. All 20 recovered rows match all 20 real rows, with a cosine similarity of 0.99999999999998 or better for every pair. The script never needed to know the hidden width in advance.

Each row is scaled to unit length, with its largest entry made positive.
