**How it works:** Rust lets `/* ... */` comments nest inside each other, and C++ doesn't.
- **First marker, `/* /* */`:** C++ sees a complete comment and compiles the C++ code after it. Rust sees an unfinished nested comment, so it skips that code.
- **After the C++ code:** a `#if 0` line followed by `// */`. To C++, the `// */` is just a line comment. To Rust, its `*/` closes the open comment, so Rust compiles the Rust code that follows. C++ skips that Rust code because it's inside `#if 0`.
- **At the end:** `/* /* */ #endif` followed by `// */`. C++ treats the comment as a space, so it sees `#endif`. Rust sees another unfinished comment that the final `*/` closes.
