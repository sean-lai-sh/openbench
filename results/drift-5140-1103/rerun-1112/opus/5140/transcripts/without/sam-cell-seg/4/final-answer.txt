I wrote `convert_masks.py`, and on the demo files every mask comes out as a polyline, with no overlaps and one contiguous region per cell. It runs on CPU in about 25 seconds for the 48 masks in the demo.

**How to run it.** The four arguments work either in order or as flags:
```
python convert_masks.py WEIGHTS OUTPUT RGB CSV
python convert_masks.py --weights_path W --output_path O --rgb_path R --csv_path C
```
- If `output_path` is a folder, the result is saved there under the input CSV's file name (e.g. `OUTPUT/demo_metadata.csv`).
- If `output_path` ends in `.csv`, it's written to exactly that file.

**What it does:**
1. Loads MobileSAM from the weights path and computes the image's features once.
2. Gives MobileSAM the bounding <USER> of every row (rectangles and polylines alike) as the prompt and gets three candidate masks per cell.
3. Picks one candidate per cell:
   - **Polylines:** the candidate that best matches the original outline, weighted by MobileSAM's own confidence score.
   - **Rectangles:** the candidate MobileSAM is most confident in, with a penalty for masks that are tiny or just fill the <USER>.
   - Each mask is also limited to a slightly enlarged version of its <USER> so it can't spread into other cells.
4. Cleans each mask: smooths the edge, keeps the largest connected piece and fills any holes.
5. Removes overlaps: a pixel claimed by more than one cell goes to the cell whose model output there is strongest. A final pass draws every outline as a filled shape and confirms no two overlap.
6. Saves each outline as a closed polyline in the same `"x1,x2,…"` format as your input, and updates `xmin/xmax/ymin/ymax` to match it.

If MobileSAM returns an empty mask for a cell, the script falls back to the original polyline, or to an ellipse inside the <USER>, so no cell is dropped. It doesn't change the MobileSAM source.

**Demo results**, checked by drawing every output outline on the image:
- 0 of 48 outlines are rectangles.
- 0 overlapping pixels.
- Every cell is a single connected region.
- The bounding <USER> columns match the new outlines.
- All other columns are identical to the input.
- For the 29 cells that already had polylines, the refined outline overlaps the original by 78% on average (IoU; lowest 64%).

Looking at the outlines drawn on the slide, they follow the nuclei well, including the cells that were rectangles.
