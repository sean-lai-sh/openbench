I wrote `pipeline_parallel.py` with `train_step_pipeline_afab`. I tested it on a small 5-layer LLaMA (CPU, gloo) at world_size 1 and 2. In both cases the loss and every parameter gradient matched a normal single-model forward and backward exactly (max difference 0). That throwaway test script has been deleted; the official test hasn't been run.

**How it works:**
- **Splitting the layers:** `_partition_layers` divides the decoder layers as evenly as possible, and any leftover layers go to the lower ranks. Rank 0 also runs the token embedding. The last rank also runs the final norm, `lm_head` and the loss. In the test, rank 0 got 3 of the 5 layers and rank 1 got 2.
- **Each stage's forward pass:** it does the same work as `LlamaModel.forward`, but only for this rank's layers. That covers position ids, the causal mask (`create_causal_mask`) and the rotary embeddings. No hooks are used, and the model itself is not changed.
- **Forward phase:** all microbatches go through first.
  - Rank 0 moves the input IDs to the device.
  - Other ranks receive hidden states shaped `[mb, seq, hidden]` from the previous rank, in the given device/dtype, and mark them as needing gradients.
  - The last rank computes `cross_entropy / num_microbatches` against the targets.
  - Every other rank sends its output on to the next rank.
- **Backward phase:** then all microbatches go back.
  - The last rank calls `loss.backward()`.
  - Other ranks receive the gradient from the next rank and run `torch.autograd.backward(out, grad)`.
  - Every rank except rank 0 then sends the gradient of its received input back to the previous rank.
- **Communication:** sends and receives use `dist.P2POp` through `dist.batch_isend_irecv`. With world_size 1 there is no communication at all.

**Things to know:**
- **Return value:** the function returns the summed, scaled loss on the last rank and `None` on the others. Your spec didn't say what to return, so check that this is what your test expects.
- **No optimizer step:** the function only computes gradients. Calling the optimizer step and zeroing gradients is left to the caller.
- **Inputs on every rank:** each rank reads `inputs[i].shape` to size its receive buffers, so the input list needs to be passed on every rank, not just rank 0.
