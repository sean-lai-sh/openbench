I've written `train_step_pipeline_afab` in `pipeline_parallel.py`. With 1 and 2 ranks, it gives the same loss and parameter gradients as a reference model run without pipelining.

**How it works:**
- **Splitting the layers:** decoder layers are divided as evenly as possible, and any extra layers go to the earliest ranks. Rank 0 also runs the token embedding. The last rank also runs the final norm, the output projection (`lm_head`) and the loss. Each rank runs only its own layers; the model itself isn't changed.
- **Forward pass, all microbatches first:**
  - Rank 0 embeds the input IDs.
  - Every other rank receives hidden states of shape `[microbatch, seq_len, hidden_size]` from the previous rank and marks them as needing gradients.
  - Each rank runs its layers with the same position IDs, rotary embeddings and causal mask that the full model would use, then sends the result to the next rank.
  - On the last rank, the loss is cross-entropy against the targets divided by the number of microbatches.
- **Backward pass, all microbatches second:**
  - The last rank calls `backward()` on each microbatch's loss.
  - Other ranks receive the gradient from the next rank and backpropagate it through their saved outputs.
  - Every rank except rank 0 sends the gradient of its input back to the previous rank.
- **Communication** uses `dist.P2POp` with `batch_isend_irecv`. All tensors sent between stages are moved to the given `device` and `dtype`, and there are no hooks in the implementation.
- **Return value:** the summed loss on the last rank and `None` on other ranks.

**Test:** a 5-layer model, 3 microbatches, CPU with the `gloo` backend. I used `torchrun` and removed the test script afterwards.
- **1 rank:** all 5 layers ran once per microbatch.
- **2 ranks:** rank 0 ran layers 0–2 and rank 1 ran layers 3–4.
- In both cases the loss matched the reference (4.8675) and the largest gradient difference was 0.

If the model shares weights between the embedding and the output projection, those two layers sit on different ranks under pipelining, so each rank holds only part of that weight's gradient. My test model didn't share them, so this case wasn't exercised.
