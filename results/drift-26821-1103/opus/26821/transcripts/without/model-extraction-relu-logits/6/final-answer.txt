I wrote `steal.py` and ran it. It recovered all 20 hidden neurons of A1 and saved them to `stolen_A1.npy` as a 20×10 matrix.

**How it works:** The script only calls `forward(x)`.
- Along any straight line through input space, the network's output is made of straight pieces. Each bend is a point where one hidden neuron turns on or off.
- The script picks random lines and finds the bends by repeatedly splitting the line, then pins each bend down exactly by intersecting the straight pieces on either side.
- At each bend, it estimates the gradient just before and just after, using finite differences. The difference between the two equals `A2[i] * A1[i,:]`, which is one row of A1 times a scale factor.
- Each row is scaled to unit length with a fixed sign, and repeats are merged. It stops once 30 lines in a row turn up no new neurons.

**Check:** It runs in about 0.5 seconds. For the check only, I compared the result against the real `forward.A1`. Every recovered row matches exactly one true row, and every true row is matched, with cosine similarity of 0.9999999999999 or better. So the result equals A1 up to reordering and scaling the rows.

One thing to know: the script drops any direction it saw only once if others were seen more than once, to filter noise. On a different network, a real neuron that shows up only once could be dropped by mistake. That didn't happen here.
