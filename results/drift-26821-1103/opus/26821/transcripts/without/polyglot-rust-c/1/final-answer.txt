**How it works:**
- **Rust's view:** Rust allows block comments inside block comments; C++ doesn't. The first line `/* /* */` leaves Rust inside a comment, so it skips all the C++ code. The line `/* */ // */` closes that comment. Rust then treats `//\` as an ordinary line comment, and the next line is Rust's `fn main`.
- **C++'s view:** C++ ends the comment at the first `*/`, so it compiles the C++ code. `/* */ // */` is just a comment. In `//\`, the backslash at the end of the line joins the next line onto the comment, so C++ never sees the Rust code.

**Limits to be aware of:**
- Both versions use 128-bit unsigned integers, so the answers are exact up to N = 184. Above that they overflow: the Rust build stops with an error, and the C++ build silently wraps around to a wrong number.
- The C++ code must never contain `/*` or `*/`, or Rust's comment counting breaks.
- The Rust code must stay on that single line after `//\`.
