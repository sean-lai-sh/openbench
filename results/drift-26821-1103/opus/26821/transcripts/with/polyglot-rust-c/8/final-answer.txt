I wrote the polyglot to `polyglot/main.rs`. I compiled it with both `rustc` and `g++ -x c++`, and both programs printed the same results:

| N | output |
|---|---|
| 0 | 1 |
| 1 | 1 |
| 2 | 2 |
| 10 | 89 |
| 90 | 4660046610375530309 |
| 180 | 30010821454963453907530667147829489881 |

**How it works:** Rust lets block comments nest, but C++ doesn't. So the line `/* /* */` is a complete comment in C++, while in Rust it leaves one comment still open.

- **C++:** After the first line it compiles the C++ `main`. Then `#if 0` makes it skip the Rust code. The final `/* /* */` is just a comment, followed by `#endif` and a `// */` line comment.
- **Rust:** Everything is inside a comment until the first `// */`, where the `*/` closes it. Then it compiles `fn main`. The final `/* /* */ … // */` hides `#endif` inside a comment.

**Limit:** Both versions use 128-bit integers, and C++ prints them with its own digit loop. Rust panics on overflow when N is about 183 or more, and C++ silently wraps around at the same point.
