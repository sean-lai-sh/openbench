Typo in settings key: `rat` should be `rate`.


The crash came from a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` returned `None`, which then failed when multiplied by `count`.

I renamed the key to `"rate"`. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

I didn't change the code. `get_rate()` still returns `None` silently if the key is missing, so a similar typo would give the same confusing error. Making it raise a clear error would catch that sooner. I can add that if you want it.
