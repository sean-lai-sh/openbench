How it works:
- **Find the bends:** it walks along random straight lines through the input space and halves the search range repeatedly to find points where the output stops changing linearly. Each bend is where one hidden neuron switches on or off.
- **Read off the row:** at each bend it estimates the gradient just before and just after, by nudging each input slightly. The difference between the two is that neuron's row of `A1`, multiplied by its output weight. Bend points where another bend is too close for clean estimates are skipped.
- **Remove duplicates:** each row is scaled to unit length with a fixed sign, and a row is kept only if it isn't already in the list. It stops after 30 lines in a row turn up no new neurons.

A neuron that is never active for any input would leave no bend, so the script couldn't find it; that wasn't a problem with this network.
