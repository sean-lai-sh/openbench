def grad(x, h=1e-6):
    g = np.zeros(D)
    f0 = forward(x)
    for i in range(D):
        e = np.zeros(D)
        e[i] = h
        fp = forward(x + e)
        fm = forward(x - e)
        gf = (fp - f0) / h
        gb = (f0 - fm) / h
        if abs(gf - gb) > 1e-5:
            return None
        g[i] = (fp - fm) / (2 * h)
    return g

`steal.py` is written and recovers all 20 neurons. Running it saves a 20×10 matrix to `stolen_A1.npy`, with each row normalized to unit length.

I checked it against the true `A1` in `forward.py`. Every true row has a stolen row with cosine similarity of at least 0.9999999999999998. That means the rows match up to permutation and scaling.

How it works:
- **Finding kinks:** It samples the network along 60 random lines. Each ReLU switching on or off shows up as a change in slope.
- **Locating each kink:** It intersects the linear pieces on either side to find where the change happens.
- **Reading the direction:** It estimates the gradient just before and just after the kink. The difference points along that neuron's row of `A1`.
- **Merging:** It groups parallel directions, ignoring sign, and keeps only directions seen at least twice.

The directions have no sign or scale, which is all that "up to scaling" allows. The script doesn't assume 20 hidden neurons, but I only tested it on this network. The detection thresholds (1e-7 for slope changes, 1e-5 for the gradient check) are tuned to weights of about this size.
