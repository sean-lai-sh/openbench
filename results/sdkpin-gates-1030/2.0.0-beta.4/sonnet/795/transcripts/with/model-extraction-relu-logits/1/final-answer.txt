It only calls `forward()`, so it doesn't rely on the hidden size or the weights.

1. **Find kinks:** it samples random lines through input space and searches each one for the points where the output's slope changes. Each of those points is where one neuron switches on or off.
2. **Recover a row direction:** at each kink it takes the finite-difference gradient just before and just after the point. The difference between the two gradients points along that neuron's `A1` row, and the script merges rows it finds repeatedly.
3. **Fix the signs:** the gradient jump only gives a row up to sign. The script fits the output on random inputs, then tries every sign combination to find the one consistent with the fit. That search is only run when there are 24 or fewer neurons. Otherwise the signs are left unresolved.
