I fixed six bugs in `catalog/`, but I haven't run `python3 -m unittest`. I had no way to run commands in this session, so the fixes come from reading the code against the tests. Please run the suite to confirm.

- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`.
- **`members.py`**: `MAX_BORROWED` was 3 and is now 5, matching the lending policy comment and the tests.
- **`fees.py`**: the late fee added the daily rate to the days late. It now multiplies (`days_late * DAILY_FEE`).
- **`factory.py`**: `sample_books()` was missing the third title, so I added `Book("Emma", "Austen", 1815, 1)`.
- **`inventory.py`**: `recent(n)` returned `n + 1` events because of a slice off-by-one. It now returns the last `n`, or an empty list when `n` is 0 or less.
- **`books.py`**: `parse_book` left the year as a string. It now converts it with `int(year)`, which also fixes `age()`.

I didn't touch anything under `tests/`.
