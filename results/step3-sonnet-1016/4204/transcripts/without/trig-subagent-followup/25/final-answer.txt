| File | Line | How it reads the setting |
|---|---|---|
| `main.py` | 11 | `cfg["fee_rate"]`, with `except KeyError: rate = 0` as a fallback |
| `billing/report.py` | 7 | `get_setting("fee_rate")`, which goes through `app/config.py:15` |
| `billing/export/csv_writer.py` | 8 | `settings.get("fee_" + "rate")`, where the key is built by string concatenation |
