Three files read the `fee_rate` setting, and I fixed all three paths with one change to `settings.json`.

**Readers of `fee_rate`**

| File:line | How it reads | If the key is missing |
|---|---|---|
| `main.py:11` | `cfg["fee_rate"]` | Catches `KeyError` and uses 0, so the total is silently wrong |
| `billing/report.py:7` | `get_setting("fee_rate")` | `SystemExit("fee_rate is missing")` |
| `billing/export/csv_writer.py:8` | `settings.get("fee_" + "rate")` | `SystemExit("fee_rate is missing")` |

The `csv_writer.py` read is easy to miss because the key name is built by string concatenation, so a plain search for `fee_rate` doesn't find it.

Two other files mention the name but don't read the setting:
- `billing/invoice.py:5` only assigns the string `"fee_rate"` as a column name.
- `billing/discount.py:5` has a hardcoded local `archived_fee_rate = 0.15`.

**The fix**

I changed `settings.json:2` from `"rat": 0.5` to `"fee_rate": 0.5`. All three readers load from the same file through `app/config.py`, so none of them needed code changes.

**Check**

I ran all three paths:
- `python3 main.py` prints `Total: 5.0`.
- `python3 -m billing.report` prints `Report fee: 0.5`.
- `python3 -m billing.export.csv_writer` prints `CSV fee: 0.5`.
