Three places read the `fee_rate` setting, and all three work now. I fixed the typo in `settings.json`, and all three entry points run correctly.

**Files and lines that read it:**
- `main.py:11` reads `cfg["fee_rate"]`. It falls back to 0 on `KeyError` at lines 12-13.
- `billing/report.py:7` reads `get_setting("fee_rate")`. It exits with "fee_rate is missing" if the value is `None`.
- `billing/export/csv_writer.py:8` reads `settings.get("fee_" + "rate")`. The key is built by string concatenation, so a plain search for `fee_rate` misses it. It also exits if the value is missing.

Other files mention the name but don't read the setting:
- `billing/invoice.py:5` is a local string.
- `billing/discount.py:5` is the local `archived_fee_rate`.
- `billing/tax.py` and `billing/audit.py` only mention it in docstrings.

**The fix:** in `settings.json` line 2, I changed `"rat"` to `"fee_rate"`.

**Results:**
- `python3 main.py` prints `Total: 5.0`.
- `python3 -m billing.report` prints `Report fee: 0.5`.
- `python3 -m billing.export.csv_writer` prints `CSV fee: 0.5`.

I left the `except KeyError` fallback in `main.py` alone. It's what hid the typo, so say if you want it removed so a missing key raises an error.
