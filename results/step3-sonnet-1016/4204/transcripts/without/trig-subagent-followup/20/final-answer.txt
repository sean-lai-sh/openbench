The setting is read in three places, and all three now work.

**Files and lines that read `fee_rate`:**
1. `main.py:11` reads `cfg["fee_rate"]`.
2. `billing/report.py:7` reads `get_setting("fee_rate")`.
3. `billing/export/csv_writer.py:8` reads `settings.get("fee_" + "rate")`. The key is built by string concatenation, so a plain search for `fee_rate` doesn't find it.

**Files that mention it but don't read the setting:**
- `billing/invoice.py:5` only sets a local string.
- `billing/discount.py:5` uses a hardcoded `archived_fee_rate`.
- `billing/tax.py` and `billing/audit.py` only have look-alike names.

**Fix:** I changed `settings.json:2` from `"rat"` to `"fee_rate"`. Before the fix, `report.py` and `csv_writer.py` would have exited with "fee_rate is missing". `main.py` was the only one that hid the problem.

**Verification:**
- `python3 main.py` prints `Total: 5.0`.
- `python3 -m billing.report` prints `Report fee: 0.5`.
- `python3 -m billing.export.csv_writer` prints `CSV fee: 0.5`.
