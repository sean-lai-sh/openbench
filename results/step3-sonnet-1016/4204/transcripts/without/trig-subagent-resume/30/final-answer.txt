- **Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `app/pricing.py:8` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. `app/report.py:9` then tried `None * 10`.
- **Fix:** I renamed the key to `"rate"` in `settings.json`.
- **Subagent:** The first subagent call traced the `None` to `app/pricing.py:8` and found the typo at `settings.json:2`. I couldn't do the resume step, because that call returned no task id and the task tool has no parameter for passing one. I read the files myself to confirm the missing key was `rate`.

I didn't change `SETTINGS.get("rate")` to `SETTINGS["rate"]`. That would make a missing key raise a `KeyError` instead of returning `None`, if you want it to fail earlier next time.
