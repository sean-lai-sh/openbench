`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate"`. `get_rate()` in `app/pricing.py:8` used `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then crashed `rate * count` in `app/report.py:9`.

**Fix:**
- In `settings.json`, I renamed `"rat"` to `"rate"`.
- In `app/pricing.py`, I changed `SETTINGS.get("rate")` to `SETTINGS["rate"]`. A missing key now raises a `KeyError` instead of silently becoming `None`.

**Subagent resume:** I couldn't do the second task call. The first call returned no task id, and the task tool has no parameter for resuming a subagent. The first report already named the missing key (`rat`), and I confirmed it by reading `settings.json` myself.
