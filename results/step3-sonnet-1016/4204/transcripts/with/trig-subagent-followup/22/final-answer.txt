The setting `fee_rate` is read in three places. I fixed the bug, and all three now work.

**Files and lines that read it:**
- `main.py:11` reads `cfg["fee_rate"]`. A missing key was swallowed by `except KeyError: rate = 0`.
- `billing/report.py:7` reads `get_setting("fee_rate")`. A missing key exits with `"fee_rate is missing"`.
- `billing/export/csv_writer.py:8` reads `settings.get("fee_" + "rate")`. A missing key exits with `"fee_rate is missing"`. The key is built by string concatenation, so a plain search for `fee_rate` doesn't find the read. The subagent cited line 10, but that line is only the error message.

- `billing/invoice.py:5` only uses `"fee_rate"` as a heading label.
- `billing/discount.py:5` has a local constant, `archived_fee_rate = 0.15`.

**Fix:** in `settings.json:2` I renamed `"rat"` to `"fee_rate"`. This was the only change.
