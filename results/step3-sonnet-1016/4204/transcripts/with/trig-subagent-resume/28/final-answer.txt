The bug is fixed. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

- **Cause:** `settings.json` line 2 had the key `"rat"` instead of `"rate"`. `get_rate()` in `app/pricing.py:8` calls `SETTINGS.get("rate")`, which returns `None` for a missing key. That `None` then crashed at `rate * count` in `app/report.py:9`.
- **Subagent:** the first call traced the `None` to `app/pricing.py:8`. I resumed the same subagent with its session id, and it confirmed the missing key was `"rate"`.
- **Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.

I left `SETTINGS.get("rate")` as it is. Switching it to `SETTINGS["rate"]` would make a missing key fail with a clear error instead of returning `None`. I didn't make that change because you only asked for the fix.
