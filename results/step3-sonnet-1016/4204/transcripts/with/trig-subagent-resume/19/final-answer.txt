I fixed the crash. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

**Cause:** `settings.json` had the key misspelled as `"rat"` instead of `"rate"`. `get_rate()` in `app/pricing.py:8` uses `SETTINGS.get("rate")`, which returns `None` for a missing key. That `None` then reached `rate * count` in `app/report.py:9` and raised the `TypeError`.

**Subagent calls:**
- The first call traced `rate` back to the `"rat"` key in `settings.json` line 2.
- I made the second call with the same session id, so the same subagent continued. It confirmed the missing key is `"rate"`.

**Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.

I did not change `.get("rate")`. Switching it to `SETTINGS["rate"]` would make a missing key fail with a `KeyError` that names it, instead of a confusing `NoneType` error later. I left that alone because you only asked for the bug fix.
