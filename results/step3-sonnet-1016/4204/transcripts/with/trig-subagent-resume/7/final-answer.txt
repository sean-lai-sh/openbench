`python3 main.py` now prints `Total: 5.0` and exits cleanly.

**Cause:** `settings.json:2` had the key `"rat"` instead of `"rate"`. `app/pricing.py:8` calls `SETTINGS.get("rate")`, which returns `None` for a missing key instead of raising an error. That `None` reached `app/report.py:9`, where `rate * count` crashed.

**Subagent calls:** The first call traced the `None` to the `"rat"` typo. I then called the task tool again with the same session id, and the subagent confirmed the missing key is `"rate"`.

**Fix:** I renamed `"rat"` to `"rate"` in `settings.json`. I left `pricing.py` alone. Switching it to `SETTINGS["rate"]` would make a future typo fail with a clear `KeyError`, if you want that.
