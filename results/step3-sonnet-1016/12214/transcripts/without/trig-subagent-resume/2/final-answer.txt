The bug is fixed. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

**Cause:** `settings.json:2` had the key `"rat"` instead of `"rate"`. `app/pricing.py:8` used `SETTINGS.get("rate")`, which returned `None` instead of raising an error. `app/report.py:9` then crashed on `None * 10`.

**Subagent findings:** The first call traced `rate` becoming `None` to `app/pricing.py:8`, with the root cause at `settings.json:2`. I resumed the same session for the second call, and it confirmed the missing key is `"rate"`.

**Fixes:**
- `settings.json`: renamed `"rat"` to `"rate"`.
- `app/pricing.py`: changed `.get("rate")` to `["rate"]`, so a missing key now raises a `KeyError` instead of surfacing later as a `TypeError`.
