The bug is fixed. `python3 main.py` now prints `Total: 5.0`.

- **Cause:** `settings.json` had the key misspelled as `"rat"`. `get_rate()` in `app/pricing.py:8` calls `SETTINGS.get("rate")`, which returned `None` because that key didn't exist. `rate * count` then crashed at `app/report.py:9`.
- **Subagent:** the first task traced the `None` to `app/pricing.py:8`. I resumed the same subagent with its task id. It confirmed the missing key was `"rate"`.
- **Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.

I left `get_rate()` using `.get`, so a missing key would still give `None` instead of an error. Switching it to `SETTINGS["rate"]` would make a future typo fail with a clear `KeyError`.
