The bug was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` in `app/pricing.py:8` uses `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then crashed `rate * count` in `app/report.py:9`.

- **Subagent trace:** the first call traced `rate` becoming `None` to `app/pricing.py:8`, caused by `settings.json` line 2. I resumed the same subagent with the task id the first call returned. It confirmed the missing key is `"rate"`.
- **Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.
- **Check:** `python3 main.py` now prints `Total: 5.0` and exits with code 0.

I didn't change `get_rate` to use `SETTINGS["rate"]`. That would make a missing key fail with a clear `KeyError` instead of returning `None`, if you want that.
