`python3 -m unittest` now passes: all 16 tests, with the tests left unmodified.

- **`search.py`:** it imported `normalize` from `catalog.nonexistent`, which doesn't exist. It now imports from `catalog.text`.
- **`members.py`:** `MAX_BORROWED` was 3 and is now 5.
- **`books.py`:** `parse_book` left the year as a string. It now converts it with `int()`.
- **`factory.py`:** `sample_books()` was missing the "Emma" book. I added `Book("Emma", "Austen", 1815, 1)`. The author, year and copy count are my own choices, since the tests only check the title.
- **`fees.py`:** `late_fee` added the daily fee to the days late instead of multiplying. It now uses `days_late * DAILY_FEE`.
- **`inventory.py`:** `recent(n)` returned `n + 1` events. It now returns the last `n`, and an empty list when `n <= 0`.
