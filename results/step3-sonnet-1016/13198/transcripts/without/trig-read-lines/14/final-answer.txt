`# The lending policy allows each member to hold five books at once.`

All 16 tests now pass with `python3 -m unittest`. I fixed these in `catalog/`:

- **`members.py`**: `MAX_BORROWED` was 3. The comment and tests say five, so I set it to 5.
- **`search.py`**: it imported `normalize` from the nonexistent `catalog.nonexistent`. It now imports from `catalog.text`.
- **`books.py`**: `parse_book` left the year as a string. It now converts it with `int`.
- **`fees.py`**: the fee was `days_late + DAILY_FEE`. It is now `days_late * DAILY_FEE`.
- **`inventory.py`**: `recent(n)` sliced `[-n - 1:]`, which returned one event too many. It now slices `[-n:]`, and returns an empty list when `n` is 0 or less. That last guard goes beyond what the tests require.
- **`factory.py`**: `sample_books()` was missing the `Emma` entry, so I added `Book("Emma", "Austen", 1815, 1)`.
