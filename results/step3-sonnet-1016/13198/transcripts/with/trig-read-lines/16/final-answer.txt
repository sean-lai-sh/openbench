`# The lending policy allows each member to hold five books at once.`

All 16 tests now pass with `python3 -m unittest`. I didn't modify any tests. The fixes in `catalog/`:

- **`members.py`**: `MAX_BORROWED` was 3, but the comment on line 3 says five. I set it to 5.
- **`books.py`**: `parse_book` left the year as a string. It now converts it with `int()`, which also fixes `age()`.
- **`fees.py`**: `late_fee` added the daily rate to the days late. It now multiplies them.
- **`inventory.py`**: `recent(n)` returned `n+1` events because of an off-by-one in the slice. It now returns `n`, and an empty list when `n` is 0.
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`.
- **`factory.py`**: `sample_books()` was missing the third book its docstring describes. I added `Book("Emma", "Austen", 1815, 1)`.
