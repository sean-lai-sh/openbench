All 25 tests now pass with `python3 -m unittest`. I didn't touch the tests. I fixed seven defects under `taskflow/`:

1. **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
2. **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which was off by one. It now uses `attempts_made < max_attempts`, which matches the docstring: with 3 attempts allowed, retries are allowed after attempts 1 and 2.
3. **`config.py`**: `deep_merge` recursed with its arguments swapped. Pipeline defaults overrode per-task settings instead of the other way round. It now calls `deep_merge(result[key], value)`.
4. **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`. Pools never fully freed, which blocked resource-limited tasks.
5. **`events.py`**: `_prefix_matches` had its operands reversed (`prefix.startswith(topic + ".")`). `job.term.*` events never reached `History`. It now checks `topic.startswith(prefix + ".")`.
6. **`statemachine.py`**: `batch_order_ok` required non-decreasing priority within a batch. Its docstring says non-increasing, so I changed `>=` to `<=`. The old check made the scheduler fail correctly ordered batches.
7. **`scheduler.py`**: `_cascade_skip` iterated over `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so grandchildren are skipped too.
