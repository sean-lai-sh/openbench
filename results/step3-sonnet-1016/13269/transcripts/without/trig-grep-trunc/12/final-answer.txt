All 25 tests now pass with `python3 -m unittest`. I didn't modify the tests. Most of the failing pipeline tests came from a few bugs in other modules, so I fixed each one at its source.

- **`queue.py`:** The sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which stopped one attempt early. It is now `attempts_made < max_attempts`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the base value overrode the task's value. It now merges `(result[key], value)`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`, which leaked capacity on multi-unit tasks and blocked later ones.
- **`statemachine.py`:** `batch_order_ok` had its comparison backwards. It now requires non-increasing priority within a batch.
- **`scheduler.py`:** `_cascade_skip` used the direct `dependents`. It now uses `transitive_dependents`, so the whole downstream chain is skipped.
- **`events.py`:** `_prefix_matches` had its arguments reversed. Prefix subscriptions such as `job.term` never matched `job.term.failed`, so history recorded no outcomes. It now uses `topic.startswith(prefix + ".")`.
