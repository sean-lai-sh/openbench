`python3 -m unittest` now passes all 25 tests. I didn't touch the tests. I made eight fixes in `taskflow/`:

- **`queue.py`:** the sort key was `(seq, -priority)`, so it ignored priority. It is now `(-priority, seq)`.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own settings. It now merges the task's values on top of the defaults.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`, which left multi-unit resources stuck as in use.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. Its docstring says non-increasing, so it now checks `current <= prev`.
- **`scheduler.py`:** `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`.
- **`events.py`:** `_prefix_matches` had the prefix and topic the wrong way round. Prefix subscribers like `job.term` never received `job.term.failed` or `job.term.skipped`, so the history's failed/skipped/succeeded lists stayed empty. It now checks `topic.startswith(prefix + ".")`.
