All 25 tests now pass under `python3 -m unittest`. I fixed seven logic bugs and didn't touch the tests.

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, so it retried one time too few. It now uses `attempts_made < max_attempts`.
- **`config.py`:** in `deep_merge`, the recursive call had its arguments swapped, so defaults overrode task settings. It now merges `(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. The docstring says non-increasing, so it now checks `current <= prev`.
- **`events.py`:** `_prefix_matches` had its operands reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`, which fixed the history tests.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`. Pools never fully drained, so resource-limited tasks never finished.
