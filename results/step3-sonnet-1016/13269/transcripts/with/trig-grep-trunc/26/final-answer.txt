All 25 tests now pass with `python3 -m unittest`. I didn't modify any tests.

My first `self` grep matched 1,325 lines and showed only 100, so I ran the test suite directly instead. Each fix below was a logic error, and some of them hid others:

1. **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority runs first and ties go in insertion order.
2. **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which allowed one attempt too few. It now uses `attempts_made < max_attempts`.
3. **`config.py`**: `deep_merge` recursed with its arguments swapped, so the pipeline defaults overrode a task's own `retry` settings. It now calls `deep_merge(result[key], value)`.
4. **`statemachine.py`**: `batch_order_ok` required priorities to be non-decreasing within a batch. Its docstring says non-increasing, so it now checks `current <= prev`.
5. **`scheduler.py`**: `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`, so every downstream task is skipped.
6. **`resources.py`**: `ResourcePool.release` did `self.used -= 1` instead of subtracting the cost. Multi-unit resources leaked capacity, so later tasks never ran.
7. **`events.py`**: `_prefix_matches` checked `prefix.startswith(topic + ".")`, which is backwards. It now checks `topic.startswith(prefix + ".")`, so `job.term.*` events reach `History`.
