The three reads ran first, and then I fixed the code. `python3 -m unittest` now runs 16 tests, all passing.

**The reads**
- **(a)** Reading the `catalog/` directory with the read tool returned "File not found". The error message listed the same path as a suggestion, so the tool doesn't seem to handle directories. I used `ls` in bash afterwards to see the package contents.
- **(b)** `books.py` with offset 0 and limit 5 returned lines 1–5.
- **(c)** `books.py` with offset 3 and limit 5 returned lines 4–8. So the offset is 0-based and starts at the line after the offset (offset 3 gives line 4).

**The fixes**
- **`books.py`:** `parse_book` now converts the year with `int(year)`. It was passing a string.
- **`factory.py`:** `sample_books()` now includes `Book("Emma", "Austen", 1815, 1)`. The docstring says the demo catalog has three titles.
- **`fees.py`:** `late_fee` now uses `days_late * DAILY_FEE`. It was adding the two.
- **`inventory.py`:** `recent(n)` now slices `[-n:]` instead of `[-n - 1:]`, which returned one event too many. It returns an empty list when `n <= 0`.
- **`members.py`:** `MAX_BORROWED` is now 5, matching the lending-policy comment and the tests.
- **`search.py`:** the import now comes from `catalog.text`. It pointed at a module that doesn't exist, and `normalize` is defined in `text.py`.

I didn't change any tests.
