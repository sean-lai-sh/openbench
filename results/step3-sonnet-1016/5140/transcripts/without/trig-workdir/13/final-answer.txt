`python3 main.py` now exits successfully and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat": 0.5`, but `app/pricing.py` reads `SETTINGS.get("rate")`. The lookup returned `None`, and `None * 10` raised the `TypeError`.

**Fix:** I changed the key to `"rate"` in `settings.json`. No code changed.

**The first command:** `python3 -c 'import pricing; ...'` run from `app/` failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, which only resolves when the project root is on the path, as it is when you run `main.py` from the root. It's unrelated to the crash, so I left it alone.
