`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`, so `report.py` tried to compute `None * 10`.

**Fix:** I changed `"rat"` to `"rate"` in `settings.json`. With the rate at 0.5 and a count of 10, the total is 5.0.

**Import check:** The `python3 -c 'import pricing; ...'` command you asked for failed with `ModuleNotFoundError` when run from `app/`. `pricing` lives inside the `app` package and imports `app.config`. It has to be imported as `app.pricing` from the project root, so that failure doesn't point to a separate bug.
