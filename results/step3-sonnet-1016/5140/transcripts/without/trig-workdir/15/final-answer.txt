The program now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` looks up `"rate"`, so it got `None`, and `None * 10` raised the `TypeError`.

**Fix:** I renamed `"rat"` to `"rate"` in `settings.json`. No code changes were needed.

Running from `app/` puts `app/` on the path instead. This is separate from the crash. Running `python3 main.py` from the project root works.
