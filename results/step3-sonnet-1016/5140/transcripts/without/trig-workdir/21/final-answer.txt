`python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then crashed in `rate * count`. I renamed the key to `"rate"` in `settings.json`.

**The `pricing` import check:** `python3 -c 'import pricing; print(pricing.__file__)'` run from `app/` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on `sys.path`. Running from `app/` doesn't put it there. This doesn't affect `python3 main.py`, which runs from the root, so I left it alone.
