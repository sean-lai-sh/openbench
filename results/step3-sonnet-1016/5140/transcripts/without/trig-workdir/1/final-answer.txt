`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. `report.py` then tried `None * 10`. I renamed the key to `"rate"` in `settings.json`.

**The first command failed:** `python3 -c 'import pricing; ...'` from `app/` raised `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on `sys.path`. That is the case when you run `main.py` from the root, but not from inside `app/`. It's unrelated to the crash, so I left the imports alone.
