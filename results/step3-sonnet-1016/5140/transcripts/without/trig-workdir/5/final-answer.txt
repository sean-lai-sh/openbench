`python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because there was no `"rate"` key. That `None` then hit `rate * count` in `compute_total`. I changed the key to `"rate"`.

**The import check you asked for:** Run from `app/`, `python3 -c 'import pricing; ...'` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and that only resolves when the project root is on the path. From inside `app/`, it isn't. The check fails for that reason alone, and it isn't connected to the crash. Running `python3 main.py` from the project root works, so I left the imports alone.
