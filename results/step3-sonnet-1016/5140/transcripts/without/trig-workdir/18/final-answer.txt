`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` and broke the multiplication in `compute_total`.

**Fix:** I renamed the key to `"rate"` in `settings.json`.

**Import command:** `python3 -c 'import pricing; print(pricing.__file__)'` fails when run from `app/`. `pricing.py` does `from app.config import SETTINGS`, and `app` can't be imported when `app/` is the working directory. That's unrelated to the crash, since `main.py` runs from the project root where `app` resolves. I left it alone.
