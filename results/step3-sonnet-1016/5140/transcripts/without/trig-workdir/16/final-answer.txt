`python3 main.py` now prints `Total: 5.0` and exits cleanly.

**Cause:** `settings.json` had a typo. The key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`, and that caused the `TypeError` in `compute_total`. I changed the key to `"rate"`.

**The command you asked me to run:** `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` fails with `ModuleNotFoundError: No module named 'app'`. That is because `pricing.py` does `from app.config import SETTINGS`. From inside `app/`, the parent directory isn't on `sys.path`, so the `app` package can't be found. This is separate from the crash. Running from the project root, as `main.py` does, works. I left the import alone.
