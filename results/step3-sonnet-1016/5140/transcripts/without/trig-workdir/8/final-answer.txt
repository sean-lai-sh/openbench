The crash is fixed. `python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then hit `None * 10` in `compute_total`.

**Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.

**The `pricing` import command:** `python3 -c 'import pricing; print(pricing.__file__)'` with `app/` as the working directory fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and from inside `app/` the parent directory isn't on `sys.path`, so `app` can't be found. This is separate from the crash, and `main.py` works because it runs from the project root. I left it alone since the task only needed `main.py` to run.
