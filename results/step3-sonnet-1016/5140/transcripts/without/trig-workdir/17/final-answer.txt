`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`. That `None` caused the `TypeError` in `compute_total`. I renamed the key to `"rate"`.

**The command you asked me to run first:** `python3 -c 'import pricing; ...'` with `app/` as the working directory failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `from app.config import SETTINGS`, which only resolves when the project root is on the import path. Running from the root, as `main.py` does, works. This failure is separate from the crash, so I left it alone.
