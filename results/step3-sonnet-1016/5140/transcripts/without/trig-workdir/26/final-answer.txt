`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo in the key name, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key wasn't there. `compute_total` then tried `None * 10`, which raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`.

The command you asked me to run first, `python3 -c 'import pricing; ...'` from inside `app/`, fails with `ModuleNotFoundError: No module named 'app'`. That's because `pricing.py` does `from app.config import ...`, which only resolves when the project root is on the path. It's a side effect of running from `app/` and unrelated to the crash. I left it alone, since `main.py` runs from the project root.
