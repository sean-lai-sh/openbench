`python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had the key `"rat"` (a typo for `"rate"`). `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`, and `None * 10` raised the `TypeError`. I renamed the key to `"rate"` in `settings.json`.

**The command you asked me to run:** `python3 -c 'import pricing; print(pricing.__file__)'` failed from `app/` with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on the import path. It works when run from the project root, as `main.py` does. It's unrelated to the crash, so I left it alone.
