`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then crashed `rate * count` in `compute_total`.

**Fix:** I renamed the key to `"rate"` in `settings.json`.

**The command you asked me to run first:** `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on `sys.path`, as it is when you run `main.py` from there. The failure comes from where I ran the command, not from the bug. I didn't change any code for it.
