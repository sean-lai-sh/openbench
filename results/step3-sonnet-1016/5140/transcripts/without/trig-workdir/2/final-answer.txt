`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` looks up `"rate"`, so `SETTINGS.get("rate")` returned `None`. That `None` then hit `None * 10` in `compute_total`. I renamed the key to `"rate"`.

**The first command:** `python3 -c 'import pricing; print(pricing.__file__)'` failed when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and `app` is only importable from the project root, not from inside `app/`. This is unrelated to the crash. I left it alone because `main.py` runs from the root, where the import works.
