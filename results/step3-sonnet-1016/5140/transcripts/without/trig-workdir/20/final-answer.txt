`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo in the key, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` was then multiplied by the count in `compute_total`, which raised the `TypeError`. I changed the key to `"rate"`.

**The import command you asked for:** `python3 -c 'import pricing; print(pricing.__file__)'` failed when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and that only resolves when the project root is on the path. `main.py` runs from the root, so it isn't affected, and I left that import alone. To run the check you asked for, use `python3 -c 'import app.pricing as p; print(p.__file__)'` from the project root.
