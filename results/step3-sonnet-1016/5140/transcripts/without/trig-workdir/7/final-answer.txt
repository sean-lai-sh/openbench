`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`. That `None` was then multiplied by `count` in `report.py`, which raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**The import check:** `python3 -c 'import pricing; ...'` from inside `app/` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and `app` can only be imported from the project root. This is unrelated to the crash, since `main.py` runs from the root where the import works. I left it alone.
