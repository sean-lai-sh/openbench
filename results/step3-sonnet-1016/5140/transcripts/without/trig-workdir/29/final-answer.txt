`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then crashed `compute_total` at `rate * count`. I fixed the key to `"rate"` in `settings.json`.

**Your first command failed:** `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` raised `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on the path. Running from `app/` puts that directory on the path instead. This is separate from the crash, and `main.py` runs from the root, so I left the import alone. From the project root, `python3 -c 'from app import pricing; print(pricing.__file__)'` should work.
