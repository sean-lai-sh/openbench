Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo in the key, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`. That `None` caused the `TypeError` in `compute_total`. I renamed the key to `"rate"`.

**The first command:** `python3 -c 'import pricing; ...'` with `app/` as the working directory failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `from app.config import SETTINGS`, and that import only resolves when the project root is on `sys.path`. This is separate from the crash. It only affects importing `pricing` directly from inside `app/`, and `main.py` run from the root works fine. I left it alone.
