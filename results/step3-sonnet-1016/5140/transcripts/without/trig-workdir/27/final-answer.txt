I fixed the crash. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`, so `compute_total` tried `None * 10`. I changed the key to `"rate"`.

**The import command you asked me to run:** `python3 -c 'import pricing; print(pricing.__file__)'` fails when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, so Python has to be started from the project root, where `app` is a package. That error is unrelated to the crash, and I left it alone because `main.py` works as the entry point.
