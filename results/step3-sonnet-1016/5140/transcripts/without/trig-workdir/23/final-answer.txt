The program now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had a typo in the key, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` instead of raising an error. That `None` then hit `rate * count` in `report.py` and caused the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. I didn't change any code.

**Import command:** `python3 -c 'import pricing; ...'` run from `app/` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `app.config`, which only resolves when the project root is on the path, as it is when you run `python3 main.py`. That failure comes from running the command inside `app/`. It isn't a second bug, so I left it alone.
