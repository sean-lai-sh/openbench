`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`. That `None` then hit `rate * count` in `report.py`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. The rate of 0.5 times a count of 10 gives 5.0.

**The import command you asked me to run:** `python3 -c 'import pricing; print(pricing.__file__)'` fails with the `app/` directory as the working directory. The error is `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, so it only imports when the project root is on `sys.path`. Running from `app/` leaves the root off `sys.path`. This is separate from the crash, and `main.py` runs from the root, so I left it alone.
