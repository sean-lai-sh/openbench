`python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then hit `rate * count` in `compute_total` and raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**Import check:** The `python3 -c 'import pricing; ...'` command you asked me to run from `app/` failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `app.config`, and `app` can only be found when you run from the project root, as `main.py` does. This is unrelated to the crash, so I left it alone.
