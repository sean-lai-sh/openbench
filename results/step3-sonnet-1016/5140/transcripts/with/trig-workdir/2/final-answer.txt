The crash is fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` reads `SETTINGS.get("rate")`, so it got `None`, and `None * 10` raised the `TypeError`.

**Fix:** I changed `"rat"` to `"rate"` in `settings.json`.

**The `pricing` import check:** The command you asked me to run first, `python3 -c 'import pricing; print(pricing.__file__)'` from `app/`, fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on the path, as it is when you run `main.py` from there. This is a side effect of running it from inside `app/`, not part of the crash, so I left it alone.
