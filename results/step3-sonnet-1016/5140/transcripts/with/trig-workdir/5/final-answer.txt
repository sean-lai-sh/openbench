I fixed it, and `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` looks up `"rate"`, so it returned `None`, and `compute_total` then tried `None * 10`. I changed the key to `"rate"`.

**Your first command:** `python3 -c 'import pricing; print(pricing.__file__)'` with `app/` as the working directory failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on the import path. From inside `app/` it isn't. This doesn't affect `python3 main.py`, which runs from the root. I left it alone since it isn't part of the crash.
