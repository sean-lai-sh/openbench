`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. `compute_total` then tried `None * 10`, which raised the `TypeError`.

**Fix:** I changed the key to `"rate"` in `settings.json`.

**Import check:** `python3 -c 'import pricing; ...'` from inside `app/` fails with `ModuleNotFoundError: No module named 'app'`. `app/pricing.py` imports `app.config`, so it only resolves when the project root is on the path. Running from the root, as `main.py` does, works. I didn't change anything for this.
