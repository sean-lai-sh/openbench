`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`, so `report.py` ended up computing `None * count`. I renamed the key to `"rate"` in `settings.json`.

**The import check you asked for:** `python3 -c 'import pricing; print(pricing.__file__)'` fails when run from `app/`. `pricing.py` does `from app.config import SETTINGS`, and that needs the project root on `sys.path`. From `app/` it raises `ModuleNotFoundError: No module named 'app'`. This is unrelated to the crash, since `main.py` runs from the root. If you want the check to pass, run it from the root as `python3 -c 'from app import pricing; print(pricing.__file__)'`.
