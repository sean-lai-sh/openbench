`python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had a typo, `"rat": 0.5`, but `app/pricing.py` reads `SETTINGS.get("rate")`. The lookup returned `None`, and `rate * count` in `app/report.py` then failed with the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`.

**Your first command:** `python3 -c 'import pricing; print(pricing.__file__)'` run from `app/` failed with `ModuleNotFoundError: No module named 'app'`. `app/pricing.py` does `from app.config import SETTINGS`, which only resolves when the project root is on the import path. The root is on the path when you run `python3 main.py` from there, but not when you run from inside `app/`. This is separate from the crash, and I left it alone.
