Fixed. `python3 main.py` now prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then crashed `rate * count` in `compute_total`. I renamed the key to `"rate"` in `settings.json`.

**The import check you asked for:** `python3 -c 'import pricing; ...'` from `app/` failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `app.config`, and `app` is only importable from the project root, not from inside `app/`. This is unrelated to the crash. The code is meant to run from the project root, as `main.py` does, so I left it alone.
