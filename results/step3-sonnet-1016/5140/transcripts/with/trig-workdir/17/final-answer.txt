`python3 main.py` now prints `Total: 5.0` and exits cleanly.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then crashed in `rate * count`. I renamed the key to `"rate"` in `settings.json`, and no code changed.

**The `import pricing` check:** From `app/`, `python3 -c 'import pricing; ...'` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `from app.config import ...`, which only resolves when the project root is on the path. It isn't related to the crash, and the app runs correctly from the root. If you need `pricing` to be importable on its own from `app/`, tell me and I'll look at it.
