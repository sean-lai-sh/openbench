`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key `"rat"` (a typo), but `app/pricing.py` reads `"rate"`. `SETTINGS.get("rate")` therefore returned `None`, and `None * 10` raised the `TypeError`.

**Fix:** I changed `"rat"` to `"rate"` in `settings.json`.

**Import check:** The `python3 -c 'import pricing; ...'` command you asked me to run from `app/` fails with `ModuleNotFoundError: No module named 'app'`. That happens because `pricing.py` does `from app.config import ...`, which only resolves when the project root is on the path. It doesn't affect `python3 main.py`, which runs from the root, so I left it alone.
