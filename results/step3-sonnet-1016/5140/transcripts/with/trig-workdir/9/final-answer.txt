`python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`. That `None` is what `report.py` tried to multiply by the count.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**The `import pricing` command:** I ran it from `app/` as you asked, and it fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, so it only imports when the project root is on the path, for example when run through `main.py`. The crash you reported doesn't come from this, and I left it alone.
