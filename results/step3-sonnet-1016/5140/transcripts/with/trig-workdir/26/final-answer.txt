`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` instead of raising an error. That `None` then hit `rate * count` in `report.py`.

**Fix:** I changed `"rat"` to `"rate"` in `settings.json`. I didn't change any code.

**The `pricing` import check:** `python3 -c 'import pricing; print(pricing.__file__)'` failed when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, which only resolves when the project root is on the import path. Running from the project root, as `main.py` does, works.
