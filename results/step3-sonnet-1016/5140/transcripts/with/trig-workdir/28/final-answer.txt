`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo in the key name, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then caused the `TypeError` in `compute_total`. I renamed the key to `"rate"` in `settings.json`.

**The `pricing` check:** You asked me to run `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` first. It failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` imports `from app.config import SETTINGS`, and `app` can only be imported from the project root. That is unrelated to the crash, since `main.py` runs from the root and imports it correctly, so I left it alone.
