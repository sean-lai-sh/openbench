`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `SETTINGS.get("rate")` therefore returned `None`, and `None * 10` raised the `TypeError`.

**Fix:** I corrected the key to `"rate"` in `settings.json`.

**Import check:** `python3 -c 'import pricing; print(pricing.__file__)'` fails when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, and that only resolves when the project root is on `sys.path`. It's unrelated to the crash, and `main.py` run from the root works fine, so I left it alone.
