`python3 main.py` now prints `Total: 5.0` and exits cleanly.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then crashed `rate * count` in `compute_total`. I fixed the key in `settings.json`, and no code changed.

**The check you asked for:** `python3 -c 'import pricing; ...'` run from `app/` failed with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and from inside `app/` the package `app` isn't importable. This comes from where the command is run and is unrelated to the crash. Run from the project root, as `main.py` does, the imports resolve.
