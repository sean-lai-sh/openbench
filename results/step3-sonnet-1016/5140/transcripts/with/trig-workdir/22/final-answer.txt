`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo, `"rat"` instead of `"rate"`. `pricing.get_rate()` looks up `"rate"` with `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then crashed in `rate * count`.

**Fix:** I changed the key to `"rate"` in `settings.json`.

**Import check:** The `python3 -c 'import pricing; ...'` command you asked me to run failed from `app/`, with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, and that only resolves when the project root is the working directory. This is unrelated to the crash, and I left it alone because `main.py` runs from the root.
