`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat": 0.5`, where it should have been `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None`. That `None` caused the `TypeError` in `compute_total`. I changed the key to `"rate"`.

**The command you asked me to run:** `python3 -c 'import pricing; ...'` from `app/` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import SETTINGS`, and that only resolves when the project root is on `sys.path`. Running `python3 main.py` from the root works because of that. It's unrelated to the crash, so I left it alone.
