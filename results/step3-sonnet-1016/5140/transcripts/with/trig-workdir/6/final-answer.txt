`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` and caused the `TypeError` in `compute_total`. I renamed the key to `"rate"`.

**The `pricing` import check:** `python3 -c 'import pricing; ...'` run from `app/` fails with `ModuleNotFoundError: No module named 'app'`. `pricing.py` does `from app.config import ...`, and that only resolves when the project root is on the path. It has nothing to do with the crash, because `main.py` runs from the project root. I left it alone, since the program works as intended.
