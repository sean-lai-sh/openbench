`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo, `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` looks up `"rate"`, so it returned `None`. That `None` is what `compute_total` then tried to multiply. I fixed the key in `settings.json`.

**The pre-check you asked for:** `python3 -c 'import pricing; print(pricing.__file__)'` fails when run from `app/`. `pricing.py` does `from app.config import ...`, and from inside `app/` the `app` package isn't importable (`ModuleNotFoundError: No module named 'app'`). That is a side effect of where the command runs. It isn't the bug behind the crash, and it doesn't affect `python3 main.py` run from the project root. I left it alone.
