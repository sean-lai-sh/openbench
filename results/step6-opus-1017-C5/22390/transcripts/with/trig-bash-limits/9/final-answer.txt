How the two diagnostics went:
1. **`python3 -c "print('diag ' * 8000)"`**: ran normally and the bash tool returned the full ~40,000-character output.
2. **`sleep 5 && python3 -m unittest` with timeout 2000**: the tool stopped the command when the 2000 ms timeout ran out, before the 5-second sleep ended. The tests never ran, so this step gave no test output. I found the bug by reading the source and the tests instead.
