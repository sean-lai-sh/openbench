The bug was in `subtract`: it added the two numbers instead of subtracting them. I fixed it, and `python3 -m unittest` now passes all 4 tests with exit code 0.

**The two diagnostics:**
1. `python3 -c "print('diag ' * 8000)"` ran and printed its full output (about 40,000 chars) with no truncation notice.
2. `sleep 5 && python3 -m unittest` with `timeout=2000` was stopped by the bash tool at 2 seconds ("terminated command after exceeding timeout 2000 ms"). The 5-second sleep was still running, so the tests never started and this run gave no test output.

**The fix:** In `calculator.py:6`, `subtract` was `return a + b`, so `test_subtract` got `subtract(5, 3) == 8` instead of `2`. I changed it to `return a - b` and left the tests unchanged.
