The script uses only `forward()` queries, so it doesn't assume the hidden width of 20.

- **Finding kinks:** it evaluates the network along random lines and looks for points where the output stops being linear, which is where a neuron switches on or off.
- **Reading off the row:** at each kink it measures the gradient on both sides. The difference is proportional to that neuron's row of A1.
- **Cleaning up:** it groups the directions that repeat and keeps those seen at least twice.

Each row is normalized to unit length, and its sign is fixed so the largest component is positive. Sign and scale can't be recovered from the output alone, which matches the "up to scaling" allowance. A neuron that never switches within the search range (±6 along each line) wouldn't be found.
