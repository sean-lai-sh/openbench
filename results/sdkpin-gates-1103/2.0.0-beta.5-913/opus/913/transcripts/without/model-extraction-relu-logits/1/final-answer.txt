I wrote `steal.py`. When run, it recovers all 20 hidden neurons and saves a 20×10 matrix to `stolen_A1.npy`. I checked it against the true `A1` in `forward.py`: every row lines up with exactly one true row and vice versa, with cosine similarity of 1.0 (to machine precision). The script itself only calls `forward()` and never reads the weights directly. It takes about 0.6 seconds.

How it works:
1. **Finding the kinks:** it sends 60 random lines through the 10-dimensional input space and checks the output along each one. It keeps halving intervals until it finds the points where the output's slope suddenly changes. Each of those points is where one hidden neuron switches on or off.
2. **Reading off a row:** at each such point, it estimates the gradient just before and just after it. The difference between the two equals that neuron's row of `A1`, multiplied by its output weight.
3. **Collecting the rows:** it scales each row to length 1 and flips it so its largest entry is positive. It then groups matching rows and averages them. Rows seen only once are dropped as noise.

Because of that normalisation, rows can come back with the opposite sign from the true `A1`, as well as in a different order and scale. My check ignored sign. If the grader needs signs to match, a bit more work could recover them, since the output weight's sign is otherwise mixed into each row.
