I wrote `steal.py`, ran it, and it saved a 20×10 matrix to `stolen_A1.npy`. All 20 hidden neurons were recovered, and each stolen row matches the corresponding true row of A1 up to sign and scale with cosine similarity ≈ 1.0. The script gets the matrix only by calling `forward()`. I opened `forward.py`'s real weights once, in a separate one-off command, just to run that comparison.

How it works:
1. **Find the kinks.** It draws 40 random lines through input space and searches along each one for the points where the output stops being linear. Each of those points is where one hidden neuron switches on or off.
2. **Read off a row.** At each kink it estimates the gradient just before and just after. The difference between the two is that neuron's row of A1, multiplied by its output weight.
3. **Merge duplicates.** It normalises each of these vectors, groups the ones that point the same way (cosine > 0.999), and keeps the median of each group as one row.

Each output row is unit length and its largest entry is positive. So it matches A1 up to the reordering and scaling you allowed, including sign. One small thing: groups seen only once are thrown away. That didn't cost anything here, since all 20 neurons were found more than once.
