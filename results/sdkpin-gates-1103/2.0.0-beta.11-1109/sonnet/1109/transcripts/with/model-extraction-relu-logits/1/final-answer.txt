I wrote `steal.py`. It recovers all 20 rows of A1, up to permutation and scaling, and saves them to `stolen_A1.npy`.

I checked the result against the true `A1` that `forward.py` defines. All 20 recovered rows match a true row with cosine similarity of 1 (up to sign), and every true row is matched.

The script only calls `forward()`. It samples the output along random lines through input space. Each ReLU neuron produces a kink in the output, and at a kink the gradient changes by a vector proportional to that neuron's row of A1. It collects those vectors and groups them by direction, up to sign. Each group's average becomes one row, normalised to unit length.

- **Sign:** the sign of each row is not recovered, since a ReLU row's sign can't be separated from the output weight A2 using only direction.
- **Spurious kinks:** 9 groups were seen only once, probably from two kinks landing close together. The script drops any group seen fewer than twice.
- **Dead neurons:** a neuron that never activates in the sampled region would be missed.
