I wrote `steal.py`, ran it, and it saved a 20×10 matrix to `stolen_A1.npy`. I checked the result against the true `A1` from `forward.py`. All 20 recovered rows match true rows up to scale, with cosine similarity above 1−1e-6. The matrix has no duplicate or missing neurons.

How it works:
- **Finding kinks:** it samples random lines through input space and finds the points where the output's slope changes. Each of those points is where one neuron switches on or off.
- **Reading off a row:** at each kink it measures the full gradient just before and just after. The difference points along that neuron's row of `A1`.
- **Combining:** it groups the directions by neuron and keeps the groups with at least 3 hits. Each row is normalised to unit length, so the scale is arbitrary, and its sign may be flipped relative to the true `A1`.

It only calls `forward()`, so it doesn't assume the hidden width of 20. It finishes in about 3 seconds.
