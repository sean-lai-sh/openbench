All 25 tests pass now. I found these root causes:

- **`queue.py`**: `sort_key` was `(seq, -priority)`. It is now `(-priority, seq)`.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`.
- **`events.py`**: `_prefix_matches` had the arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priority to be non-decreasing. It now requires non-increasing, as the docstring says.
- **`config.py`**: `deep_merge` recursed with `(override, base)` swapped, so the base values won over the overrides. It now recurses with `(base, override)`.
- **`scheduler.py`**: `_cascade_skip` skipped only direct dependents. It now skips all transitive dependents, in pipeline order.
