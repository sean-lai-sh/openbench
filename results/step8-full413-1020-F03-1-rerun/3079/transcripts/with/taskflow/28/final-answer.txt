`python3 -m unittest` now passes all 25 tests. I didn't edit any tests.

These are the defects I fixed:

- **`queue.py`:** the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` stopped one attempt early. It now retries while `attempts_made < max_attempts`.
- **`events.py`:** the prefix match had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` had its comparison backwards. It now requires the current priority to be less than or equal to the previous one.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`, which leaked capacity.
- **`config.py`:** `deep_merge` swapped its base and override arguments when recursing into nested mappings. That made defaults override a task's own retry settings.
- **`scheduler.py`:** the skip cascade used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so everything downstream of a failed task is skipped.
