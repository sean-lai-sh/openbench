`python3 -m unittest` now passes all 25 tests. I fixed seven bugs and didn't touch the tests.

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` was off by one (`attempts_made < max_attempts - 1`). It is now `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. It now requires non-increasing, which matches its docstring.
- **`resources.py`:** `ResourcePool.release` always subtracted 1 instead of `cost`. It now subtracts `cost`.
- **`config.py`:** `deep_merge` recursed with the base and override swapped, so defaults overrode task settings. It now recurses with `deep_merge(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so everything downstream of a permanent failure is skipped.
