All 25 tests now pass. I fixed eight bugs, one line each:

- **`queue.py`:** the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority dispatches first and ties go FIFO.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It is now `attempts_made < max_attempts`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`. Pools never freed their full capacity, so tasks blocked.
- **`statemachine.py`:** `batch_order_ok` had its comparison reversed. It now requires `current <= prev`, which is non-increasing priority within a batch.
- **`scheduler.py`:** `_cascade_skip` used the direct `dependents`. It now uses `transitive_dependents`, so every downstream task gets skipped.
- **`config.py`:** `deep_merge` recursed with the base and override swapped, so defaults overrode the task's own values. It now calls `deep_merge(result[key], value)`.
- **`events.py`:** `_prefix_matches` checked `prefix.startswith(topic + ".")` backwards. It now checks `topic.startswith(prefix + ".")`. Before this fix, `History` never received any `job.term.*` events.

I didn't change any tests.
