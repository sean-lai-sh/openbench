`python3 -m unittest` now passes: 25 tests, all OK. I didn't modify any tests.

There were seven defects, each a one-line fix:

- **`queue.py`**: `_Entry.sort_key` ordered by `(seq, -priority)`. It now orders by `(-priority, seq)`, so higher priority dispatches first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which cut the retry budget by one. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`**: `batch_order_ok` required priority to be non-decreasing within an admission batch. The docstring says non-increasing, so it now returns `current_priority <= prev_priority`.
- **`events.py`**: `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`, so a prefix subscription receives its whole subtree.
- **`resources.py`**: `ResourcePool.release` always did `used -= 1`. It now does `used -= cost`.
- **`config.py`**: `deep_merge` recursed as `deep_merge(value, result[key])`, which let the defaults override a task's own settings. It now recurses as `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `dag.transitive_dependents`, so every downstream task is skipped.
