All 25 tests now pass. I fixed seven bugs in `taskflow/`:

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priorities within a batch to rise. It now requires them not to rise (`current <= prev`), as its docstring says.
- **`config.py`:** `deep_merge` recursed with `(override, base)` swapped, so the pipeline defaults overrode a task's own settings. It now recurses with `(base, override)`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`, so pools leaked capacity.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.
