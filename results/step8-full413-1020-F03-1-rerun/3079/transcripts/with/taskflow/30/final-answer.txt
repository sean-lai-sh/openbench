`python3 -m unittest` now passes all 25 tests. I fixed seven defects and didn't touch the tests.

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority is dispatched first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priorities to be non-decreasing within a batch. It now requires non-increasing, as its docstring says.
- **`resources.py`**: `ResourcePool.release` always subtracted 1 unit, whatever the cost. It now subtracts `cost`, so a task holding more than one unit no longer leaves usage stuck above zero.
- **`config.py`**: `deep_merge` passed its arguments in the wrong order when recursing into nested dicts, so the base values overrode the task's own. A per-task `retry` override lost to the defaults. The base now goes first and the override second.
- **`scheduler.py`**: `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.
