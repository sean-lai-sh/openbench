All 25 tests now pass. I fixed these six defects:

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` checked for non-decreasing priority. It now checks `current <= prev`, which matches the "non-increasing within a batch" rule in its docstring.
- **`resources.py`:** `ResourcePool.release` did `used -= 1`. It now does `used -= cost`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so defaults overrode a task's own values. It now recurses as `deep_merge(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so every downstream task gets skipped.

I didn't modify any tests.
