All 25 tests now pass. I fixed seven bugs and left the tests untouched:

- **`queue.py`**: `sort_key` ordered by `(seq, -priority)`. It now orders by `(-priority, seq)`.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priority to rise within a batch, which contradicts its own docstring. It now requires it to be non-increasing.
- **`config.py`**: `deep_merge` recursed with the base and override swapped, so the defaults overwrote task overrides. The arguments are now in the right order.
- **`scheduler.py`**: `_cascade_skip` skipped only direct dependents. It now uses `transitive_dependents`.
- **`resources.py`**: `ResourcePool.release` always subtracted 1 instead of `cost`. It now subtracts `cost`.
