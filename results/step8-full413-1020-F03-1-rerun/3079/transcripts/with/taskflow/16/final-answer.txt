`python3 -m unittest` now passes all 25 tests. I didn't modify any tests.

I fixed seven defects. Each one was a place where the code did something different from what its docstring said:

- **`queue.py`**: `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had the arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priority to be non-decreasing within an admission batch. It now requires non-increasing, as documented.
- **`resources.py`**: `ResourcePool.release` did `used -= 1` regardless of cost. It now does `used -= cost`.
- **`scheduler.py`**: `_cascade_skip` skipped only direct dependents. It now uses `transitive_dependents`.
- **`config.py`**: `deep_merge` recursed with `(override, base)` swapped, so the pipeline defaults overwrote per-task overrides. It now recurses with `(base, override)`.
