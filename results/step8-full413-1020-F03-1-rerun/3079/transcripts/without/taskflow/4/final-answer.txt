`python3 -m unittest` now passes all 25 tests. I didn't edit any tests. These are the seven fixes:

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority comes first and ties break FIFO.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had the prefix and topic the wrong way round. It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`:** `ResourcePool.release` always subtracted 1. It now subtracts `cost`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. It now requires non-increasing, as the docstring says.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own values. It now recurses with `(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so every downstream task is skipped.
