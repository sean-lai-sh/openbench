`python3 -m unittest` now passes all 25 tests. I changed these files under `taskflow/`:

- **`queue.py`:** `_Entry.sort_key` was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which dropped the last allowed attempt. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had the arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within an admission batch. It now requires non-increasing.
- **`config.py`:** `deep_merge` recursed as `deep_merge(override, base)` for nested dicts, so the defaults overwrote a task's own `retry` settings. The arguments are now in the right order.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `transitive_dependents`, so everything downstream of a permanent failure is skipped.
- **`resources.py`:** `ResourcePool.release` always subtracted 1 instead of `cost`, which leaked capacity and stalled the resource-limited pipelines. It now subtracts `cost`.

I stopped once the suite was green and didn't read the other modules, such as `history.py`, for bugs the tests don't exercise.
