All 25 tests now pass. I made six fixes:

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`. It now uses `attempts_made < max_attempts`, which fixes the off-by-one in the retry count.
- **`events.py`**: `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`. It now subtracts `cost`.
- **`statemachine.py`**: `batch_order_ok` compared the wrong way round. A batch must be non-increasing in priority, so it now returns `current <= prev`.
- **`config.py`**: `deep_merge` swapped its arguments when recursing, so the base value overrode the task's own value. It now recurses with `(base, override)`.

I also changed `scheduler.py`'s `_cascade_skip` to use `dag.transitive_dependents`. It was using the direct `dependents`, so only a failed task's immediate children were skipped, not everything downstream.
