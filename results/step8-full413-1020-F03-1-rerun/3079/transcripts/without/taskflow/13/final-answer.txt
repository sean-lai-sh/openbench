All 25 tests now pass. I found and fixed these seven defects:

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority runs first and ties go FIFO.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had the arguments reversed (`prefix.startswith(topic + ".")`). It now uses `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. It now requires non-increasing (`current <= prev`), as the docstring says.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the base overrode the task. It now calls `deep_merge(result[key], value)`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`, which leaked capacity.
- **`scheduler.py`:** `_cascade_skip` used the direct `dag.dependents`, so only children were skipped. It now uses `dag.transitive_dependents`.
