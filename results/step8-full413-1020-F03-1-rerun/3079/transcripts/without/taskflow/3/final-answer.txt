`python3 -m unittest` now passes all 25 tests. I fixed these defects:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority comes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` was off by one (`attempts_made < max_attempts - 1`). It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priority to be non-decreasing within an admission batch. It now requires non-increasing (`current <= prev`).
- **`resources.py`**: `ResourcePool.release` always subtracted 1 unit. It now subtracts `cost`.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so base values overrode the overrides. It now calls `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so the whole downstream chain is skipped.

I didn't modify any tests.
