`python3 -m unittest` now passes all 25 tests. I didn't touch the tests. I fixed seven defects, all in `taskflow/`:

- **`queue.py`:** `_Entry.sort_key` was `(seq, -priority)`. It's now `(-priority, seq)`, so higher priority goes first and insertion order only breaks ties.
- **`retry.py`:** `should_retry` was off by one, so a task with `max_attempts=3` got only 2 attempts. It now returns `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` returned true for rising priority. It now returns `current <= prev`, matching the non-increasing rule in its docstring.
- **`config.py`:** `deep_merge` recursed with the base and override swapped, so defaults overwrote a task's own `retry` settings. It now uses `deep_merge(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so skips reach the whole downstream chain.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`. Multi-unit resources leaked and later tasks were never admitted.
