`python3 -m unittest` now passes all 25 tests. I fixed these seven defects, all under `taskflow/`:

- **`queue.py`:** `_Entry.sort_key` ordered by `(seq, -priority)`. It now orders by `(-priority, seq)`, so higher priority goes first and ties are FIFO.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`. It now uses `attempts_made < max_attempts`, so `max_attempts=3` allows retries after attempts 1 and 2, as the docstring says.
- **`events.py`:** `_prefix_matches` checked `prefix.startswith(topic + ".")`, which is backwards. It now checks `topic.startswith(prefix + ".")`.
- **`config.py`:** `deep_merge` recursed with the base and override swapped. It now calls `deep_merge(result[key], value)`, so overrides win at nested keys.
- **`statemachine.py`:** `batch_order_ok` used `>=`. The batch guard is meant to require non-increasing priority, so it now uses `<=`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` regardless of cost. It now does `used -= cost`.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.

I didn't modify any tests.
