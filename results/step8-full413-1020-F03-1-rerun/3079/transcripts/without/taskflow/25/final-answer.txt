`python3 -m unittest` now passes all 25 tests. I fixed seven bugs, and I didn't touch the tests.

- **`queue.py`:** the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` had an off-by-one (`attempts_made < max_attempts - 1`). It is now `attempts_made < max_attempts`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 unit instead of `cost`. That left pools stuck as full.
- **`events.py`:** `_prefix_matches` had its arguments swapped. It now checks `topic.startswith(prefix + ".")`.
- **`config.py`:** `deep_merge` recursed as `deep_merge(value, result[key])`, which let the base override the override. It now recurses as `deep_merge(result[key], value)`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing. It now requires non-increasing, as the docstring says.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`.
