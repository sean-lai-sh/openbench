All 25 tests now pass. I fixed these seven defects:

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority dispatches first and ties go FIFO.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`events.py`**: the prefix match had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`**: `ResourcePool.release` always subtracted 1. It now subtracts `cost`.
- **`statemachine.py`**: the batch-ordering guard `batch_order_ok` was inverted. It now requires `current_priority <= prev_priority`, matching its docstring ("non-increasing priority").
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own settings. It now recurses as `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`.
