All 25 tests now pass. I fixed these defects:

- **`queue.py`**: `sort_key` was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
- **`retry.py`**: `should_retry` had an off-by-one. It is now `attempts_made < max_attempts`.
- **`resources.py`**: `ResourcePool.release` always subtracted 1. It now subtracts `cost`.
- **`events.py`**: `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so base values overrode task values. It now calls `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `transitive_dependents`.
- **`statemachine.py`**: `batch_order_ok` had its comparison reversed. It now returns `current_priority <= prev_priority`, as the docstring describes.

I didn't modify any tests.
