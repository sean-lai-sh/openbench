All 25 tests now pass. I made seven one-line fixes, and I didn't touch the tests.

- **`queue.py`:** `sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It is now `attempts_made < max_attempts`, matching the docstring.
- **`events.py`:** `_prefix_matches` had the arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1`, so any multi-unit cost leaked capacity. It now subtracts `cost`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. The docstring says non-increasing, so the comparison is now `current <= prev`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own values. It now merges `(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so everything downstream of a permanent failure is skipped.
