## Root cause
**`settings.json:2`** has a misspelled key:
```json
"rat": 0.5,
```
`main.py` looks the rate up under a different name, **`main.py:10-13`**:
```python
try:
    rate = cfg["fee_rate"]
except KeyError:
    rate = 0
```

## Why the total is wrong
`app/config.py:9-10` loads `settings.json` into `SETTINGS` as written, so the dict has `"rat"` and no `"fee_rate"`. The lookup `cfg["fee_rate"]` raises `KeyError`, and the `except` block quietly sets `rate = 0`. The total becomes `0 * 10 = 0`. Because the missing key is covered up instead of reported, a config typo shows up as a believable but wrong total.

## Suggested fix
- **Main fix:** rename the key in `settings.json` from `"rat"` to `"fee_rate"`.
- **Optional hardening:** remove the silent fallback to 0 in `main.py:12-13` so a missing key raises an error. `billing/report.py:7-9` already does this: it exits with `"fee_rate is missing"`.
