All 25 tests pass now (`Ran 25 tests ... OK`), and no test files were changed.

The fixes, one per file in `taskflow/`:

1. **`queue.py`**: Queue sorting is fixed so higher-priority tasks come out first, and tasks with equal priority come out in the order they were added.
2. **`retry.py`**: `should_retry` was stopping one attempt short of `max_attempts`; it now allows all of them.
3. **`resources.py`**: `release` now gives back the full cost of a task instead of always 1.
4. **`statemachine.py`**: `batch_order_ok` had the comparison backwards. It now requires priority to stay the same or go down within a batch.
5. **`events.py`**: The topic prefix check was reversed. It now asks whether the topic starts with the prefix, not the other way round.
6. **`config.py`**: In nested merges, values from the base config were overwriting the override values. Override values now win.
7. **`scheduler.py`**: When a task fails, the scheduler now skips every task downstream of it, not just the tasks that depend on it directly.
