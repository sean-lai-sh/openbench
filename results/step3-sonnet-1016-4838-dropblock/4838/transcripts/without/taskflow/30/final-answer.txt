All 25 tests now pass. I didn't modify the tests.

I fixed seven bugs in total. Each one contradicted its own docstring:

| File | Bug | Fix |
|---|---|---|
| `queue.py` | `sort_key` was `(seq, -priority)` | Now `(-priority, seq)` |
| `retry.py` | `should_retry` used `max_attempts - 1` | Now compares against `max_attempts` |
| `events.py` | `_prefix_matches` had its arguments reversed | Now `topic.startswith(prefix + ".")` |
| `statemachine.py` | `batch_order_ok` compared priorities the wrong way | Now requires non-increasing priority |
| `config.py` | `deep_merge` recursed with its arguments swapped | Now `deep_merge(result[key], value)` |
| `scheduler.py` | `_cascade_skip` used `dependents`, which returns only direct children | Now uses `transitive_dependents` |
| `resources.py` | `ResourcePool.release` did `used -= 1` | Now `used -= cost` |

The last one caused the three remaining failures. Each task released only one unit instead of its full cost, so tasks that needed the whole pool never got admitted again.
