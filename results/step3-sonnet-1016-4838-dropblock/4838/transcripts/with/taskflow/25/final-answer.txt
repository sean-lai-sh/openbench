All 25 tests pass, so there's nothing left to do.

The seven fixes are all in `taskflow/`, and I didn't change any tests:

1. `queue.py`: the sort key is now `(-priority, seq)`, so higher priority runs first and ties go in FIFO order.
2. `retry.py`: `should_retry` had an off-by-one and now uses `attempts_made < max_attempts`.
3. `events.py`: `_prefix_matches` had its operands reversed. It now checks `topic.startswith(prefix + ".")`.
4. `statemachine.py`: `batch_order_ok` now requires non-increasing priority. The queue ordering bug had been hiding this one.
5. `config.py`: `deep_merge` now lets the override win in nested merges.
6. `resources.py`: `release` now subtracts `cost` instead of 1.
7. `scheduler.py`: `_cascade_skip` now uses `transitive_dependents`, so skips reach indirect dependents too.
