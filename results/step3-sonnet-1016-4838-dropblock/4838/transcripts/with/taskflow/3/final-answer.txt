## Fixes (all under `taskflow/`)
1. `queue.py`: the sort key is now `(-priority, seq)`. Higher priority comes first, and ties go in FIFO order.
2. `retry.py`: `should_retry` now uses `attempts_made < max_attempts`. It previously used `max_attempts - 1`, which was off by one.
3. `events.py`: `_prefix_matches` now checks `topic.startswith(prefix + ".")`. The arguments were reversed.
4. `statemachine.py`: `batch_order_ok` now requires priority to be non-increasing within a batch.
5. `config.py`: `deep_merge` now recurses as `deep_merge(result[key], value)`. The override value was previously the base.
6. `scheduler.py`: `_cascade_skip` now uses `transitive_dependents`, so a failure skips all downstream jobs and not only direct children.
7. `resources.py`: `ResourcePool.release` now does `self.used -= cost` instead of `-= 1`. Multi-unit tasks were leaking capacity. Later tasks were never admitted, which made the three pipeline tests fail.
