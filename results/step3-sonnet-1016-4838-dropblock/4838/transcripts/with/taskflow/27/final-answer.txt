The last bug was in `taskflow/scheduler.py`. `_cascade_skip` looped over `self.dag.dependents(...)`, which only returns direct children. I changed it to `self.dag.transitive_dependents(...)`, so every downstream task is skipped. That function does a breadth-first walk, so the skip order is deterministic. I read `transitive_dependents` and found nothing wrong with it.
