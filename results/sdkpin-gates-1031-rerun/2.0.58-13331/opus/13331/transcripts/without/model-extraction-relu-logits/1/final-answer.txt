I wrote `steal.py` and ran it. It found 20 hidden neurons and saved a 20×10 matrix to `stolen_A1.npy` in about 0.6 seconds.

To check it, I compared the result against the real `A1` inside `forward.py`, which the script itself never reads. All 20 real neurons match exactly one recovered row each, with cosine similarity 1.0000000. The signs also came out positive, so the result really is `A1` with its rows reordered and rescaled. I've only run it on this one network.

**How it works:**
1. **Find where neurons switch on or off.** The script draws random straight lines through the 10-dimensional input space. Along each line the output is made of straight segments, and it bends wherever a neuron turns on or off. A recursive search finds each bend by fitting lines and checking where they meet.
2. **Recover each neuron's direction.** At each bend, it estimates the gradient just before and just after by small finite differences. The difference between the two is proportional to that neuron's row of `A1`, so it normalises it and removes duplicates. It stops once 15 lines in a row turn up no new neurons.
3. **Fix the signs.** Step 2 only gives each row up to a factor of ±1. To settle this, the script fits the network's output with least squares using the hyperplanes it found. Because a ReLU network has no separate linear term, any linear part left over in the fit shows which rows point the wrong way. It tries every combination of flips (fast enough for up to 22 neurons) to find which rows to flip.

Run it with `python steal.py`; it prints the matrix and writes `stolen_A1.npy` next to the script.
