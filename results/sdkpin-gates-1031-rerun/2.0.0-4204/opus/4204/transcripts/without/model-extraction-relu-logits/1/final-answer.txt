I wrote `steal.py`, ran it, and it recovered all 20 hidden neurons, saved as a 20×10 matrix in `stolen_A1.npy`. The run took 16,420 queries.

To check the result, I compared it with the real `A1` stored in `forward.py`; the script itself only calls `forward()`. Every recovered row points in the same direction as one of the real rows (cosine similarity 0.99999999), and every real row is matched. So the matrix equals `A1` up to the order of the neurons and a scale factor on each row.

**How it works:**
1. **Find the kinks.** Along a straight line through input space, the network's output is a series of straight segments, with a bend wherever one hidden neuron switches on or off. The script picks random lines (spanning t from -100 to 100) and searches each one by splitting intervals in half until it pins down every bend.
2. **Read off each neuron's weights.** At each bend it estimates the gradient just before and just after (by nudging each input slightly). The difference between the two is that neuron's row of `A1`, multiplied by its output weight. Normalising gives the row up to scale and sign.
3. **Remove duplicates and stop.** A new direction counts as a new neuron only if it isn't nearly parallel to one already found (|cos| > 0.9999). The script stops after 15 lines in a row turn up nothing new.

Each row is scaled to length 1, and its sign is flipped so its largest entry is positive. A neuron that never switches on or off for any input couldn't be found by this method, but that wasn't an issue for this network.
