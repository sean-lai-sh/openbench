Root cause: the settings key is misspelled (`rat` instead of `rate`), so `get("rate")` returns None.


Fixed. `settings.json` had a typo, `"rat"` instead of `"rate"`. That made `SETTINGS.get("rate")` return `None`, which caused the `TypeError`. I renamed the key, and `python3 main.py` now prints `Total: 5.0`.
