All 25 tests now pass with `python3 -m unittest`. I didn't modify any tests. I ran only the tests; there was no lint or typecheck command to run.

I fixed these seven bugs:

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties break FIFO.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`:** `batch_order_ok` had its comparison reversed. It now requires `current_priority <= prev_priority`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own settings. It now calls `deep_merge(result[key], value)`.
- **`events.py`:** `_prefix_matches` tested `prefix.startswith(topic + ".")` backwards. It now tests `topic.startswith(prefix + ".")`, which is what lets `History` receive the `job.term.*` events.
- **`resources.py`:** `ResourcePool.release` did `self.used -= 1` instead of subtracting the cost. Pools leaked capacity, which caused the resource-test failures.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`, so the whole downstream chain is skipped.
