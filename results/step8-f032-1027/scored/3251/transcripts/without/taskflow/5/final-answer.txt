All 25 tests now pass. I found eight bugs, fixed in this order:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`**: `batch_order_ok` had its comparison reversed. A batch must dispatch in non-increasing priority order, so it now checks `current <= prev`.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`, which leaked capacity and stalled the resource-limited runs.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own settings. It now recurses with `(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so the whole downstream chain is skipped.
- **`events.py`**: `_prefix_matches` had the `startswith` check backwards. Prefix subscriptions such as `job.term` never matched `job.term.failed`, so history never recorded terminal outcomes.

I didn't change any tests.
