All 25 tests now pass. I fixed seven bugs; the test names often pointed at the wrong module.

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`:** `batch_order_ok` had its comparison backwards. It now requires the current priority to be less than or equal to the previous one. With the queue fixed, the old check would have failed every multi-priority batch.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own settings. It now recurses as `deep_merge(result[key], value)`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`. Any task holding more than one unit of a pool leaked capacity, which stalled the resource tests.
- **`scheduler.py`:** `_cascade_skip` used the direct `dag.dependents`, so only children were skipped. It now uses `dag.transitive_dependents`, which skips every downstream task.
- **`events.py`:** `_prefix_matches` tested `prefix.startswith(topic + ".")`, the wrong way round. It now tests `topic.startswith(prefix + ".")`. Because of this, `History` never received `job.term.*` events, so its failed, skipped and succeeded lists were empty.
