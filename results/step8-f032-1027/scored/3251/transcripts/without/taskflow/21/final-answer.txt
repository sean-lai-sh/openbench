`python3 -m unittest` now passes all 25 tests. I didn't touch the tests. These are the seven fixes:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` was off by one, using `attempts_made < max_attempts - 1`. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`, so the `job.term` subscription gets `job.term.*` events.
- **`statemachine.py`**: `batch_order_ok` required priority to be non-decreasing within a batch. The docstring and the queue ordering both say non-increasing, so it now checks `current <= prev`.
- **`resources.py`**: `ResourcePool.release` did `used -= 1` instead of `used -= cost`, which leaked capacity for any task costing more than 1.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so defaults overrode task settings. It now recurses with `(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so the whole downstream chain is skipped.
