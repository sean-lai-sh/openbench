All 25 tests now pass. I found seven bugs and fixed each at its source, without touching the tests:

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties are FIFO.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so defaults overrode the task's own values. It now merges `result[key]` with `value`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of subtracting the cost. It now does `used -= cost`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within an admission batch, the opposite of the documented rule. It now requires non-increasing priority.
- **`scheduler.py`:** `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a failed task is skipped.
- **`events.py`:** `_prefix_matches` had the startswith check inverted, so prefix subscriptions never matched subtopics like `job.term.failed`. It now checks `topic.startswith(prefix + ".")`. This is why the history's failed and skipped sets came back empty.
