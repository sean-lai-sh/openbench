`python3 -m unittest` now passes all 25 tests. I fixed these defects without touching the tests:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority dispatches first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priorities to be non-decreasing. It now requires non-increasing, as the docstring says.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`, so pools never fully freed. That blocked the resource-limited runs.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own settings. It now recurses with `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` used the direct `dependents`, so only immediate children were skipped. It now uses `transitive_dependents`.
