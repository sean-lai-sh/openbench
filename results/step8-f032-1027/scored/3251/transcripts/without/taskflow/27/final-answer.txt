`python3 -m unittest` now passes all 25 tests. I didn't touch the tests.

I fixed seven defects:

- **`queue.py`:** `_Entry.sort_key` ordered by `(seq, -priority)`. It now orders by `(-priority, seq)`, so higher priority comes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` had an off-by-one (`< max_attempts - 1`). It is now `< max_attempts`.
- **`events.py`:** `_prefix_matches` had the prefix and topic the wrong way round. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required non-decreasing priority. The docstring says non-increasing, so it now checks `current <= prev`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`.
- **`config.py`:** `deep_merge` swapped base and override when recursing into nested dicts, so the defaults overrode the task's own values. It now merges the override on top of the base.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `transitive_dependents`, so everything downstream of a failed task is skipped.
