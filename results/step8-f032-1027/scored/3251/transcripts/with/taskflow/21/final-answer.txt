`python3 -m unittest` now passes all 25 tests. I fixed six defects, and I didn't touch the tests.

- **`queue.py`**: the sort key was `(seq, -priority)`, which ordered by insertion first. It is now `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had the prefix and topic the wrong way round. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priorities to rise within a batch. It now requires `current <= prev`, so they must not rise.
- **`config.py`**: `deep_merge` swapped base and override in its recursive call, so defaults overrode the task's own nested values. It now recurses with `deep_merge(result[key], value)`.
- **`resources.py`**: `ResourcePool.release` did `self.used -= 1` instead of `-= cost`. This leaked capacity and left jobs stuck.
- **`scheduler.py`**: `_cascade_skip` used the direct dependents only. It now uses `dag.transitive_dependents`, so the whole downstream chain is skipped.

I didn't make any changes beyond what the failing tests needed.
