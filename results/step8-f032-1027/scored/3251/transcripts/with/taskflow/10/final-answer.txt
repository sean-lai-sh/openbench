`python3 -m unittest` now passes all 25 tests. I fixed seven bugs, and I didn't touch the tests:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority dispatches first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which cut the budget short by one attempt. It now uses `attempts_made < max_attempts`.
- **`config.py`**: `deep_merge` recursed with the arguments swapped, so the defaults overrode the task's own values. It now merges `(base_child, override_child)`.
- **`events.py`**: `_prefix_matches` had the prefix check backwards. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priorities to go up within a batch. It now requires `current <= prev`, as the docstring says.
- **`resources.py`**: `ResourcePool.release` always subtracted 1 instead of `cost`, so multi-unit resources leaked and later tasks never ran. It now subtracts `cost`.
- **`scheduler.py`**: `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`.

I didn't check the modules the tests don't cover for similar defects.
