All 25 tests now pass with `python3 -m unittest`. I didn't touch the tests. I found seven bugs and fixed each one:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority runs first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`**: `batch_order_ok` had its comparison reversed. It now requires the current priority to be less than or equal to the previous one within an admission batch.
- **`config.py`**: `deep_merge` recursed with the arguments swapped, so the base overrode the override. It now calls `deep_merge(result[key], value)`.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`.
- **`events.py`**: `_prefix_matches` tested `prefix.startswith(topic + ".")`, which is backwards. It now tests `topic.startswith(prefix + ".")`, so `job.term` matches `job.term.failed`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so the whole downstream chain is skipped.
