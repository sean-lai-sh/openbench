All 25 tests now pass with `python3 -m unittest`. I didn't modify any tests.

I found and fixed these root causes:
- **`queue.py`:** `sort_key` was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority runs first and ties go in FIFO order.
- **`retry.py`:** `should_retry` was off by one. It is now `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` had its comparison inverted. It now requires non-increasing priority within a batch.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`.
- **`config.py`:** `deep_merge` swapped base and override when recursing, so a task's nested retry override lost to the defaults.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`.
