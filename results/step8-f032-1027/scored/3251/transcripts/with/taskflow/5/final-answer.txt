All 25 tests now pass under `python3 -m unittest`. I fixed seven defects and didn't touch the tests.

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority comes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`**: `batch_order_ok` had its comparison reversed. It now requires each task admitted in a batch to have priority less than or equal to the one before it.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`, so multi-unit resources leaked and later tasks never got admitted.
- **`scheduler.py`**: `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`, so a permanent failure skips everything downstream.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own values. This was why a task's `retry.max_attempts` was ignored.
- **`events.py`**: `_prefix_matches` tested `prefix.startswith(topic + ".")` instead of `topic.startswith(prefix + ".")`. `job.term.*` events never reached the history, so `failed_jobs`, `skipped_jobs` and `outcome_counts` came back empty.
