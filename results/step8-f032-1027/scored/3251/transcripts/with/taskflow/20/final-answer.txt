All 25 tests now pass with `python3 -m unittest`. I didn't touch the tests. I fixed these seven defects:

1. **`queue.py`**: `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
2. **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave one retry too few. It now uses `attempts_made < max_attempts`.
3. **`config.py`**: `deep_merge` recursed with the arguments swapped, so the defaults overrode the task's own nested values. It now recurses with `(base, override)`.
4. **`resources.py`**: `ResourcePool.release` did `used -= 1` instead of subtracting the cost. Pools never fully freed, so resource-limited pipelines stalled.
5. **`statemachine.py`**: `batch_order_ok` had its comparison backwards. It now requires non-increasing priority within an admission batch.
6. **`scheduler.py`**: `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so the whole downstream chain is skipped.
7. **`events.py`**: `_prefix_matches` had the prefix and topic swapped, so `job.term` subscribers never received `job.term.failed` and the like. History's succeeded/failed/skipped sets stayed empty until this was fixed.
