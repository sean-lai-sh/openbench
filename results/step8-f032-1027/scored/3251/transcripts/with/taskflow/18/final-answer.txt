All 25 tests now pass. I fixed seven bugs, and I didn't modify any tests.

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which was off by one. It now uses `attempts_made < max_attempts`.
- **`config.py`:** `deep_merge` swapped its arguments when it recursed, so the defaults overrode the task's own values. It now recurses with `(result[key], value)`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`, which leaked capacity. It now subtracts `cost`.
- **`statemachine.py`:** `batch_order_ok` had its comparison reversed. It now requires the current priority to be less than or equal to the previous one.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `transitive_dependents`, so skips reach the whole downstream chain.
- **`events.py`:** `_prefix_matches` had its arguments swapped, so `job.term` subscribers never received `job.term.failed` and the like. It now checks `topic.startswith(prefix + ".")`. This was why the history terminal sets and outcome counts came back empty.
