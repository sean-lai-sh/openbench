All 25 tests now pass. I found these defects and fixed each at its source:

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` had an off-by-one and stopped retrying one attempt early. It now returns `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments swapped. It now uses `topic.startswith(prefix + ".")`, so a prefix subscription matches its own subtree.
- **`statemachine.py`**: `batch_order_ok` had its comparison inverted. It now requires `current <= prev`, which is the non-increasing priority order the docstring describes.
- **`resources.py`**: `ResourcePool.release` always subtracted 1 instead of `cost`. It now subtracts `cost`.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so defaults overrode task settings. It now merges as `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.
