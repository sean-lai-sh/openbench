All 25 tests pass now. I fixed seven bugs and didn't touch the tests.

- **`queue.py`:** the sort key was `(seq, -priority)`. It's now `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which retried one time too few. It's now `attempts_made < max_attempts`.
- **`statemachine.py`:** `batch_order_ok` checked `current >= prev`. The docstring says priority must be non-increasing within a batch, so it's now `current <= prev`.
- **`scheduler.py`:** `_cascade_skip` iterated over direct dependents only. It now uses `transitive_dependents`, so the whole downstream chain is skipped.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own values. It now merges `(result[key], value)`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1`. It now subtracts `cost`.
- **`events.py`:** `_prefix_matches` had the prefix test reversed. It now checks `topic.startswith(prefix + ".")`, so `job.term` subscribers receive `job.term.failed`.
