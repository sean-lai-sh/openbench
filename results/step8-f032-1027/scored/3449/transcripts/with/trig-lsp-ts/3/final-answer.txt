I couldn't run `tsc` to confirm the fix, because TypeScript isn't installed. There is no `node_modules` directory and no global `tsc`.

The error was in `src/index.ts`, where `label` was declared as a `string` but assigned the number `8417`. I changed it to the string `"8417"`:

```ts
export const label: string = "8417"
```

I kept the `string` annotation and quoted the value. If you wanted a number, change the annotation to `number` and leave the value unquoted.

To verify, run `npm install --save-dev typescript` and then `node node_modules/typescript/bin/tsc --noEmit`. I didn't install it myself because that would add a dependency to `package.json`.
