I fixed the type error in `src/index.ts`. `label` was declared as a `string` but assigned the number `8417`, so I changed it to the string `"8417"`:

```ts
export const label: string = "8417"
```

`typescript` wasn't installed, so the `tsc` command couldn't run at first. I ran `npm i --no-save typescript`, which added `node_modules` without changing `package.json`. After that, `node node_modules/typescript/bin/tsc --noEmit` passes.

If you'd rather keep the value as a number, change the type to `number` instead.
