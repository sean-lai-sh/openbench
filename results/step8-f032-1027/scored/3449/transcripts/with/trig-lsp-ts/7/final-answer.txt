I fixed the type error in `src/index.ts`, but I couldn't run `tsc` to confirm it. TypeScript isn't installed here: there's no `node_modules` directory and no global `tsc`.

The error was that `label` was declared as `string` but assigned the number `8417`. I changed the value to a string:

```ts
export const label: string = "8417"
```

I picked this over changing the type to `number` because the declared type is `string` and nothing else in the project uses `label`. If you want a number, change the annotation to `number` and keep the original value.

After you run `npm install typescript`, `node node_modules/typescript/bin/tsc --noEmit` should pass.
