The crash came from a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` returned `None` and `rate * count` failed. I renamed the key to `"rate"`, and `python3 main.py` now prints `Total: 5.0` and exits cleanly.

I left the code alone. `get_rate()` still returns `None` silently when the key is missing, so a similar typo would give the same confusing error. I can make it raise a clear error instead if you want.
