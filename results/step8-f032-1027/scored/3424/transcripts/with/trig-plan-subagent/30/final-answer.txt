The crash is fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

The subagent traced it to a typo in `settings.json:2`. The key was spelled `"rat"`, but `app/pricing.py:8` looks up `SETTINGS.get("rate")`. `dict.get` returns `None` for a missing key, so `compute_total` ended up multiplying `None` by an int. I confirmed this by reading the files myself.

I renamed the key to `"rate"` in `settings.json`. No code changes were needed.
