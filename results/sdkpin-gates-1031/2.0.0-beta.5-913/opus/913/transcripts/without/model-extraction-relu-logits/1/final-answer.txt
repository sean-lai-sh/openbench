**How it works:** the script only calls `forward()`. It picks random lines through the input space and searches along each one for "kinks", the points where the output stops changing in a straight line because one neuron is switching on or off. At each kink, it measures the slope of the output just before and just after. The difference between the two points in the same direction as that neuron's row of A1. It then merges duplicate directions and keeps only those it found at least twice.

**Check:** to confirm the result, I compared it with the real `A1` in `forward.py` (the script itself never reads it). Each recovered row matches exactly one true row, all 20 are covered, and the agreement is essentially perfect (cosine similarity 0.9999999999999997).

**One limitation:** each row is scaled to length 1, and its sign may be flipped. Querying the output this way can't tell a neuron's direction apart from its exact opposite, so the script fixes the sign by convention rather than recovering it. If your check needs the original sign of each row, not just the same direction, this won't pass it.
