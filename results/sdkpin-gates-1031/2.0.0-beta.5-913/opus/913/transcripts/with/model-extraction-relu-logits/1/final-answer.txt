I wrote `steal.py`, and it recovers all 20 hidden neurons. When I ran it, it saved a 20×10 matrix to `stolen_A1.npy` in about 1 second, using roughly 56,000 calls to `forward()`.

To check it, I compared the result against the real `A1` in `forward.py`. Every stolen row matches exactly one real row with a cosine similarity of 1.0, and the signs come out right too. The script itself only learns about the network by calling `forward()`; I opened `forward.py` just for that check.

How it works:
1. **Find where each neuron switches on.** It picks random straight lines through input space and narrows down the exact points where the output stops changing in a straight line. Each such point is where one hidden neuron crosses from off to on.
2. **Read off that neuron's weights.** At each of those points it measures the output's slope (gradient) just before and just after. The difference points along that neuron's row of `A1`. Each row is scaled to length 1 and duplicates are dropped, stopping after 15 lines in a row turn up nothing new.
3. **Fix the signs.** The gradient at any point equals the sum of the active neurons' contributions. The script tries all 2²⁰ on/off combinations to find which neurons are on when on the "negative" side of their boundary, then flips those rows. If no combination fits, it leaves the signs as they are, so they could be wrong.

The rows of the output are scaled to length 1, so they match `A1` only up to scaling and reordering of neurons, as you asked. Run it with `python steal.py`.
