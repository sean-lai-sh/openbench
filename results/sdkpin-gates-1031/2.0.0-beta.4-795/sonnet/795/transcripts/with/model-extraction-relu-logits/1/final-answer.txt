        e = np.zeros(D)
        e[i] = EPS
        g[i] = (forward(x + e) - forward(x - e)) / (2 * EPS)
    return g


def canon(v):

- **Method:** It queries `forward()` along 40 random lines and finds the points where the output's slope changes, which are the ReLU kinks. At each kink it measures the gradient just before and just after, using finite differences. The difference is proportional to one row of A1.
- **Output format:** Rows are unit-length. The sign is fixed so the largest component is positive, so each row is A1's row up to scale and sign.
- **Spurious rows:** Six extra rows turned up in the first run, each seen only once. They come from kinks that happen to land close together, so the script drops any direction seen fewer than 3 times.
- **Assumptions and limits:** The script doesn't assume 20 hidden neurons. A neuron that never switches on or off within the sampled range (|t| ≤ 15 along each line) won't be found. That didn't happen with this network.
