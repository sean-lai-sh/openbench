**Actual output:** `Total: 0`

## Root cause

The key in the config file is misspelled.

**`settings.json:2`**
```json
"rat": 0.5,
```
The code expects the key to be `"fee_rate"`, but the file has `"rat"`. No other file defines `fee_rate`.

**Why this gives 0 instead of an error:** `main.py:10-13` catches the missing key and quietly uses 0:
```python
try:
    rate = cfg["fee_rate"]
except KeyError:
    rate = 0
```
The lookup raises `KeyError`, `rate` becomes `0`, and `0 * 10` prints `Total: 0`. `app/config.py:9-10` loads the JSON correctly, so the loader is not the problem.

**Confirmation:** The other two places that read `fee_rate` fail outright on the same missing key. I ran both with `python3 -B`, which doesn't write cache files:

- `python3 -m billing.export.csv_writer` prints `fee_rate is missing` (billing/export/csv_writer.py:8-10)
