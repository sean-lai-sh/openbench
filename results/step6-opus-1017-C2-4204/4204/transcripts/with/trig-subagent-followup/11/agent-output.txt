**Root cause**
The settings key is misspelled, and `main.py` hides the error that would have shown it.

1. `settings.json:2`:
   ```json
   "rat": 0.5,
   ```
   The key is `"rat"`, but the code looks up `"fee_rate"`.

2. `main.py:10-13`:
   ```python
   try:
       rate = cfg["fee_rate"]
   except KeyError:
       rate = 0
   ```
