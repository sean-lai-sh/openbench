## Root cause
**`settings.json:2`** spells the key as `rat` instead of `fee_rate`:
```json

```
`main.py:10-13` then looks up `fee_rate` and quietly falls back to 0 when it's missing:
```python

        rate = cfg["fee_rate"]
    except KeyError:
```
