## Root cause
**`settings.json` line 2** has the wrong key name:
```json
  "rat": 0.5,
```
**`main.py` lines 10–13** look for a different name and hide the failure:
```python
    try:
        rate = cfg["fee_rate"]
    except KeyError:
        rate = 0
```
`app/config.py:14-15` loads `settings.json` into `SETTINGS` unchanged, so nothing renames `rat` along the way.

## Why it produces the wrong result
1. Since `fee_rate` isn't in the settings, `cfg["fee_rate"]` raises a `KeyError`.
2. The `except KeyError` branch catches it and sets `rate = 0` without any warning.
3. Then `0 * 10 = 0`, so the program prints a plausible-looking but wrong total instead of failing.

Other code also expects `fee_rate`: `billing/report.py:7` and `billing/export/csv_writer.py:8` read that key and exit with "fee_rate is missing" if it's absent.
