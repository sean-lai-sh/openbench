## Root cause
**`settings.json`, line 2:**
```json
  "rat": 0.5,
```
The key is a typo. Everything that reads this file looks for `"fee_rate"`, including `main.py:11`:
```python
        rate = cfg["fee_rate"]
```

**Contributing cause, `main.py` lines 12–13:**
```python
    except KeyError:
        rate = 0
```

## Why it produces the wrong total
`app/config.py:9-10` loads `settings.json` into `SETTINGS` as-is, so the dict has `"rat"` and no `"fee_rate"`. The lookup at `main.py:11` raises `KeyError`. The `except` block quietly sets `rate = 0`, so `total = 0 * 10 = 0`. There's no error or warning, so the missing setting looks like a real total of 0.

## Suggested fix (not applied)
1. Rename the key in `settings.json` from `"rat"` to `"fee_rate"`.
2. Make `main.py` fail loudly when `fee_rate` is missing instead of defaulting to `0`. `billing/report.py` and `billing/export/csv_writer.py` already do this with `raise SystemExit("fee_rate is missing")`. That way a bad config can't produce a wrong total again.
