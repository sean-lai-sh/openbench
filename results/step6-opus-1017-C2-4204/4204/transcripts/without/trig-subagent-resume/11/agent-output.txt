## Root cause

**`rate` becomes None at `app/pricing.py:8`:**
```python
def get_rate():
    """The per-item rate configured for the service."""
    return SETTINGS.get("rate")
```
`SETTINGS` has no `"rate"` key, so `dict.get` returns `None` instead of raising an error.

**The key is misspelled in `settings.json:2`:** it's `"rat"` where the code expects `"rate"`.
```json
{
  "rat": 0.5,
  "currency": "USD",
  "label": "Total"
}
```
