## 1. What it prints vs. what it should print

- **What it prints** (from running `python3 main.py`): `Total: 0`
- **What it should print:** `Total: 5.0`

**Why 5.0:** `main.py` multiplies `rate * COUNT`, and `COUNT = 10` (`main.py:5`). The only rate value in `settings.json` is `0.5` (line 2), so the total should be 0.5 × 10 = 5.0. Nothing else in the files offers a different rate.

## 2. Root cause

**Main problem: `settings.json:2`**
```json
  "rat": 0.5,
```
The key is spelled `"rat"`, but the code reads `"fee_rate"`.

**Why it shows 0 instead of an error: `main.py:10-13`**
```python
    try:
        rate = cfg["fee_rate"]
    except KeyError:
        rate = 0
```
`app/config.py:9-10` loads `settings.json` into `SETTINGS` without checking it. When `"fee_rate"` isn't found, `main.py` quietly uses `rate = 0`, so the total becomes `0 * 10 = 0` with no warning.

Every other piece of code that reads this setting expects `fee_rate` too, which confirms the JSON file is the side that's wrong:
- `billing/report.py:7`: `get_setting("fee_rate")`
- `billing/export/csv_writer.py:8`: `settings.get("fee_" + "rate")`

Both of those would stop with `"fee_rate is missing"` right now.
