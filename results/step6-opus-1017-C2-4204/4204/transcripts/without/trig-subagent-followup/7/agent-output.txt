## Root cause
The key name in **`settings.json:2`** is wrong:
```json
  "rat": 0.5,
```
The code reads it by its full name, **`main.py:10-13`**:
```python
    try:
        rate = cfg["fee_rate"]
    except KeyError:
        rate = 0
```

## Why it gives the wrong result
`app/config.py:9-10` loads `settings.json` unchanged into `SETTINGS`. Since there is no `"fee_rate"` key, `cfg["fee_rate"]` raises `KeyError`. The `except` block catches it and sets `rate = 0`, so `total = 0 * 10 = 0` (`main.py:14`). The 0.5 rate is loaded but never used, and no error is shown.

- `billing/export/csv_writer.py:8` calls `settings.get("fee_" + "rate")`
