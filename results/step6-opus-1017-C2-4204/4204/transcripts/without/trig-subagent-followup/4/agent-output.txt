## What it prints vs. what it should print
- **Actual:** `Total: 0`
- **Expected:** `Total: 5.0`. `main.py` charges `COUNT = 10` items at the configured fee rate, and the only rate in `settings.json` is `0.5`. 0.5 × 10 = 5.0.

## Root cause
**`settings.json`, line 2**
```json
"rat": 0.5,
```
Everything that uses the settings looks for a key named `fee_rate`: `main.py:11`, `billing/report.py:7` and `billing/export/csv_writer.py:8`. Because the file says `"rat"`, there is no `fee_rate` key at all. `app/config.py:9-10` loads the JSON as-is with no checks, so `SETTINGS == {"rat": 0.5, "currency": "USD", "label": "Total"}`.

## Secondary issue (why the total is 0 instead of an error)
**`main.py`, lines 10-13**
```python
try:
    rate = cfg["fee_rate"]
except KeyError:
    rate = 0
```
When the key is missing, this falls back to `rate = 0` without any message. Line 14 then computes `0 * 10 = 0` and prints it as if it were correct. The other two scripts handle the same missing key more strictly: I ran `python3 -m billing.report` and `python3 -m billing.export.csv_writer`, and both stop with `fee_rate is missing`.
