The `subtract` bug is fixed: `python3 -m unittest` now runs all 4 tests with OK and exit code 0.

**Diagnostics:**
1. `python3 -c "print('diag ' * 8000)"` ran, but the bash tool cut the output off at its 30,000-character limit, so only part of the ~40,000 characters came back.
2. `sleep 5 && python3 -m unittest` with a 2000 ms timeout was stopped at 2 seconds, before the tests started, so it produced no test output. A 5-second sleep can't finish within that limit.

**The bug:** in `calculator.py:6`, `subtract` returned `a + b` instead of `a - b`. That made `subtract(5, 3)` return 8 where the test expects 2. I changed it to `a - b` and didn't touch the tests.
