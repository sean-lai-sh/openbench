I fixed the bug and the test suite now passes: `python3 -m unittest` runs 4 tests with exit code 0.

**What the diagnostics showed:**
1. `python3 -c "print('diag ' * 8000)"`: the bash tool cut the output off at its 30,000-character limit, so only about 30k of the 40k characters came back.
2. `sleep 5 && python3 -m unittest` with timeout 2000: the tool stopped the command after 2 seconds, during the 5-second sleep. The tests never ran in that call.

**The bug:** `subtract` in `calculator.py:6` returned `a + b` instead of `a - b`, so `subtract(5, 3)` gave 8 instead of the expected 2. I changed it to `a - b` and left the tests untouched.
