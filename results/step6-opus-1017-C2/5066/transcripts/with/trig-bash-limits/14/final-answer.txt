The bug is fixed: `subtract` in `calculator.py:6` returned `a + b` instead of `a - b`. I made it `a - b`, and `python3 -m unittest` now passes all 4 tests with exit code 0. I didn't change the tests.

**What the two diagnostics showed:**
1. **`python3 -c "print('diag ' * 8000)"`:** the bash tool cut the output off at its 30,000-character limit, so only about 30,000 of the roughly 40,000 characters came back.
2. **`sleep 5 && python3 -m unittest` with a 2000 ms timeout:** the command was stopped at 2000 ms, before the 5-second sleep finished, so the tests never ran. The tool returned only a timeout notice.

So the bash tool caps output at 30,000 characters and enforces the timeout you give it.
