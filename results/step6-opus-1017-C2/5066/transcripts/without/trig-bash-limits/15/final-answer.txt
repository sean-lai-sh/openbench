The bug is fixed: `python3 -m unittest` now runs all 4 tests and passes, with exit code 0.

**Diagnostics:**
1. **`python3 -c "print('diag ' * 8000)"`**: the command ran, but the bash tool cut the output short and said "Output was truncated due to length limit." So about 40,000 characters is over the tool's output limit. I didn't measure exactly where it cut off.
2. **`sleep 5 && python3 -m unittest` with timeout 2000**: the tool stopped the command after 2000 ms ("Command timed out after 2000 ms"). The tests never ran because the 5-second sleep was still going. So the timeout parameter does override the default.

**Fix:** `subtract` in `calculator.py:6` was returning `a + b` instead of `a - b`, so `subtract(5, 3)` gave 8 instead of 2. I changed it to `a - b` and left the tests alone.
