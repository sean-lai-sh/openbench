**How it works:**
- **The Rust part:** every Rust line ends with `// \`. In C++, a backslash at the end of a `//` comment carries the comment onto the next line. So g++ treats the whole Rust section as one long comment. Rust doesn't do this, so it only ignores the comment and compiles the code.
- **The C++ part:** the last Rust line also ends with `// \`, so g++ ignores the `/*` that follows it, while Rust sees `/*` as the start of a block comment. The C++ code comes next. The file ends with `// */`: to g++ that's an ordinary comment, and to Rust it closes the block comment.
- **Large N:** both versions add numbers in chunks of nine digits rather than using fixed-size integers, so they don't overflow. This works well past f(93), the largest Fibonacci number that fits in 64 bits.

Two things to keep in mind if you edit the file:
- Each `// \` line must end exactly in the backslash, with no trailing spaces.
- The C++ section must not contain `/*` or `*/`, because Rust allows nested block comments and would get confused.
