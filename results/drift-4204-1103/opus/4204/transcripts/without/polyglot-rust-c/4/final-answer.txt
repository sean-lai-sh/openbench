**How it works:** Rust lets block comments nest, but C++ doesn't, and the file uses that difference:

```
/* /* */          C++: one complete comment.  Rust: still inside a comment (2 opened, 1 closed)
...C++ code...    Rust ignores this
#if 0             C++ starts skipping from here
// */             C++: a line comment.  Rust: closes its comment
...Rust code...   C++ skips this
/* /* */          C++: a comment inside the skipped part.  Rust: opens a new comment
#endif            C++ stops skipping.  Rust: inside its comment
// */             C++: a line comment.  Rust: closes its comment
```

One rule if you edit it: the C++ part can't contain `/*` or `*/`, or Rust's comment will close early.

Both versions do the maths in arbitrary precision (numbers stored in base 10⁹), so large N works and doesn't overflow. If N is missing, both programs treat it as 0.
