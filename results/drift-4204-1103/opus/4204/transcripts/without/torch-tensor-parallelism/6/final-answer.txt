I created `parallel_linear.py` with `ColumnParallelLinear` and `RowParallelLinear`. I tested both on CPU with world sizes 1, 2 and 4, comparing against a regular `nn.Linear` with the same weights and a zero bias. The outputs and the gradients for the input, weight and bias all matched.

**ColumnParallelLinear**
- **Weight:** each rank keeps its slice of `master_weight[out_features/ws * rank : ..., :]`, so the full matrix is split along the output dimension.
- **Bias:** a zero bias of size `out_features/ws`, split the same way as the output.
- **Forward:** each rank computes its part of the output, then the parts are joined along the last dimension with `all_gather`.
- **Backward:** each rank takes its slice of the output gradient, and the input gradient is summed across ranks with `all_reduce`.

**RowParallelLinear**
- **Weight:** each rank keeps its slice of `master_weight[:, in_features/ws * rank : ...]`, so the full matrix is split along the input dimension.
- **Bias:** a full zero bias of size `out_features`, the same on every rank.
- **Forward:** each rank computes a partial output, the partial outputs are summed with `all_reduce`, and then the bias is added.
- **Backward:** the output gradient passes straight back to every rank.

Things that behave in ways you might not assume:
- **Input to RowParallelLinear:** your spec doesn't say whether the tests pass the full input or one already split per rank, so it accepts both. If the last dimension equals `in_features`, it splits the input itself and gathers the input gradient on the way back; otherwise it treats the input as already split.
- **Weight layout:** `master_weight` must have the `nn.Linear` shape `(out_features, in_features)`; there's an assert that rejects anything else.
- **Divisibility:** `out_features` (column) and `in_features` (row) must divide evenly by the world size.
- **Without distributed setup:** if `torch.distributed` isn't initialised, both classes act as a world size of 1.

The communication steps are custom autograd functions, so gradients flow correctly through `all_gather` and `all_reduce`.
