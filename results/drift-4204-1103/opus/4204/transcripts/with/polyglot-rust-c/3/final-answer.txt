I wrote the polyglot to `polyglot/main.rs`. It compiled with both `rustc` and `g++ -x c++`. For N = 0, 1, 2, 3, 10, 50, 90 and 150, both programs printed the same answers, starting 1, 1, 2, 3 as you specified.

**How it works:**
- In C++, a `//` comment ending in `\` carries on to the next line. In Rust it doesn't. So the `/*` on line 2 is just part of a comment for C++, but for Rust it starts a block comment that hides the whole C++ section.
- Inside the C++ part, `#if 0` makes the C++ compiler skip the Rust code. A later `//\` line followed by `*/` closes Rust's block comment, so Rust compiles that code.
- At the end, the same trick hides the closing `#endif` from Rust.

**Limit:** both versions use 128-bit unsigned integers (`u128` in Rust, `unsigned __int128` in C++), so results are correct up to N = 184. Above that, the Rust build (no optimisation by default) stops with an overflow error, and the C++ build silently prints a wrapped-around wrong number.
