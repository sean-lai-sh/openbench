I wrote `pipeline_parallel.py` with `train_step_pipeline_afab`, and it matches a single-process reference model exactly. I tested it with world sizes 1 and 2 on CPU (gloo backend), with both `sdpa` and `eager` attention, using a 5-layer LLaMA in float32 and 3 microbatches. On every rank the loss matched and the largest parameter-gradient difference was 0. I deleted the test script afterwards, and I didn't run your actual test suite.

**How it works:**
- **Splitting the layers:** the decoder layers are divided as evenly as possible, and any extra layers go to the lowest ranks. With 5 layers and 2 ranks, rank 0 runs layers 0–2 and rank 1 runs layers 3–4. Rank 0 also runs the embedding; the last rank also runs the final norm, `lm_head` and the loss.
- **Each stage:** it runs only its own layers, rebuilding the position IDs, rotary embeddings and causal mask that `LlamaModel.forward` would normally create. The mask comes from transformers' `create_causal_mask`, with a hand-built causal mask as a fallback.
- **Schedule:** all forward passes run first, then all backward passes.
  - **Forward:** each rank receives hidden states from the previous rank (except rank 0), runs its layers and sends the result on. The last rank computes `cross_entropy` against the targets and divides it by the number of microbatches.
  - **Backward:** the last rank calls `loss.backward()`. The other ranks receive the gradient from the next rank and backpropagate it, and every rank except 0 sends its input gradient back to the previous rank.
- **Communication:** stages talk through `dist.P2POp` and `dist.batch_isend_irecv`. Inputs, received hidden states and gradients are all moved to the given `device` and `dtype`. No hooks are used.

**Things to know:**
- **The model itself is not converted to `dtype`.** If the model's weights are in a different dtype from the one passed in, the layers could fail on a type mismatch.
- **Targets are used as given, not shifted.** The loss is plain cross-entropy on `targets`, so they need to be shifted already if that's what you intend.
- **Return value:** the function returns the total scaled loss on the last rank and `None` on the other ranks.
- **Full model on every rank:** each rank keeps the complete model and simply runs only its own layers, so layers on other ranks get no gradients.
- **Hidden-state shapes:** every rank works out the shape of incoming hidden states from `inputs[i].shape`, so the input microbatches need to be available on all ranks.
