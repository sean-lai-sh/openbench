I wrote `convert_masks.py` and ran it on the demo files. It refined all 48 masks with MobileSAM on CPU in about 10 seconds, and every output mask is now a polyline. A check script found no overlapping masks, one connected region per cell, and no rectangles. I also drew the old outlines next to the new ones, and the new ones follow the nuclei closely.

**How it works:**
1. It loads MobileSAM (`vit_t`) from `weights_path` and runs it on the image once.
2. Each mask's bounding box is the prompt. MobileSAM returns three candidate masks and the script picks one using MobileSAM's own confidence score. Candidates far too large or small for the box are penalised, and for polylines, closeness to your original outline also counts. The result is cut to the box plus about 15%, keeping only the largest region with holes filled.
3. **Overlaps:** where two masks claim the same pixel, the cell where MobileSAM is more confident gets it. A 1-pixel gap is kept between neighbouring cells so the polygons can't touch or cross.
4. If a cell gets no usable mask, the script puts an ellipse inside its box instead. If that doesn't fit either, it falls back to a free area of the box, and as a last resort a tiny shape at the nearest free pixel. Every row therefore always gets a polyline. None of the demo cells needed this.
5. Each mask is turned into a closed polyline, lightly simplified, with the first point repeated at the end like your input. `xmin/xmax/ymin/ymax` are recalculated from it.

**Output:** the CSV has the same columns, row order and unnamed index column as the input, with only `xmin`, `xmax`, `ymin`, `ymax`, `coords_x` and `coords_y` changed.

**Two choices you should know about:**
- **The `type` column is unchanged**, because you said to update only those six columns. Rows that started as rectangles still say `rectangle` even though their coordinates are now polylines. If you want them all to say `polyline`, add `out["type"] = "polyline"` before the CSV is saved.
- **Output location:** if `output_path` is a folder, the CSV is saved inside it under the input CSV's file name (e.g. `out/demo_metadata.csv`). If it ends in `.csv`, it's used as the file path directly.

**Usage** (named and positional arguments give identical output):
```
python convert_masks.py --weights_path mobile_sam.pt --output_path out_dir --rgb_path img.png --csv_path meta.csv
python convert_masks.py mobile_sam.pt out_dir img.png meta.csv
```

It uses only the packages you listed and doesn't modify MobileSAM.
