All 25 tests now pass. I fixed seven bugs, and I didn't touch the tests.

- **`queue.py`:** `_Entry.sort_key` ordered by `(seq, -priority)`. It now uses `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the base value overrode the override. It now calls `deep_merge(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` iterated over `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so every downstream task gets skipped.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within an admission batch. Its own docstring says non-increasing, so it now checks `current <= prev`. With the queue ordering fixed, the old check would have failed valid batches.
- **`events.py`:** `_prefix_matches` checked `prefix.startswith(topic + ".")`, which is backwards. It now checks `topic.startswith(prefix + ".")`. This is why `History` never saw the `job.term.*` events.
- **`resources.py`:** `ResourcePool.release` always did `used -= 1` instead of `used -= cost`. Pools never freed fully, which stalled multi-unit resource tasks.
