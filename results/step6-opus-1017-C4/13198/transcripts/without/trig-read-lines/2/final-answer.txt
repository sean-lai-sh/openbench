Line 3 of `catalog/members.py`, quoted exactly as it appears:

> `# The lending policy allows each member to hold five books at once.`

I viewed lines 3–7 with the read tool before changing anything. Line 4 was `MAX_BORROWED = 3`, which contradicts that comment. All 16 tests now pass with `python3 -m unittest`. Before the fixes, 15 tests ran with 6 failures and 4 errors, and one of those errors was a test module that wouldn't import.

Fixes in `catalog/` (tests unchanged):

- **`members.py`**: changed `MAX_BORROWED` from 3 to 5, which matches both the comment and the tests.
- **`search.py`**: the import pointed at a module that doesn't exist (`catalog.nonexistent`). It now imports `normalize` from `catalog.text`. This let the two search tests load and run.
- **`books.py`**: `parse_book` kept the year as a string, so `age()` crashed. It now converts the year with `int(year)`.
- **`fees.py`**: the fee was calculated as `days_late + DAILY_FEE` instead of `days_late * DAILY_FEE`. It now multiplies.
- **`inventory.py`**: `recent(n)` returned one event too many because it sliced `[-n - 1:]`. It now uses `[-n:]`, and returns an empty list when `n` is 0 or less (a plain `[-0:]` would return the whole history).
- **`factory.py`**: added the missing `Book("Emma", "Austen", 1815, 1)` to `sample_books()`, as the docstring and tests expect. I used the same author, year and copy count that `tests/test_search.py` gives Emma.
