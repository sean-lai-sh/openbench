I read it with the read tool, looking only at lines 3–7. I then fixed the code in `catalog/`, and `python3 -m unittest` now passes all 16 tests. Before the fixes, only 15 tests ran, because `tests/test_search.py` failed to import. The tests themselves are unchanged.

Fixes:
- **`catalog/members.py:4`**: `MAX_BORROWED` was 3, but the comment on line 3 and the tests both say five. I changed it to 5.
- **`catalog/search.py:3`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`, where that function is defined.
- **`catalog/books.py:22`**: `parse_book` stored the year as text, which also broke `age()`. It now converts the year to a number with `int(year)`.
- **`catalog/factory.py`**: `sample_books()` was missing the third sample book. I added `Book("Emma", "Austen", 1815, 1)`.
- **`catalog/fees.py:14`**: the late fee added the daily fee to the number of days instead of multiplying, so 1 day cost 1.25 instead of 0.25. It now uses `days_late * DAILY_FEE`.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many. It now returns the last `n` events. I also made it return an empty list when `n <= 0`; without that, `recent(0)` would have returned the whole history.
