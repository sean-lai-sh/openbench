Line 3 of `catalog/members.py`, quoted verbatim:

```
# The lending policy allows each member to hold five books at once.
```

I viewed it with the read tool, showing only lines 3–7. `python3 -m unittest` now passes all 16 tests. Before the fixes, 15 tests ran with 6 failures and 4 errors; one of the errors was a test file that couldn't be imported, so its 2 tests weren't counted. I didn't change any tests.

What I changed in `catalog/`:

- **`members.py`**: `MAX_BORROWED` was `3`, but the comment on line 3 and the tests both say five. Changed it to `5`.
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`, where `normalize` lives.
- **`books.py`**: `parse_book` stored the year as text, so `age()` failed when subtracting. It now converts the year to a number with `int(year)`.
- **`fees.py`**: the fee was days late *plus* the daily rate. It's now days late *times* the rate, so 1 day costs 0.25 and 4 days cost 1.00.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`, and an empty list when `n <= 0`.
- **`factory.py`**: added the missing `Emma` book that the docstring and tests expect, using `Book("Emma", "Austen", 1815, 1)`.
