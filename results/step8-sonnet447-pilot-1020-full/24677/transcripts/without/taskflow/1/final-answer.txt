All 25 tests pass. I found seven bugs, some in different modules from the tests that exposed them:

- **`queue.py`**: `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority runs first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which was off by one. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`**: `batch_order_ok` required priorities to be non-decreasing within a batch. It now requires non-increasing, as its docstring says.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a failure is skipped.
- **`resources.py`**: `ResourcePool.release` did `self.used -= 1` instead of `-= cost`, which leaked pool capacity.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own settings. It now recurses with `(base, override)`.
- **`events.py`**: `_prefix_matches` had its operands backwards (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`, so the history sees `job.term.*` events.

I didn't modify any tests.
