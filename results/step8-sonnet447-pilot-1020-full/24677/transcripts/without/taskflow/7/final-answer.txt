`python3 -m unittest` now passes: all 25 tests. I didn't touch the tests. There were seven separate defects, and fixing some of them exposed the others.

| File | Bug | Fix |
|---|---|---|
| `taskflow/queue.py` | `sort_key` returned `(seq, -priority)`, so insertion order beat priority. | It now returns `(-priority, seq)`. |
| `taskflow/retry.py` | `should_retry` used `attempts_made < max_attempts - 1`, which is off by one and gave one attempt too few. | It now uses `attempts_made < max_attempts`. |
| `taskflow/resources.py` | `ResourcePool.release` did `used -= 1` instead of subtracting the cost. | It now subtracts `cost`. |
| `taskflow/statemachine.py` | `batch_order_ok` required non-decreasing priority, but the docstring says non-increasing. | The check is now `current <= prev`. |
| `taskflow/scheduler.py` | `_cascade_skip` skipped only direct dependents, not the whole downstream chain. | It now uses `dag.transitive_dependents`. |
| `taskflow/config.py` | `deep_merge` recursed with its arguments swapped, so defaults overrode task settings. | It now recurses as `deep_merge(result[key], value)`. |
| `taskflow/events.py` | `_prefix_matches` checked `prefix.startswith(topic + ".")`, the wrong way round, so `job.term.*` events never reached `History`. | It now checks `topic.startswith(prefix + ".")`. |
