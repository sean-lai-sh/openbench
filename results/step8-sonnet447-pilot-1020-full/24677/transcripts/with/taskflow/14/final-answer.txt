`python3 -m unittest` now passes all 25 tests. I fixed seven logic bugs in `taskflow/` and left the tests alone.

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority dispatches first and insertion order breaks ties.
- **`retry.py`:** `should_retry` had an off-by-one (`attempts_made < max_attempts - 1`). It now uses `attempts_made < max_attempts`, which allows retries after attempts 1 and 2 when `max_attempts` is 3.
- **`config.py`:** `deep_merge` recursed with the arguments swapped, so the base overrode the override. It now recurses with the base first and the override second.
- **`statemachine.py`:** `batch_order_ok` required priorities to be non-decreasing within an admission batch. The docstring says non-increasing, so I flipped the comparison to `<=`.
- **`scheduler.py`:** `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.
- **`resources.py`:** `ResourcePool.release` did `self.used -= 1` instead of subtracting `cost`, which leaked capacity for any task that held more than one unit.
- **`events.py`:** `_prefix_matches` checked `prefix.startswith(topic + ".")`, with the roles reversed. It now checks `topic.startswith(prefix + ".")`. Before this, the history's `job.term` subscription never received the terminal events.
