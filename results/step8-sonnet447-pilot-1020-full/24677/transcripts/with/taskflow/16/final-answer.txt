`python3 -m unittest` now passes: all 25 tests, with no test files modified. There were seven separate bugs:

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave one retry too few. It is now `attempts_made < max_attempts`, matching its docstring.
- **`config.py`:** `deep_merge` recursed with the arguments swapped, so the defaults overrode the task's own values. It now merges the override on top of the base.
- **`scheduler.py`:** `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`.
- **`statemachine.py`:** `batch_order_ok` required priorities to be non-decreasing within an admission batch. The docstring says non-increasing, so it now checks `current <= prev`.
- **`events.py`:** `_prefix_matches` had the prefix and topic reversed. Subscribing to `job.term` therefore never matched `job.term.failed` and similar topics. It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`. Multi-unit resource tasks leaked capacity and stalled.
