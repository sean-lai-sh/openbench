All 25 tests now pass. I fixed seven bugs, one line each:

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It is now `attempts_made < max_attempts`.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so defaults overrode a task's own settings. It now calls `deep_merge(result[key], value)`.
- **`resources.py`**: `ResourcePool.release` did `used -= 1` instead of `used -= cost`. Pools never fully freed, which blocked later tasks.
- **`statemachine.py`**: `batch_order_ok` required priority to be non-decreasing within an admission batch. The docstring says non-increasing, so it now checks `current <= prev`.
- **`scheduler.py`**: `_cascade_skip` used `dag.dependents` (direct children only). It now uses `transitive_dependents`, so the whole downstream chain is skipped.
- **`events.py`**: `_prefix_matches` had the prefix and topic reversed (`prefix.startswith(topic + ".")`). It is now `topic.startswith(prefix + ".")`. Before this fix, the history never saw `job.term.*` events.
