`python3 -m unittest` now passes: all 25 tests, with no test files modified. I fixed six bugs in `taskflow/`.

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`, so the queue ignored priority. It now returns `(-priority, seq)`.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments swapped (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`:** `ResourcePool.release` always subtracted 1 instead of `cost`, so multi-unit costs were never fully returned. It now subtracts `cost`.
- **`statemachine.py`:** `batch_order_ok` had its comparison reversed. A batch is meant to run in non-increasing priority, so a higher-priority task after a lower one was accepted, and the scheduler then wrongly failed valid dispatches. It now checks `current <= prev`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so defaults overrode task settings. It now calls `deep_merge(result[key], value)`.

One more bug showed up only after those fixes. `Scheduler._cascade_skip` used `dag.dependents`, which returns direct children only. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.
