`python3 -m unittest` now passes all 25 tests. I didn't touch the tests. I fixed these seven defects:

| File | Bug | Fix |
|---|---|---|
| `queue.py` | `_Entry.sort_key` returned `(seq, -priority)`, so insertion order beat priority. | It now returns `(-priority, seq)`. |
| `retry.py` | `should_retry` used `attempts_made < max_attempts - 1`, which is off by one. | It now uses `attempts_made < max_attempts`. |
| `statemachine.py` | `batch_order_ok` required priorities to be non-decreasing within a batch, the opposite of the documented rule. | It now requires `current <= prev`. |
| `resources.py` | `ResourcePool.release` subtracted 1 instead of `cost`, so multi-unit tasks leaked capacity. | It now subtracts `cost`. |

| `config.py` | `deep_merge` recursed with its arguments swapped, so defaults overrode the task's own values. | The recursion is now `deep_merge(result[key], value)`. |
