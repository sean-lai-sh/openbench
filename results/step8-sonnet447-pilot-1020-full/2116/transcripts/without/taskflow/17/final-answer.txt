`python3 -m unittest` now passes: 25 tests, all OK. I fixed seven bugs and didn't touch the tests.

| File | Bug | Fix |
|---|---|---|
| `queue.py` | `_Entry.sort_key` returned `(seq, -priority)`, so the queue ignored priority. | It now returns `(-priority, seq)`. |
| `retry.py` | `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. | It now uses `attempts_made < max_attempts`. |
| `events.py` | `_prefix_matches` checked `prefix.startswith(topic + ".")`, which is backwards. History's `job.term` subscription therefore never saw `job.term.failed`, `job.term.skipped` or `job.term.succeeded`. | It now checks `topic.startswith(prefix + ".")`. |
| `statemachine.py` | `batch_order_ok` required priorities to be non-decreasing within a batch, but the docs say non-increasing. | It now checks `current <= prev`. |
| `resources.py` | `ResourcePool.release` did `used -= 1` instead of subtracting the cost. Resources leaked, which caused the resource-test failures. | It now does `used -= cost`. |
| `config.py` | `deep_merge` recursed with its arguments swapped, so the defaults overrode task values. | It now recurses as `deep_merge(result[key], value)`. |
| `scheduler.py` | `_cascade_skip` used the direct dependents of a failed task, so only its immediate children were skipped. | It now uses `dag.transitive_dependents`, which covers everything downstream. |
