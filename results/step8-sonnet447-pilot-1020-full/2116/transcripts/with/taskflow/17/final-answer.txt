All 25 tests now pass. I found six bugs, in six different modules:

- **`queue.py`:** `_Entry.sort_key` ordered by `(seq, -priority)`. It now orders by `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`:** `batch_order_ok` had its comparison backwards. It now requires `current_priority <= prev_priority`, as its docstring says.
- **`events.py`:** `_prefix_matches` tested `prefix.startswith(topic + ".")`, which is the wrong way round. It now tests `topic.startswith(prefix + ".")`.
- **`resources.py`:** `ResourcePool.release` always subtracted 1. It now subtracts `cost`.
- **`config.py`:** `deep_merge` swapped its arguments when it recursed, so the base value overrode the override in nested dicts. That is fixed.
- **`scheduler.py`:** `_cascade_skip` only skipped direct dependents. It now uses `dag.transitive_dependents`, so every downstream task is skipped.

That is seven edits across seven files. I didn't modify any tests.
