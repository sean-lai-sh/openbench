All 25 tests now pass with `python3 -m unittest`. I fixed six root-cause defects, and I didn't touch the tests.

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority runs first and equal priorities stay in insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priorities within an admission batch to be non-decreasing. That's the opposite of the documented rule, so it now checks `current <= prev`. The scheduler's guard was failing correctly-ordered tasks outright, which looked like retry and resource bugs.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`. Multi-unit costs leaked capacity and left the pool stuck.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so defaults overrode the task's own values. It now merges `(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns direct children only. It now uses `dag.transitive_dependents`, so the whole downstream subtree is skipped.
