`python3 -m unittest` now passes all 25 tests. I didn't modify any tests.

I fixed seven bugs:

- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority runs first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had the prefix check reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priorities to rise within a batch. It now requires `current_priority <= prev_priority`, as the docstring says.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own values. It now calls `deep_merge(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so every downstream task is skipped.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of subtracting the cost. Pools therefore never fully freed, and resource-limited tasks stalled.
