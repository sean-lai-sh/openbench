`python3 -m unittest` now passes all 25 tests. I fixed seven bugs, and I didn't touch the tests.

- **`queue.py`:** The sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority runs first and ties go in FIFO order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing, but the docstring says non-increasing. It now checks `current <= prev`.
- **`config.py`:** `deep_merge` recursed with the arguments swapped, so defaults overrode a task's own settings. It now merges `(base, override)`.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so a failure skips everything downstream.
- **`resources.py`:** `ResourcePool.release` did `self.used -= 1` instead of `-= cost`. That leaked capacity, so resource-limited pipelines stalled.
