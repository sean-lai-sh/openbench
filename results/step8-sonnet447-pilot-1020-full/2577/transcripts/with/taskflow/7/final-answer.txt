`python3 -m unittest` now passes all 25 tests. I changed one line in each of six files under `taskflow/`.

- **`queue.py`**: `_Entry.sort_key` was `(seq, -priority)`. It now sorts on `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which allowed one retry too few. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had its arguments backwards. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priority to rise within an admission batch. It now requires it to be non-increasing (`current <= prev`).
- **`resources.py`**: `ResourcePool.release` always subtracted 1 instead of the cost. It now subtracts `cost`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `transitive_dependents`.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the base overrode the task's own values. It now merges `(result[key], value)`.

I only checked the code paths the tests cover. The other modules under `taskflow/` have no tests, so any defects in them would not show up here.
