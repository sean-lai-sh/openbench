Fix deep_merge, and cascade must be transitive.


`python3 -m unittest` now passes all 25 tests. I fixed seven bugs and didn't touch the tests.

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which retried one time too few. It is now `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` had the arguments reversed, so a prefix subscriber didn't receive events under its prefix. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` used `>=`, which rejected non-increasing priority order inside a batch. It now uses `<=`.
- **`resources.py`**: `ResourcePool.release` did `used -= 1` instead of `used -= cost`, which leaked capacity.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so defaults overrode a task's own settings. It now merges the task's values on top of the defaults.
- **`scheduler.py`**: `_cascade_skip` used the direct `dependents`, so only direct children were skipped. It now uses `transitive_dependents`.
