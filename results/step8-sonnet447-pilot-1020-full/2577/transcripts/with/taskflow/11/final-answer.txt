I found seven bugs, each a one-line logic error:

- **`queue.py`:** `_Entry.sort_key` ordered entries by `(seq, -priority)`. It now uses `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which cut the retry budget short by one. It now uses `attempts_made < max_attempts`.
- **`statemachine.py`:** `batch_order_ok` had its comparison reversed. It now checks `current_priority <= prev_priority`, so priorities are non-increasing within a batch.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own values. It now merges `(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` skipped only the direct dependents of a failed task. It now iterates `transitive_dependents`, so everything downstream is skipped.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of the task's cost. It now subtracts `cost`.
- **`events.py`:** `_prefix_matches` tested the prefix and topic the wrong way round. It now checks `topic.startswith(prefix + ".")`.
