`python3 -m unittest` now passes all 25 tests. I fixed seven bugs and didn't touch the tests.

- **`queue.py`:** the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and insertion order only breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`resources.py`:** `ResourcePool.release` always subtracted 1 instead of the task's cost. It now subtracts `cost`.
- **`events.py`:** the prefix match had its arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within an admission batch. It now requires non-increasing, as the docstring says.
- **`config.py`:** `deep_merge` swapped base and override when recursing into nested dicts, so defaults overwrote task values. It now recurses with the arguments in the right order.
- **`scheduler.py`:** the cascade skip only reached direct dependents. It now uses `dag.transitive_dependents`, so everything downstream of a permanent failure is skipped.
