`python3 -m unittest` now passes all 25 tests. I didn't modify any tests. I fixed seven bugs, most of them one-line changes:

- **`queue.py`**: The sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority runs first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave one attempt too few. It now uses `attempts_made < max_attempts`.
- **`events.py`**: `_prefix_matches` checked `prefix.startswith(topic + ".")`, which had the arguments reversed. It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`**: `ResourcePool.release` always subtracted 1 from `used`. It now subtracts `cost`.
- **`statemachine.py`**: `batch_order_ok` used `>=` and allowed priority to rise within a batch. The docstring says priority must not increase, so it is now `<=`.
- **`config.py`**: `deep_merge` recursed with the arguments swapped, so the defaults overrode the task's own values. It now recurses as `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` only skipped direct dependents. It now uses `transitive_dependents`, so everything downstream of a permanent failure is skipped.
