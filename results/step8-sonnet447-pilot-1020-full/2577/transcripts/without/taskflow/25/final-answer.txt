All 25 tests now pass. I changed these in `taskflow/`:

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
- **`retry.py`:** `should_retry` allowed one retry too few. It now returns `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had its arguments reversed, so prefix subscribers never saw `job.term.*` events. It now checks `topic.startswith(prefix + ".")`.

- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`, so multi-unit resource costs leaked. It now subtracts `cost`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so defaults overrode task settings. It now recurses with `deep_merge(result[key], value)`.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`.
