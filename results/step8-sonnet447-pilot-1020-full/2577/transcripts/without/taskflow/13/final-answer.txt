`python3 -m unittest` now passes all 25 tests. I fixed seven bugs, and I didn't edit any tests.

- **`queue.py`:** the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties are first-in-first-out.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which cut retries one short. It now uses `attempts_made < max_attempts`.
- **`resources.py`:** `ResourcePool.release` subtracted 1 instead of `cost`, so multi-unit tasks never gave their resources back.
- **`events.py`:** `_prefix_matches` had the prefix check reversed. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` allowed priority to rise within an admission batch. It now requires `current <= prev`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own settings. It now merges `(base, override)` in that order.
- **`scheduler.py`:** `_cascade_skip` called `dag.dependents()`, which returns only direct children. It now calls `transitive_dependents()`, so everything downstream of a permanent failure is skipped.

Some of these hid each other. The retry and resource fixes had to land before the pipeline tests could show the config and cascade-skip failures.
