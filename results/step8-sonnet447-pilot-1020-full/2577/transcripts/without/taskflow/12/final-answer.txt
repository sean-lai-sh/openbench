Fix deep_merge and cascade skip (use transitive dependents).


`python3 -m unittest` now passes all 25 tests. I fixed these defects:

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in FIFO order.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which cut the retry budget short. It now uses `attempts_made < max_attempts`.
- **`events.py`**: the prefix match checked `prefix.startswith(topic + ".")`, which is backwards. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`**: `batch_order_ok` required priorities to be non-decreasing within an admission batch. The docstring says non-increasing, so it now checks `current <= prev`.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`, so multi-unit resources leaked and later tasks couldn't be admitted.
- **`config.py`**: `deep_merge` swapped the base and override arguments when recursing into nested dicts. Task-level `retry` overrides were being lost.
- **`scheduler.py`**: `_cascade_skip` used the direct dependents. It now uses `dag.transitive_dependents`, so a permanent failure skips every downstream task.
