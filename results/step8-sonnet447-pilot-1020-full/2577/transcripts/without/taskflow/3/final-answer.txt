`python3 -m unittest` now passes all 25 tests. I didn't modify any tests. There were seven bugs:

- **`queue.py`:** `_Entry.sort_key` sorted by `(seq, -priority)`. It now sorts by `(-priority, seq)`, so higher priority goes first and ties keep insertion order.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which stopped one attempt early. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` checked `prefix.startswith(topic + ".")`, which is backwards. It now checks `topic.startswith(prefix + ".")`.
- **`statemachine.py`:** `batch_order_ok` required priorities to be non-decreasing within an admission batch. It now requires non-increasing, as the docstring says.
- **`resources.py`:** `ResourcePool.release` always subtracted 1 from `used`. It now subtracts `cost`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the base overrode the task's own values. It now merges the override on top of the base.
- **`scheduler.py`:** `_cascade_skip` skipped only direct dependents. It now uses `dag.transitive_dependents`, so a permanent failure skips everything downstream.
