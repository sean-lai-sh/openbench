All 25 tests now pass. I ran `python3 -m unittest` after the last change and it reported `OK`. I fixed seven defects and didn't touch the tests:

- **`queue.py`**: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and FIFO breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It is now `attempts_made < max_attempts`.
- **`statemachine.py`**: `batch_order_ok` compared priorities the wrong way round. It now returns `current_priority <= prev_priority`, which matches the non-increasing-priority rule.
- **`resources.py`**: `ResourcePool.release` always subtracted 1 instead of `cost`, so multi-unit resources were never fully released. It now subtracts `cost`.
- **`events.py`**: `_prefix_matches` had its arguments swapped. It now uses `topic.startswith(prefix + ".")`.
- **`config.py`**: `deep_merge` recursed with the base and override swapped, so defaults overwrote task overrides. It now calls `deep_merge(result[key], value)`.
- **`scheduler.py`**: `_cascade_skip` used the direct `dependents` only. It now uses `transitive_dependents`, so a permanent failure skips everything downstream.
