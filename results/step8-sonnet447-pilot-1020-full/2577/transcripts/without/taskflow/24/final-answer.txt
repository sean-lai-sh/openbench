`python3 -m unittest` now passes all 25 tests. I didn't modify any tests. Each defect was a one-line logic error:

- **`queue.py`:** `_Entry.sort_key` ordered by `(seq, -priority)`. It now uses `(-priority, seq)`, so higher priority dispatches first and insertion order breaks ties.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which was off by one. It now uses `attempts_made < max_attempts`.
- **`events.py`:** `_prefix_matches` had the arguments reversed (`prefix.startswith(topic + ".")`). It now checks `topic.startswith(prefix + ".")`.
- **`resources.py`:** `ResourcePool.release` always subtracted 1 from `used`. It now subtracts `cost`.
- **`statemachine.py`:** `batch_order_ok` required priority to be non-decreasing within a batch. It now requires non-increasing, as its docstring says.
- **`config.py`:** `deep_merge` swapped base and override when recursing into nested dicts, so defaults overwrote per-task `retry` settings. It now merges `result[key]` with `value`.
- **`scheduler.py`:** `_cascade_skip` only skipped direct dependents. It now uses `transitive_dependents`, so everything downstream of a permanent failure is skipped.
