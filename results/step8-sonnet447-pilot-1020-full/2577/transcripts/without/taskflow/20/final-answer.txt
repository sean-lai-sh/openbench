`python3 -m unittest` now passes all 25 tests. I fixed seven defects in `taskflow/`:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`resources.py`**: `ResourcePool.release` subtracted 1 instead of `cost`, so pools leaked capacity. It now subtracts `cost`.
- **`statemachine.py`**: `batch_order_ok` had its comparison backwards. Within a batch, priority must be non-increasing, so it now checks `current <= prev`.
- **`config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own values. It now merges `(base_child, override_child)`.
- **`events.py`**: `_prefix_matches` had its arguments reversed in the `startswith` check. It now uses `topic.startswith(prefix + ".")`, which fixes the history terminal-event subscription.
- **`scheduler.py`**: the failure cascade only skipped direct dependents. It now uses `dag.transitive_dependents`, so downstream tasks like `d` in the diamond case are skipped too.
