All 25 tests now pass. I found seven bugs, all in `taskflow/`:

- **`queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority goes first and insertion order breaks ties.
- **`retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which stopped one attempt early. It now uses `attempts_made < max_attempts`.
- **`resources.py`**: `ResourcePool.release` did `used -= 1` instead of `used -= cost`, so multi-unit costs were never fully released.
- **`statemachine.py`**: `batch_order_ok` had its comparison reversed. A batch must have non-increasing priority, so it now checks `current <= prev`.
- **`events.py`**: `_prefix_matches` tested `prefix.startswith(topic + ".")` instead of `topic.startswith(prefix + ".")`. Prefix subscribers such as `job.term` therefore never received events, and that left the history's failed, skipped and succeeded sets empty.
- **`config.py`**: `deep_merge` recursed as `deep_merge(value, result[key])`, which let the base win over the override. It now recurses with the arguments the other way round.
- **`scheduler.py`**: `_cascade_skip` used the direct `dag.dependents`. It now uses `dag.transitive_dependents`, so a permanent failure skips everything downstream, not just its direct children.
