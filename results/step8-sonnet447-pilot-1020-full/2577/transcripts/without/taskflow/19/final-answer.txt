All 25 tests now pass. I fixed these eight bugs and didn't touch the tests:

- `queue.py`: the sort key was `(seq, -priority)`. It is now `(-priority, seq)`, so higher priority goes first and ties go in insertion order.
- `retry.py`: `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt too early. It is now `attempts_made < max_attempts`.
- `statemachine.py`: `batch_order_ok` required priority to be non-decreasing within an admission batch. The docstring says non-increasing, so I flipped the comparison to `<=`.
- `config.py`: `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own values. It now merges `(base, override)` in the right order.
- `events.py`: `_prefix_matches` had the prefix check backwards. It now uses `topic.startswith(prefix + ".")`, which makes the history's `job.term` subscription receive the terminal events.

- `resources.py`: `ResourcePool.release` subtracted 1 instead of `cost`, which leaked capacity and stalled later tasks.
