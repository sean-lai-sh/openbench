`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, with the key spelled `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` instead of raising an error. The `None` then reached `rate * count` in `compute_total` and caused the `TypeError`. The traceback pointed at `report.py`, but the bug was in the config file.

**Fix:** I renamed the key to `"rate"` in `settings.json`. I made no code changes.

If you'd rather get a clear error for a missing or misspelled setting, change `get_rate()` to use `SETTINGS["rate"]`. I left it as is.
