`python3 main.py` now exits cleanly and prints `Total: 5.0`.

The cause was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because of the typo. That `None` then reached `rate * count` in `compute_total` and raised the `TypeError`. I renamed the key to `"rate"`, and no code changes were needed.

`get_rate()` still returns `None` silently when the key is missing. If you want a misspelled setting to fail with a clear error instead, changing it to `SETTINGS["rate"]` would do that. I left it alone since you only asked for the crash to be fixed.
