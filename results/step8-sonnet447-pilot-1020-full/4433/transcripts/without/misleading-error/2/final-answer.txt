`python3 main.py` now exits cleanly and prints `Total: 5.0`.

**Cause:** `settings.json` had a typo, `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then failed in `rate * count` in `report.py`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. I didn't change any code.

I left `get_rate()` as it was. It still returns `None` silently if the key is missing, so a future typo would fail the same confusing way. Using `SETTINGS["rate"]` would raise a clear `KeyError` instead. I can make that change if you want it.
