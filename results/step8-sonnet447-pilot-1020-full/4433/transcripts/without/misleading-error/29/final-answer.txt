The script now runs and prints `Total: 5.0`.

The cause was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then failed in `rate * count` inside `compute_total`. I renamed the key to `"rate"` and left the code alone.
