`python3 main.py` now exits successfully and prints `Total: 5.0`.

The cause was a typo in `settings.json`. The key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` was then multiplied by `count` in `compute_total`, which raised the `TypeError`.

I renamed the key to `"rate"` and changed no code. Because `.get()` silently returns `None` for a missing key, a similar typo would fail the same confusing way. If you want a clearer error, `get_rate()` could use `SETTINGS["rate"]` so a missing key raises a `KeyError`.
