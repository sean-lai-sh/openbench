The crash came from a typo in `settings.json`. The key was `"rat"` instead of `"rate"`. `SETTINGS.get("rate")` therefore returned `None`, and `None * 10` raised the `TypeError`.

I renamed the key to `"rate"`. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

I left the code alone. `get_rate()` still returns `None` quietly when the key is missing, so a similar typo would produce the same confusing error again. If you'd like, I can make it raise a clear error instead.
