I fixed it. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

The cause was a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py` returned `None`. That `None` then hit `rate * count` in `compute_total` and raised the `TypeError`.

I renamed the key to `"rate"` in `settings.json` and left the code alone.

`get_rate()` will still return `None` quietly if the key goes missing again. If you'd rather it fail with a clear error, I can change it to `SETTINGS["rate"]`.
