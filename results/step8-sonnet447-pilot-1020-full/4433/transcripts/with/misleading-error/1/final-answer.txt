`python3 main.py` now prints `Total: 5.0` and exits cleanly.

The cause was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then failed in `rate * count` in `app/report.py`. I renamed the key to `"rate"` and didn't change any code.

`get_rate()` could raise a clear error when the rate is missing, so a typo like this fails with a useful message instead of a `TypeError`. I left that alone since you only asked for the fix.
