`python3 main.py` now exits successfully and prints `Total: 5.0`.

The cause was a typo in `settings.json`. The key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because that key didn't exist. That `None` then failed in `rate * count`. I renamed the key to `"rate"` and left the code alone.

`get_rate()` still returns `None` silently when the key is missing, so a similar typo would give the same confusing `TypeError`. Switching it to `SETTINGS["rate"]` would make it fail with a clear `KeyError` instead. I didn't make that change.
