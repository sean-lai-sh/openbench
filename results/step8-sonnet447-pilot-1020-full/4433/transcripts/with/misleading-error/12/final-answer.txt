The crash came from a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py` returned `None`. `compute_total` then tried to multiply `None` by 10.

I renamed the key to `"rate"`. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

I didn't change any code. `get_rate()` still returns `None` silently if the key is missing, which is why the error showed up in `report.py` and not where the bad value came from. If you want, I can make it fail with a clear message when `rate` is absent.
