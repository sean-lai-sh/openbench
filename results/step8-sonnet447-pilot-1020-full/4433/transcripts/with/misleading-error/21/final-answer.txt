`python3 main.py` now exits successfully and prints `Total: 5.0`.

The cause was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` is what `compute_total` tried to multiply by the count. I renamed the key to `"rate"` and left the code unchanged.

`SETTINGS.get("rate")` hides a missing key by returning `None`. Using `SETTINGS["rate"]` would raise a `KeyError` that names the missing key. I didn't make that change.
