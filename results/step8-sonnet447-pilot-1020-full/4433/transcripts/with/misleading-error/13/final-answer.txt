`python3 main.py` now exits cleanly and prints `Total: 5.0`.

The cause was a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py` returned `None`. That `None` then reached `rate * count` in `compute_total` and raised the `TypeError`. I renamed the key to `"rate"` and left the code alone.

If you want a typo like this to fail with a clear message next time, change `get_rate()` to use `SETTINGS["rate"]`. A missing key would then raise a `KeyError` instead of passing `None` along. I didn't make that change.
