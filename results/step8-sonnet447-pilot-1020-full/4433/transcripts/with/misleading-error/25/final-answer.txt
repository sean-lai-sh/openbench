`python3 main.py` now exits cleanly and prints `Total: 5.0`.

The cause was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then failed in `rate * count` in `app/report.py`. I renamed the key to `"rate"` and changed no code.

`get_rate()` would still return `None` for any missing key, so a future typo would fail the same confusing way. I left that alone since you only asked for the fix.
