`python3 main.py` now exits cleanly and prints `Total: 5.0`.

The cause was a typo in `settings.json`. The key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then hit `rate * count` in `compute_total` and raised the `TypeError`. I renamed the key to `"rate"`, and no code changes were needed.

`get_rate()` will still return `None` quietly if the key goes missing again. If you want a clearer error in that case, it could raise one instead. I left it alone since you didn't ask for that.
