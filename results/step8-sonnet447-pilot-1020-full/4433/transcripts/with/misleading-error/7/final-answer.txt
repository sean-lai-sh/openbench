Fixed. `settings.json` had a typo: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which quietly returned `None` for the missing key. That `None` then crashed `rate * count` in `compute_total`. I renamed the key to `"rate"`, and `python3 main.py` now prints `Total: 5.0`.

I didn't change the code. `get_rate()` could raise an error when the key is missing instead of returning `None`, which would make a typo like this easier to spot. I left it alone because you only asked for the crash fix.
