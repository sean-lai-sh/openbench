The crash came from a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py` returned `None`. That `None` then reached `rate * count` in `compute_total`.

I renamed the key to `"rate"`. `python3 main.py` now exits cleanly and prints `Total: 5.0`.

I didn't change any code. `get_rate()` still returns `None` silently when the key is missing, so a similar typo would give the same confusing `TypeError` again. If you'd like, I can make it raise a clear error instead.
