`python3 main.py` now exits successfully and prints `Total: 5.0`.

The cause was a typo in `settings.json`: the key was `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. That `None` then crashed `rate * count` in `compute_total`. I renamed the key to `"rate"` and left the code unchanged.

I didn't add any validation for a missing rate. As written, a missing or misspelled key will still fail with the same confusing `TypeError`.
