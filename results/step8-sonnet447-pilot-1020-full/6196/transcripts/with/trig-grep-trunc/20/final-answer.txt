`python3 -m unittest` now reports all 25 tests passing. I didn't change any tests.

My first `grep` for `self` was truncated at 100 matches and didn't help, so I ran the suite and read the failing modules instead. I found and fixed seven bugs:

| File | Bug | Fix |
|---|---|---|
| `queue.py` | `_Entry.sort_key` sorted by `(seq, -priority)`, so priority was ignored. | Changed to `(-priority, seq)`. |
| `retry.py` | `should_retry` used `attempts_made < max_attempts - 1`, one attempt short. | Changed to `attempts_made < max_attempts`. |
| `resources.py` | `ResourcePool.release` did `used -= 1` instead of subtracting the cost, so pools never freed fully. | Changed to `used -= cost`. |
| `statemachine.py` | `batch_order_ok` checked `current >= prev`, which is the wrong direction for non-increasing priority. | Changed to `current <= prev`. |
| `config.py` | `deep_merge` recursed with the arguments swapped, so base values overrode task overrides. | Now `deep_merge(result[key], value)`. |
| `events.py` | `_prefix_matches` tested `prefix.startswith(topic + ".")`, so prefix subscribers like `History` never received `job.term.*` events. | Now `topic.startswith(prefix + ".")`. |
| `scheduler.py` | `_cascade_skip` used direct `dependents`, so only children were skipped. | Now uses `transitive_dependents`. |
