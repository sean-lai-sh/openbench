All 25 tests now pass with `python3 -m unittest`. I didn't modify the tests. I fixed seven defects:

- **`taskflow/queue.py`**: `_Entry.sort_key` returned `(seq, -priority)`. It now returns `(-priority, seq)`, so higher priority dispatches first and insertion order breaks ties.
- **`taskflow/retry.py`**: `should_retry` used `attempts_made < max_attempts - 1`, which stopped one attempt early. It now uses `attempts_made < max_attempts`.
- **`taskflow/config.py`**: `deep_merge` recursed with its arguments swapped, so the defaults overrode the task's own values. It now calls `deep_merge(result[key], value)`.
- **`taskflow/statemachine.py`**: `batch_order_ok` required priorities to be non-decreasing within a batch. The docstring says non-increasing, so it now checks `current <= prev`.
- **`taskflow/resources.py`**: `ResourcePool.release` did `self.used -= 1` instead of subtracting the cost. Pools leaked capacity, which broke the resource-limited pipelines.
- **`taskflow/events.py`**: `_prefix_matches` tested `prefix.startswith(topic + ".")`, which is backwards. It now tests `topic.startswith(prefix + ".")`. This was why the history's failed, skipped and terminal-event queries came back empty.
- **`taskflow/scheduler.py`**: `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `dag.transitive_dependents`, so every downstream task gets skipped.
