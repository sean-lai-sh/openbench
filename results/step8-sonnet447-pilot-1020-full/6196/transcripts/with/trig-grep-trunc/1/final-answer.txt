`python3 -m unittest` now passes all 25 tests. I didn't modify any tests. I fixed seven logic bugs:

- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which stopped one attempt early. It is now `attempts_made < max_attempts`.
- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`, so the queue ignored priority. It is now `(-priority, seq)`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the base overrode the override. It now recurses with `(result[key], value)`.
- **`statemachine.py`:** `batch_order_ok` had its comparison backwards. It now requires `current <= prev`, which is non-increasing priority.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`, so pools leaked capacity and the resource tests failed.
- **`events.py`:** `_prefix_matches` had the prefix and topic swapped, so prefix subscribers never received `job.term.*` events and the history tests failed.
