| File | Bug | Fix |
|---|---|---|
| `taskflow/queue.py` | `_Entry.sort_key` returned `(seq, -priority)`, so insertion order beat priority. | Changed to `(-priority, seq)`. |
| `taskflow/retry.py` | `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. | Changed to `attempts_made < max_attempts`. |
| `taskflow/config.py` | `deep_merge` recursed with its arguments swapped, so the defaults overrode a task's own `retry` settings. | Now `deep_merge(result[key], value)`. |

| `taskflow/scheduler.py` | `_cascade_skip` used `dag.dependents`, which returns only direct children, so skips didn't reach grandchildren. | Now uses `dag.transitive_dependents`. |
| `taskflow/events.py` | `_prefix_matches` had its arguments reversed. `History` never saw `job.term.*` events, so its failed, skipped and succeeded sets and outcome counts were empty. | Now `topic.startswith(prefix + ".")`. |
