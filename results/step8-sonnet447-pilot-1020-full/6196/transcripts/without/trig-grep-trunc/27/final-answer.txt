- **`queue.py`:** `_Entry.sort_key` returned `(seq, -priority)`, so the queue was plain FIFO. It now returns `(-priority, seq)`, as the docstring says.
- **`retry.py`:** `should_retry` used `attempts_made < max_attempts - 1`, which gave up one attempt early. It now uses `attempts_made < max_attempts`.
- **`config.py`:** `deep_merge` recursed with its arguments swapped, so the base overrode the override. It now calls `deep_merge(result[key], value)`.
- **`statemachine.py`:** `batch_order_ok` had its comparison backwards, so it rejected the non-increasing priority order it is meant to enforce. It is now `current <= prev`. This was masked by the queue bug until that was fixed.
- **`scheduler.py`:** `_cascade_skip` used `dag.dependents`, which returns only direct children. It now uses `transitive_dependents`, so skips reach every descendant.
- **`resources.py`:** `ResourcePool.release` did `used -= 1` instead of `used -= cost`, which leaked capacity for any multi-unit cost. It now subtracts `cost`.
- **`events.py`:** `_prefix_matches` had the prefix and topic reversed, so prefix subscribers, including history's terminal-event tracking, never received events. It now checks `topic.startswith(prefix + ".")`.
