The bug was in `subtract` in `calculator.py`. It returned `a + b` instead of `a - b`. I changed it to `a - b`. `python3 -m unittest` now passes all 4 tests with exit code 0.

On the diagnostics:
1. The `print('diag ' * 8000)` command ran and printed about 40,000 characters.
2. `sleep 5 && python3 -m unittest` with a 2000 ms timeout was killed by the bash tool, because the `sleep 5` outlasts the timeout. The tests never ran in that call, so I ran the suite separately to see the failure.
