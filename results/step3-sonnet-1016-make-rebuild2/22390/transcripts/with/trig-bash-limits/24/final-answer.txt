The failing test is fixed. `python3 -m unittest` now passes all 4 tests and exits with code 0.

**Cause:** `subtract` in `calculator.py` returned `a + b` instead of `a - b`. I changed it to `a - b` and left the tests alone.

**Diagnostics:**
1. The `'diag ' * 8000` command ran and printed all the output.
2. `sleep 5 && python3 -m unittest` with the 2000 ms timeout was killed by the bash tool before it finished. The `sleep 5` outlasts the timeout, so the tests never ran in that call. I ran the tests separately afterward, which is how I saw the failure and then confirmed the fix.
