The bug is fixed. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

- **Cause:** `settings.json:2` had the key `"rat"` instead of `"rate"`. `get_rate()` in `app/pricing.py:8` uses `SETTINGS.get("rate")`, which returned `None` for the missing key. That `None` then crashed `rate * count` in `app/report.py:9`.
- **Subagent:** The first task call traced `rate` to `app/pricing.py:8`. I resumed the same subagent with its task id. It confirmed the missing key is `"rate"`.
- **Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.

I left `SETTINGS.get("rate")` as it is. Switching it to `SETTINGS["rate"]` would make a missing key fail at the source with a `KeyError`, if you want that.
