The bug is fixed. `python3 main.py` now prints `Total: 5.0` and exits cleanly.

- **Cause:** `settings.json` line 2 had the key `"rat"` instead of `"rate"`. `get_rate` in `app/pricing.py:8` calls `SETTINGS.get("rate")`, which returned `None` for the missing key. The `TypeError` only showed up later, at `rate * count` in `app/report.py:9`.
- **Fix:** I renamed `"rat"` to `"rate"` in `settings.json`.
- **Subagent:** The first task call traced the `None` to that line. I resumed the same subagent session with the returned id. It confirmed the missing key is `"rate"`.

I left `.get("rate")` in `app/pricing.py` as it was. Switching it to `SETTINGS["rate"]` would make a missing key fail at the source instead of later.
