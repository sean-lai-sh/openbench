- **Cause:** `settings.json` had the key `"rat"` instead of `"rate"`. `get_rate()` in `app/pricing.py` calls `SETTINGS.get("rate")`, which returned None for the missing key. That None then reached `rate * count` in `app/report.py`.
- **Fix:** I renamed the key to `"rate"` in `settings.json`.
- **Subagent steps:** The first task call worked. It put the None at `app/pricing.py` and named the `"rat"` typo. The second call didn't happen, because the first call returned no id and the task tool has no parameter for resuming a subagent. I checked the missing key myself by reading the files.
