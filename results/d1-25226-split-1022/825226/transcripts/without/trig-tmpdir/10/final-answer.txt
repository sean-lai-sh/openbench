`python3 main.py` now exits cleanly and prints `Hello, world!`.

There were two bugs:
- **`greeter.py`:** the function definition was missing its trailing colon (`def greet(name)`). I changed it to `def greet(name):`.
- **`main.py`:** it imported from a module called `greetings`, which doesn't exist. The file is `greeter.py`, so I changed the import to `from greeter import greet`.

I didn't use a separate scratch directory. The fixes were two one-line edits, so I made them directly in the project. Running the program also left a `__pycache__` folder in the project.
