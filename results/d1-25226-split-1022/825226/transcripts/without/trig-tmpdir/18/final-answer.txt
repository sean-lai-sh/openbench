`python3 main.py` now exits with status 0 and prints `Hello, world!`.

There were two bugs:
- **Wrong module name:** `main.py` imported from `greetings`, but the file is `greeter.py`. I changed the import to `from greeter import greet`.
- **Syntax error:** `def greet(name)` in `greeter.py` was missing its colon. I added it.

I didn't use a scratch directory, since both fixes were one-line edits and I verified them by running the program in place.
