### Verdict
- **The prompt line drives the behaviour change.** Under PROMPT-only, mktemp drops from 23/60 to 0/30 (p=1.9e-5) and opencode/ use rises from 0 to 9/30 (p=2e-5).
- **The pre-approval alone changes nothing.** PERM-only matches BASE on every measure (all p>=0.17).
- **The pre-approval is what prevents the rejections.** PROMPT-only sends the agent to a path that isn't approved, so rejections go up (9/30 vs 6/60, p=0.032) and solved goes down (21/30 vs 55/60, p=0.012). All 9 PROMPT failures are wrong_answer that ended on a rejection. The full PR, with prompt and pre-approval together, has 0 rejections.
- PROMPT-only shows "no leak" (combined 1/30) only because rejected attempts create nothing.
