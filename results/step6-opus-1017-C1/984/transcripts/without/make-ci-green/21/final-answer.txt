I fixed six bugs in `catalog/`, but I couldn't run `python3 -m unittest` because I have no shell here. I worked through the tests by reading them against the code, so please run the suite to confirm.

- **`search.py`**: it imported `normalize` from `catalog.nonexistent`, which doesn't exist. It now imports it from `catalog.text`.
- **`fees.py`**: the fee was days late *plus* the daily rate. It's now days late *times* the daily rate (`days_late * DAILY_FEE`).
- **`members.py`**: the borrowing limit was 3, but the comment and tests say 5. I changed `MAX_BORROWED` to 5.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns the last `n` events (`[-n:]`), and an empty list when `n <= 0`, because `[-0:]` would return the whole history.
- **`books.py`**: `parse_book` left the year as a string, so `age()` failed. The year is now converted with `int()`.
- **`factory.py`**: `sample_books()` was missing `Emma`. I added it as `Book("Emma", "Austen", 1815, 1)`. The tests only check the title, so the author, year and copy count are values I chose.

I didn't change any tests.
