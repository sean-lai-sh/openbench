I fixed six bugs in `catalog/` by reading the code against the tests, but I haven't run the suite. I only had file read/edit tools here, no shell, so I couldn't run `python3 -m unittest`. Tracing each test by hand, they should all pass now.

- **`search.py`**: imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`.
- **`fees.py`**: added the daily fee to the days late instead of multiplying. It's now `days_late * DAILY_FEE`.
- **`members.py`**: the borrow limit was set to 3, though the policy comment and tests say 5. It's now 5.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n` events, and an empty list if `n <= 0` (otherwise `[-0:]` would return the whole history).
- **`books.py`**: `parse_book` stored the year as a string, which also broke `age()`. It now converts it with `int(year)`.
- **`factory.py`**: the sample data was missing `Emma` (Austen, 1815), so it had two books instead of three.

Please run `python3 -m unittest` to confirm.
