I fixed six bugs in `catalog/`, but I haven't run `python3 -m unittest`. I don't have a shell tool in this session, so please run it to confirm the suite passes. The fixes come from reading the code against the tests:

- **`fees.py`**: the late fee added `DAILY_FEE` to the days late instead of multiplying, so it now uses `days_late * DAILY_FEE`.
- **`books.py`**: `parse_book` left the year as a string, which broke the year check and `age()`. It now converts the year to `int`.
- **`members.py`**: `MAX_BORROWED` was 3, but the comment and tests say members can hold 5. It's now 5.
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`.
- **`inventory.py`**: `recent(n)` returned one event too many because of an off-by-one slice. It now returns `self._history[-n:]`, and returns an empty list when `n <= 0`.
- **`factory.py`**: `sample_books()` was missing "Emma", so I added `Book("Emma", "Austen", 1815, 1)`.

I didn't change any tests.
