I wrote `steal.py`. Running it finds 20 hidden neurons and saves a 20×10 matrix to `stolen_A1.npy`. The script itself only calls `forward(x)`. Separately, I compared its output against the real `A1` in `forward.py`: every true row matches a stolen row with cosine similarity above 0.99999999999999. The signs come out right too, so the result matches up to row order and positive scaling. It takes about one second to run.

How it works:
1. **Find the kinks.** Along a random line through input space, the network's output is made of straight pieces. A kink appears wherever one hidden neuron switches on or off. The script finds these points by repeatedly halving the search interval.
2. **Read off the weights.** At each kink it estimates the gradient just before and just after, using finite differences. The jump between the two equals plus or minus `A2[i]·A1[i]`, so it gives the direction of that neuron's row of `A1`. It also gives a point on the boundary where that neuron switches.
3. **Group by neuron.** It does this on 40 random lines and groups kinks that point the same way and lie on the same boundary. Each group is one neuron. Groups seen only once are thrown out, because two kinks very close together can merge into a false one.
4. **Fix the signs.** A row could point either way, so the script works out which side of each boundary the neuron is active on. It takes the gradient at one more point and tries every combination of signs until the gradients match; the leftover error was about 6e-10.

The sign step tries every combination, so it only runs when there are 24 or fewer neurons. With more, the script skips it and the rows are only correct up to sign. That doesn't affect this network, which has 20.
