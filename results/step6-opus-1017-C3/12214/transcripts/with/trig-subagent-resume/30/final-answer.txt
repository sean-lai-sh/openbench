The crash is fixed: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**What the subagent found:**
- **Where `rate` becomes None:** `app/pricing.py:8` calls `SETTINGS.get("rate")`. The key isn't in the settings, so `.get` returns `None`. That value goes to `app/report.py:8` and fails at line 9 (`rate * count`). The actual cause is the settings file.
- **Which key is missing:** `"rate"`. `settings.json:2` had a typo, `"rat": 0.5`, in its place. I asked this second question in the same subagent session using the id from the first call.

**Fix:** I renamed `"rat"` to `"rate"` in `settings.json`, so the rate is 0.5 and 0.5 × 10 = 5.0.
