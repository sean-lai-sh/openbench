Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo. The key was `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py:8` returned `None`, and `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**The command you asked me to run first** (`python3 -c 'import pricing; ...'` from inside `app/`) didn't print a path. It failed with `ModuleNotFoundError: No module named 'app'`. That happens because `pricing.py` imports `from app.config import ...`, which only works when Python starts from the project root, the way `main.py` does. It's unrelated to the crash and I left it alone. If you need to import from inside `app/`, use `python3 -c 'import app.pricing'` from the root.

Separately, `get_rate()` still quietly returns `None` when the key is missing. If you'd like a clearer error next time, it could use `SETTINGS["rate"]` instead.
