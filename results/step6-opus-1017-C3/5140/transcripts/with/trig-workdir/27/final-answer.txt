The crash came from a typo in the config: `settings.json` spelled the key `"rat"` instead of `"rate"`. So `SETTINGS.get("rate")` in `app/pricing.py:8` returned `None`, and `report.py` then tried to multiply `None` by 10.

I renamed the key to `"rate"` in `settings.json`. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

You asked me to start by running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/`. That failed with `ModuleNotFoundError: No module named 'app'`. This is a separate issue, not the cause of the crash: `pricing.py` imports `app.config`, which only works when Python runs from the project root, the way `main.py` does. Running from the root works fine, so I left those imports alone.
