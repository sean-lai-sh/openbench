The crash was caused by a typo in the settings file, and it's fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** In `settings.json`, the rate was stored under the key `"rat"` instead of `"rate"`. So `SETTINGS.get("rate")` in `app/pricing.py` returned `None`, and `report.py` then failed trying to multiply `None` by 10.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**About the command you asked me to run first:** `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` didn't print a path. It failed with `ModuleNotFoundError: No module named 'app'`. Python did find `app/pricing.py`, but that file imports `from app.config import SETTINGS`, which only works when you run from the project root (as `main.py` does). This is separate from the crash. Running from inside `app/` just isn't how the project is set up to work.
