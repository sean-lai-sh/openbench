Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**About the first command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` gave `ModuleNotFoundError: No module named 'app'`. That's expected and isn't the bug. `app/pricing.py` imports with `from app.config import SETTINGS`, which only works when Python is started from the project root, as `main.py` is. The traceback did confirm that `pricing` is the local `app/pricing.py`.

**Cause of the crash:** `settings.json` had a typo in a key name: `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` reads the rate with `SETTINGS.get("rate")`, which quietly returns `None` when the key is missing. `compute_total` then tried `None * 10` and crashed.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changed.

To make a bad config fail with a clearer message next time, `get_rate()` could use `SETTINGS["rate"]`, or raise an error when the value is `None`. That way you'd get a `KeyError` naming the missing key instead of a confusing `TypeError` later on. I haven't made that change.
