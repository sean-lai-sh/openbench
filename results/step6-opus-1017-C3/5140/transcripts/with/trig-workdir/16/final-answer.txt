Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The command you asked for first:** `python3 -c 'import pricing; print(pricing.__file__)'` run from `app/` failed with `ModuleNotFoundError: No module named 'app'`. That's because `app/pricing.py` uses `from app.config import SETTINGS`, which only works when you run from the project root (as `main.py` does). It doesn't mean anything is broken, so I didn't change any imports. The traceback did confirm that `pricing` comes from `app/pricing.py`.

**Cause of the crash:** `settings.json` misspelled the key as `"rat": 0.5` instead of `"rate"`. So `SETTINGS.get("rate")` in `app/pricing.py:8` returned `None`, and `rate * count` in `app/report.py:9` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. 0.5 × 10 = 5.0, which matches the expected output.

`get_rate()` still returns `None` without complaint if the key goes missing again. If you want that to fail loudly instead, `pricing.py` could use `SETTINGS["rate"]`.
