Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The command you asked for first:** running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` failed with `ModuleNotFoundError: No module named 'app'`, so it never printed a path. The traceback does show it found `app/pricing.py`, but that file starts with `from app.config import SETTINGS`. That import only works when the project root (the folder above `app/`) is on Python's search path, which it isn't when you run from inside `app/`. This is separate from the crash, and running `main.py` from the root works. I didn't change it.

**Cause of the crash:** a typo in `settings.json`. The key was `"rat"` instead of `"rate"`, so `get_rate()` in `app/pricing.py` (which calls `SETTINGS.get("rate")`) got `None`. Multiplying that by the count in `app/report.py:9` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`, which is the only change. The program now computes 0.5 × 10 = 5.0.

`get_rate()` still returns `None` without any warning if the key is ever missing. If you'd rather it fail with a clear message, it could use `SETTINGS["rate"]` instead.
