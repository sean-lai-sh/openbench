Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**About the first command:** running `python3 -c 'import pricing; ...'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. Python did find `app/pricing.py`, but that file starts with `from app.config import SETTINGS`. That import only works when the project root is on the path, which is how `main.py` is meant to run. This isn't a bug, and it isn't what caused the crash.

**Root cause:** `settings.json` had a typo in a key name, `"rat": 0.5` instead of `"rate": 0.5`. So `SETTINGS.get("rate")` in `app/pricing.py:8` returned `None`, and `compute_total` then tried to multiply `None * 10`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. I didn't change any code.
