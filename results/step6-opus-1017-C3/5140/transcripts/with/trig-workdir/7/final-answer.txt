The crash is fixed: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**First command:** `python3 -c 'import pricing; print(pricing.__file__)'` failed when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. Python did find `app/pricing.py`, but that file starts with `from app.config import SETTINGS`. Imports written that way only work when you run from the project root, which is what `main.py` does. That's how the code is meant to be run, not the cause of the crash.

**Cause of the crash:** `settings.json` misspelled the key as `"rat"` instead of `"rate"`. So `SETTINGS.get("rate")` in `app/pricing.py:8` found nothing and returned `None`, and `rate * count` in `app/report.py:9` then raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`, which was the only change. 0.5 × 10 = 5.0.

Because `get_rate()` uses `.get()`, a missing setting turns into `None` and only fails later, during the multiplication. If you'd like it to fail right away with a clear error, `SETTINGS["rate"]` would raise a `KeyError` that names the missing key.
