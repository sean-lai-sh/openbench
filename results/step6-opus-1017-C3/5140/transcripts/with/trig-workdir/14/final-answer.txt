The script runs now. `python3 main.py` prints `Total: 5.0` and exits with code 0.

**About the command you asked for first:** running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` failed with `ModuleNotFoundError: No module named 'app'`. It did find the file (`app/pricing.py`), but that file imports `from app.config import SETTINGS`, which only works when `app` is imported as a package from the project root, the way `main.py` does it. This is unrelated to the crash, so I left it alone.

**Cause of the crash:** `settings.json` had a typo in a key name: `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which quietly returns `None` when the key is missing, and `report.compute_total` then failed trying to multiply `None` by 10.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changed.

Because `.get()` hides a missing key, a typo like this only shows up later as a confusing `None` error. If you'd rather it fail right away with a clear `KeyError`, `get_rate()` could use `SETTINGS["rate"]` instead.
