I fixed it: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**First command:** `python3 -c 'import pricing; ...'` failed when run from `app/` with `ModuleNotFoundError: No module named 'app'`. That isn't the bug you hit. `pricing.py` imports `app.config`, so the package can only be imported from the project root, which is how `main.py` loads it.

**Cause of the crash:** `settings.json` had a typo. The key was `"rat": 0.5` instead of `"rate"`. So `pricing.get_rate()` called `SETTINGS.get("rate")`, got `None`, and `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`, which gives 0.5 × 10 = 5.0.

`get_rate()` still returns `None` without any warning if the key is missing. If you'd rather a bad config fail loudly, change it to `SETTINGS["rate"]`, which raises a `KeyError` naming the missing key.
