**The command you asked for first:** `python3 -c 'import pricing; print(pricing.__file__)'` run from `app/` doesn't print a path. It fails with `ModuleNotFoundError: No module named 'app'`. The traceback still shows the file is `app/pricing.py`. It fails because that file imports `from app.config import SETTINGS`, which only works when run from the project root, as `main.py` is. That's how the project is meant to be run, and it has nothing to do with the crash.

**Root cause:** `settings.json` had a typo. The key was `"rat": 0.5` instead of `"rate": 0.5`. So `pricing.get_rate()` (`SETTINGS.get("rate")`) returned `None`, and `rate * count` in `app/report.py:9` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

`get_rate()` still quietly returns `None` if the key is missing. Switching it to `SETTINGS["rate"]` would make a bad config fail right away with a clearer error, but I haven't changed it.
