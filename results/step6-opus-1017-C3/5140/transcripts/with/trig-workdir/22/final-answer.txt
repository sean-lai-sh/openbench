I fixed it: the rate key in `settings.json` was misspelled as `"rat"`, and correcting it to `"rate"` makes `python3 main.py` print `Total: 5.0` and exit with code 0.

**The command you asked me to run first:** `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`, so it didn't print a path. `app/pricing.py` was found, but it imports `from app.config import SETTINGS`. That kind of import only works when you run from the project root, which is how `main.py` runs. It's unrelated to the crash.

**Why it crashed:** `app/pricing.py:8` reads the rate with `SETTINGS.get("rate")`. Because the key in the file was `"rat"`, that returned `None` instead of a number. `app/report.py:9` then tried to multiply `None * 10`, which caused the `TypeError`. With the key fixed, the rate is 0.5 and the total is 0.5 × 10 = 5.0.

I didn't change any code. If you want a typo like this to give a clear error instead of an unexplained `None`, `get_rate()` could use `SETTINGS["rate"]`, which fails right away when the key is missing.
