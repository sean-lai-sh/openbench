Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**About the first command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` failed with `ModuleNotFoundError: No module named 'app'`, so it never printed a path. That's because `app/pricing.py` imports `from app.config import SETTINGS`, which only works when you run from the project root, the way `main.py` does. It isn't related to the crash, and I didn't change it.

**Cause of the crash:** `settings.json` had a typo in the key name: `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which returned `None` instead of failing loudly. `compute_total` then tried to multiply `None * 10`.

**Fix:** I renamed the key to `"rate"` in `settings.json`, so the result is 0.5 × 10 = 5.0.

If you want missing config to fail with a clearer error in future, `get_rate()` could use `SETTINGS["rate"]` instead of `.get("rate")`. A missing key would then raise a `KeyError` naming it, rather than a confusing `TypeError` further down. I didn't make that change.
