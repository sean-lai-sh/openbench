I fixed it: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**First command:** `python3 -c 'import pricing; ...'` failed when run from `app/` with `ModuleNotFoundError: No module named 'app'`. The code imports its own files as `from app.config import ...`, which only works when Python starts from the project root, where `main.py` is. That's how the program is meant to be run, so this error isn't a bug.

**The crash:** `settings.json` had a typo. The key was spelled `"rat"` instead of `"rate"`. So `SETTINGS.get("rate")` in `app/pricing.py` found nothing and returned `None`, and `None * 10` raised the `TypeError` in `app/report.py:9`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

`get_rate()` still returns `None` without any warning if the key is missing, so a similar typo would crash the same way. Changing it to `SETTINGS["rate"]` would make it fail straight away with a clear `KeyError`. I didn't make that change.
