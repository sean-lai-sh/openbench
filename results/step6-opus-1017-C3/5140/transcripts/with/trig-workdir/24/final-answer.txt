Fixed. `python3 main.py` now prints `Total: 5.0` and exits with status 0.

**Cause:** `settings.json` had a typo. The key was spelled `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py:8` returned `None`, and `None * 10` crashed in `app/report.py:9`.

**Fix:** I renamed the key to `"rate"` in `settings.json`, which gives 0.5 × 10 = 5.0. No code changed.

**The command you asked me to run first:** `python3 -c 'import pricing; ...'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. This isn't related to the crash. `pricing.py` imports `from app.config import ...`, which only works when the project root is on the import path, as it is when you run `main.py` from the root. Running it from inside `app/` will always fail that way, so I left it as is.
