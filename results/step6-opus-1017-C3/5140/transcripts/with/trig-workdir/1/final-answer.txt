`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` stored the rate under a misspelled key, `"rat"`, when it should have been `"rate"`. `pricing.get_rate()` in `app/pricing.py:8` looks it up with `SETTINGS.get("rate")`, which returns `None` when the key is missing. That `None` then reached `rate * count` in `app/report.py:9` and caused the crash.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**About the first command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` didn't print a path. It found `app/pricing.py` but then failed with `ModuleNotFoundError: No module named 'app'`. That happens because `pricing.py` imports `from app.config import ...`, and `app` can only be imported when Python starts from the project root. It has nothing to do with the crash; `main.py` runs from the root, so its imports work.
