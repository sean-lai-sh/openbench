The crash is fixed: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**First command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from `app/` failed with `ModuleNotFoundError: No module named 'app'`. This isn't a separate bug. `app/pricing.py` imports `from app.config import SETTINGS`, which only works when the project root is on the path, as it is when you run `main.py` from the root. It still told me that `pricing` comes from `app/pricing.py`, not from somewhere else on the path.

**Cause:** `settings.json` had a typo. The key was `"rat": 0.5` instead of `"rate"`. So `SETTINGS.get("rate")` in `app/pricing.py` returned `None`, and `rate * count` in `app/report.py` then raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.
