The script works now. `python3 main.py` prints `Total: 5.0` and exits with code 0.

**The cause:** `settings.json` misspelled the key as `"rat"` instead of `"rate"`. `pricing.get_rate()` looks it up with `SETTINGS.get("rate")`, which returns `None` when the key is missing. `report.compute_total` then tried to multiply `None * 10`, which raised the error.

**The fix:** I renamed the key to `"rate"` in `settings.json`, so the rate of 0.5 times 10 items gives 5.0. That was the only change.

**About the command you asked me to run first:** `python3 -c 'import pricing; ...'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`, so it never printed a path. `app/pricing.py` imports `from app.config import SETTINGS`, which only works when Python runs from the project root, the way `main.py` runs it. This is separate from the crash you reported and doesn't affect `main.py`, so I left it alone.
