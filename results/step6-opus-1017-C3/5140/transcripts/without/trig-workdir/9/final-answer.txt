`python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The command you asked me to run first:** `python3 -c 'import pricing; ...'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. That's because `app/pricing.py` imports `from app.config`, which only works when the project root is on the import path, as it is when `main.py` runs. It's a side effect of the folder layout and has nothing to do with the crash, so I left it alone.

**Cause of the crash:** a typo in `settings.json`. The setting was named `"rat"` instead of `"rate"`. So `pricing.get_rate()`, which calls `SETTINGS.get("rate")`, got `None` back, and `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. 0.5 × 10 = 5.0, which matches the expected output.

If you'd like a clearer error next time a setting is missing, `get_rate()` could use `SETTINGS["rate"]` instead, so it fails with a `KeyError` naming the missing key rather than returning `None`. I didn't make that change.
