I fixed the crash: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**About the first command:** `python3 -c 'import pricing; print(pricing.__file__)'` failed when run from `app/`, with `ModuleNotFoundError: No module named 'app'`. That's because `app/pricing.py` imports `from app.config import SETTINGS`, which only works when the project root is the working directory. So it never printed a file path. This is a separate issue from the crash and I left the imports alone, since `main.py` runs from the root as intended.

**Cause of the crash:** `settings.json` misspelled the key as `"rat"` instead of `"rate"`. As a result, `pricing.get_rate()` (`SETTINGS.get("rate")`) returned `None`, and `rate * count` in `app/report.py:9` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.
