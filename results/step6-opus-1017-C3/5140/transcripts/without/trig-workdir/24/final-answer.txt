The crash is fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had the key misspelled as `"rat"` instead of `"rate"`. `pricing.get_rate()` looks it up with `SETTINGS.get("rate")`, which returned `None` when the key was missing. `report.compute_total` then tried to multiply `None` by 10, which raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. I didn't change any code.

**The command you asked me to run first:** `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. That's because `pricing.py` imports `from app.config import ...`, which only resolves when you run from the project root, as `main.py` does. It has nothing to do with the crash, and I left it as is.

One thing you might want to change: `get_rate()` quietly returns `None` when the key is missing, so a config typo only shows up later as a confusing error. Using `SETTINGS["rate"]` would fail straight away with a clear `KeyError: 'rate'`.
