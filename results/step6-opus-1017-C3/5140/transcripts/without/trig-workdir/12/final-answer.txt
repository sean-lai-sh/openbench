I fixed the crash: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Cause:** `settings.json` had a typo. The key was spelled `"rat"` instead of `"rate"`, so `pricing.get_rate()` (`SETTINGS.get("rate")`) returned `None`. Multiplying that by the count is what crashed `compute_total`. Renaming the key to `"rate"` was the only change.

**The first command you asked for failed.** Running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` stopped with `ModuleNotFoundError: No module named 'app'`. That's because `pricing.py` imports `from app.config import ...`, and the `app` package can only be found when Python runs from the project root. It's unrelated to the crash, but it means that command didn't print a file path. From the project root, `python3 -c 'import app.pricing as p; print(p.__file__)'` should work instead.
