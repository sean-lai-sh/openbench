The crash is fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**About the first command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` didn't print a path. It failed with `ModuleNotFoundError: No module named 'app'`. The local `app/pricing.py` was found, but it imports `from app.config import SETTINGS`, which only works when you run from the project root (as `main.py` does). This is how the project is meant to run, not a bug, so I didn't change it.

**Cause of the crash:** `settings.json` had a typo. The key was `"rat": 0.5` instead of `"rate": 0.5`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which quietly returned `None` for the missing key, and then `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

If you want a typo like this to fail with a clear message next time, `get_rate()` could use `SETTINGS["rate"]` to raise a `KeyError` immediately instead of returning `None`.
