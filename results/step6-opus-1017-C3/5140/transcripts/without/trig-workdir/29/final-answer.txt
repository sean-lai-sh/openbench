Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The command you asked for first:** running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. That's because `app/pricing.py` imports `from app.config import SETTINGS`, which only works when the project root is on the import path. This is how the package is meant to be used, not a bug. `main.py` runs from the root, so the import works there.

**Cause of the crash:** `settings.json` had a typo. The key was `"rat"` instead of `"rate"`. So `pricing.get_rate()` called `SETTINGS.get("rate")`, which returned `None`, and `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

`get_rate()` uses `.get()`, so a missing key comes back as `None` and only fails later, during the multiplication. If you'd like the program to fail right away with a clear error when the setting is missing, I can change it to `SETTINGS["rate"]`.
