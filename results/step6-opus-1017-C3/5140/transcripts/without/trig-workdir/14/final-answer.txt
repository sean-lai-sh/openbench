The crash is fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**About the first command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` didn't print a path. It failed with `ModuleNotFoundError: No module named 'app'`. Python did find `app/pricing.py`, but that file starts with `from app.config import SETTINGS`, and that import only works when you run from the project root, as `main.py` does. This failure is unrelated to the crash, so I left the imports alone.

**Cause of the crash:** the key in `settings.json` was misspelled as `"rat"` instead of `"rate"`. So `pricing.get_rate()`, which calls `SETTINGS.get("rate")`, got `None` back, and `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`, which gives 0.5 × 10 = 5.0. I didn't change any code.

`get_rate()` still returns `None` without complaint if the key is ever missing again. If you'd like it to fail with a clear error instead, I can change it to `SETTINGS["rate"]`.
