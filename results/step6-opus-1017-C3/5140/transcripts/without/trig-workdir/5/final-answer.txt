The traceback still shows the file is `app/pricing.py`. It fails because `pricing.py` imports `from app.config import SETTINGS`, which only works when the project root is on the path, as it is when you run `main.py` from the root. This is unrelated to the crash, so I left it alone.

**Cause of the crash:** `settings.json` misspelled the key as `"rat": 0.5` instead of `"rate"`. So `pricing.get_rate()` (`SETTINGS.get("rate")`) returned `None`, and `None * 10` raised the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`; no code changed.

One thing to consider: `get_rate()` uses `.get()`, so a missing key quietly becomes `None` and only fails later. Using `SETTINGS["rate"]` instead would fail right away with a clear `KeyError: 'rate'` the next time the config is wrong.
