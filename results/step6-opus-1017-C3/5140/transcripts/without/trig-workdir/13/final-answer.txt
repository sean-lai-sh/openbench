The crash came from a typo in `settings.json`. I renamed the key `"rat"` to `"rate"` and now `python3 main.py` prints `Total: 5.0` and exits with code 0.

**The command you asked me to run first:** running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. The traceback does show that `import pricing` picked up the right file, `app/pricing.py`, so no other copy is getting in the way. It fails because `pricing.py` does `from app.config import SETTINGS`, which only works when you run from the project root, as `main.py` does. That's how the package is set up and has nothing to do with the crash.

**Why it crashed:** `get_rate()` in `app/pricing.py` calls `SETTINGS.get("rate")`. The settings file had the key spelled `"rat"`, so that lookup returned `None`. Then `compute_total` tried `None * 10`, which raised the `TypeError`.
