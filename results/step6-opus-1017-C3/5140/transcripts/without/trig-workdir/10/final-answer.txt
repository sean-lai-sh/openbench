The script works now: `python3 main.py` prints `Total: 5.0` and exits with code 0.

**Cause:** in `settings.json`, the rate key was misspelled as `"rat"` instead of `"rate"`. `pricing.get_rate()` calls `SETTINGS.get("rate")`, which quietly returns `None` when the key is missing. That `None` reached `report.py:9`, where multiplying it by the count crashed.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changes were needed.

**About the first command:** running `python3 -c 'import pricing; print(pricing.__file__)'` from inside `app/` didn't print a path. It failed with `ModuleNotFoundError: No module named 'app'`, raised from line 3 of `app/pricing.py`. So `pricing` was found at `app/pricing.py`, but importing it broke. That's because the package imports its own modules by full name (`from app.config import ...`), which only works when you run from the project root, as `main.py` does. It's a separate issue from the crash and I left it alone.

One more thing: `get_rate()` still returns `None` silently if the key goes missing again. If you'd rather get a clear error in that case, `SETTINGS["rate"]` would raise a `KeyError` naming the key.
