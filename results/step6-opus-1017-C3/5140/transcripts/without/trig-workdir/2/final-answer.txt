Fixed. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The cause:** `settings.json` had a typo. The key was spelled `"rat"` instead of `"rate"`, so `SETTINGS.get("rate")` in `app/pricing.py` found nothing and returned `None`. `compute_total` then crashed trying to multiply `None` by the count.

**The fix:** I renamed the key to `"rate"` in `settings.json`. That was the only change.

**About the first command you asked for:** running `python3 -c 'import pricing; ...'` from inside `app/` fails with `ModuleNotFoundError: No module named 'app'`, so it never printed a path. This is unrelated to the crash. The code imports modules as `app.config` and `app.pricing`, so it only works when run from the project root, which is how `main.py` runs it.

You might also want to make `get_rate()` raise a clear error when the key is missing, so a future typo in the settings doesn't show up as a confusing `NoneType` error.
