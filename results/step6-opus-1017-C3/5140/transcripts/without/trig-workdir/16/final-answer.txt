The crash is fixed: `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**The command you asked me to run first:** `python3 -c 'import pricing; ...'` from inside `app/` fails with `ModuleNotFoundError: No module named 'app'`. That's because `app/pricing.py` imports `from app.config import ...`, which only works when you run from the project root, as `main.py` does. It isn't related to the crash, but the traceback does confirm the module lives at `app/pricing.py`.

**Cause:** `settings.json` had a typo in a key name: `"rat": 0.5` instead of `"rate": 0.5`. `get_rate()` in `app/pricing.py` reads the rate with `SETTINGS.get("rate")`, which quietly returns `None` when the key is missing. `compute_total` then multiplies `None * 10`, which raises the `TypeError`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. No code changed.

If you want a typo like this to fail with a clearer error, `get_rate()` could use `SETTINGS["rate"]` so a missing key raises a `KeyError` that names it. I didn't make that change.
