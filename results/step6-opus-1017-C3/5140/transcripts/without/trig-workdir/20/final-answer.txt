The fix was one character: `settings.json` had the key `"rat"` where it should have been `"rate"`. I renamed it, and `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**Why it crashed:** `pricing.get_rate()` in `app/pricing.py:8` reads the value with `SETTINGS.get("rate")`. Because the key was misspelled, `.get()` returned `None` instead of raising an error. That `None` then hit `rate * count` in `app/report.py:9`, which is where the traceback appeared.

**About the first command:** running `python3 -c 'import pricing; ...'` from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`, so it never printed a file path. It failed because `pricing.py` imports `from app.config import SETTINGS`, and that only works when the project root is on the import path. This doesn't affect the real program, since `main.py` runs from the root, and I didn't change it.

**Optional hardening:** you could change `get_rate()` to use `SETTINGS["rate"]`, or add a check, so a missing key fails right away with a clear error. I didn't make that change because it wasn't needed for the fix.
