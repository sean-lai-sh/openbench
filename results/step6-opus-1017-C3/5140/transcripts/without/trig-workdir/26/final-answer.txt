I fixed it. `python3 main.py` now prints `Total: 5.0` and exits with code 0.

**First command:** `python3 -c 'import pricing; print(pricing.__file__)'` run from inside `app/` failed with `ModuleNotFoundError: No module named 'app'`. That happens because `app/pricing.py` imports `from app.config import ...`, which only works when you run from the project root, as `main.py` does. The traceback did show that `pricing` loads from `app/pricing.py`. This error has nothing to do with the crash.

**Cause of the crash:** `settings.json` had a typo. The key was `"rat": 0.5` instead of `"rate": 0.5`. So `pricing.get_rate()` looked up `"rate"`, found nothing and returned `None`, and `report.compute_total` then failed on `None * 10`.

**Fix:** I renamed the key to `"rate"` in `settings.json`. 0.5 × 10 gives 5.0. That's the only change; no code was edited.

`get_rate()` still quietly returns `None` when the key is missing, so a similar config typo would crash the same way. If you'd like, I can change it to raise a clear error that names the missing setting.
