**Root cause:** a typo in `settings.json`. The key was `"rat": 0.5` instead of `"rate": 0.5`. In `app/pricing.py`, `get_rate()` looks up `SETTINGS.get("rate")`, which returned `None` because the key didn't exist. `compute_total` then tried to multiply `None * 10`, which caused the crash.

**Fix:** I renamed the key to `"rate"` in `settings.json` (line 2). I didn't change any code.

`get_rate()` will still return `None` without warning if that key is ever missing. Using `SETTINGS["rate"]` instead would make a config mistake like this fail straight away with a clear `KeyError`. body
