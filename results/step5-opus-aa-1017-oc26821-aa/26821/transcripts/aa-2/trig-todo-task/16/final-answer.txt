The whole suite now passes: `python3 -m unittest` runs 16 tests with no failures. Before, it ran 15, because `test_search` couldn't be imported and counted as a single error. I didn't touch the tests.

I fixed six bugs in `catalog/`:

- **`books.py`**: `parse_book` kept the year as text (`"1965"`), so the year check failed and `age()` crashed. It now converts the year to a number.
- **`factory.py`**: `sample_books()` was missing the third book, so I added `Book("Emma", "Austen", 1815, 1)`. The test only checks the title, so the author, year and copies are my own choice.
- **`fees.py`**: the late fee added the daily rate to the number of days instead of multiplying, so one day late cost 1.25 instead of 0.25.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns the last `n`, and an empty list when `n` is 0 or less.
- **`members.py`**: the borrowing limit was 3, but the comment above it and the tests both say 5. A subagent investigated this one and found that single number caused both failures in `test_members`.
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`, where the function actually lives.

I tracked the work with the todo list throughout.
