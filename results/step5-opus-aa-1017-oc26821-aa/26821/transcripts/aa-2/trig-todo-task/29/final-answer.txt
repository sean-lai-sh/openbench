All 16 tests now pass with `python3 -m unittest`. I didn't change the tests. There were 15 before because `test_search.py` couldn't be imported and counted as one error; now its two real tests run.

Fixes in `catalog/`:
- **`search.py`**: it imported `normalize` from `catalog.nonexistent`, which doesn't exist. It now imports it from `catalog.text`.
- **`books.py`**: `parse_book` kept the year as a string, which also broke `age()`. It now converts the year with `int(year)`.
- **`factory.py`**: `sample_books()` was missing `Emma`, the third title its docstring promises. I added `Book("Emma", "Austen", 1815, 1)`.
- **`fees.py`**: the fee was days late *plus* the daily rate (`days_late + DAILY_FEE`). It now multiplies them (`days_late * DAILY_FEE`).
- **`inventory.py`**: a subagent looked into this one. `recent(n)` returned one event too many because the slice was `[-n - 1:]`. It is now `[-n:] if n > 0 else []`. The `n > 0` guard is extra: without it, `recent(0)` would return the whole history. No test covers that case.
- **`members.py`**: `MAX_BORROWED` was set to 3, but the comment above it and the tests both say 5. I changed it to 5.
