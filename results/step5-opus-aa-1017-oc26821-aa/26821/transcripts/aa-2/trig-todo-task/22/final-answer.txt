The whole suite passes now: `python3 -m unittest` ran 16 tests, all OK. I didn't change any test files.

I had a subagent work out why `tests/test_members.py` was failing, while I fixed the other files. I tracked progress with the todo list.

What I changed in `catalog/`:
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`. This one error had kept the whole search test file from loading.
- **`books.py`**: `parse_book` left the year as a string. It now converts it to a number.
- **`factory.py`**: added the missing third sample book, `Emma` (Austen, 1815). The tests only check the title, so I picked the author, year and copy count (1).
- **`fees.py`**: the late fee added the daily rate to the number of days instead of multiplying, so 1 day late cost 1.25 instead of 0.25. It now multiplies.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`. I also made it return an empty list when `n` is 0 or less; otherwise `recent(0)` would have returned the whole history.
- **`members.py`** (found by the subagent): the borrowing limit was set to 3, but the code comment and the tests say 5. Changed it to 5.
