I fixed six bugs in `catalog/`, and `python3 -m unittest` now passes all 16 tests. I didn't change any test files. The first run reported 15 tests because `tests/test_search.py` couldn't be imported, so its 2 tests never ran.

**Fixes:**
- **`catalog/search.py`:** it imported `normalize` from a module that doesn't exist, `catalog.nonexistent`. It now imports it from `catalog.text`, which is where the function lives.
- **`catalog/books.py`:** `parse_book` stored the year as text. It now converts it to a number, which also fixes `age()`.
- **`catalog/factory.py`:** `sample_books()` was missing `Emma`. I added it as `Book("Emma", "Austen", 1815, 1)`. The test only checks the title, so I chose the author, year and copy count.
- **`catalog/fees.py`:** the late fee added the daily rate to the number of days instead of multiplying (`days + 0.25` instead of `days * 0.25`).
- **`catalog/inventory.py`:** `recent(n)` returned one event too many. A subagent investigated this one. My fix also makes `recent(0)` return an empty list; a plain slice would have returned the whole history.
- **`catalog/members.py`:** the borrowing limit was 3, but the comment in the file and the tests say 5.

I tracked each failure in the todo list.
