`python3 -m unittest` now passes all 16 tests. The first run reported 15 because `test_search.py` couldn't be imported at all; with that fixed, its two tests ran too. I didn't change any tests.

I used the todo list to track progress and gave the `test_members.py` investigation to a subagent. It found the cause there, and I made that fix along with the others:

- **`catalog/members.py`**: `MAX_BORROWED` was 3, but the comment and the tests both say members can hold 5 books. Changed it to 5.
- **`catalog/books.py`**: `parse_book` kept the year as a string, which also broke `age()`. It now converts it with `int(year)`.

- **`catalog/fees.py`**: the fee added the daily rate to the number of days instead of multiplying, so it's now `days_late * DAILY_FEE`.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many (`[-n - 1:]`), so it's now `[-n:]`. I also made it return `[]` when `n <= 0`, because `[-0:]` would otherwise return the whole history.
- **`catalog/search.py`**: it imported from `catalog.nonexistent`, which doesn't exist. It now imports from `catalog.text`, where `normalize` actually lives.
