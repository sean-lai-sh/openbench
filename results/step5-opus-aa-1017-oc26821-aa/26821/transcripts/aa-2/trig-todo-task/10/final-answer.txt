I fixed six bugs in `catalog/`, and `python3 -m unittest` now passes all 16 tests. I didn't change any test files. (The first run only reported 15 tests because `test_search.py` couldn't be imported.)

| File | Bug | Fix |
|---|---|---|
| `catalog/search.py` | Imported `normalize` from `catalog.nonexistent`, a module that doesn't exist | Import it from `catalog.text` |
| `catalog/books.py` | `parse_book` kept the year as a string | Convert it with `int(year)` |
| `catalog/factory.py` | `sample_books()` was missing Emma, which its docstring lists | Added `Book("Emma", "Austen", 1815, 1)` |
| `catalog/fees.py` | Fee was days late **plus** the daily rate | Changed to days late **times** the daily rate |
| `catalog/inventory.py` | `recent(n)` returned one event too many | Changed the slice to `[-n:]`, and return `[]` when `n <= 0` |
| `catalog/members.py` | `MAX_BORROWED = 3`, but the comment and tests say members can hold five books | Set it to 5 |

As you asked, a subagent investigated `test_inventory.py`. It found the off-by-one in `recent()`. It also pointed out that the plain `[-n:]` fix would return the whole history when `n` is 0, so I added the `n <= 0` check.
