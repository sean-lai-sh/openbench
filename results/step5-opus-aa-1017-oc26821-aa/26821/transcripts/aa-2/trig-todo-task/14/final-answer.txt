The suite now passes: `python3 -m unittest` ran all 16 tests with no failures. I only changed files in `catalog/`; the tests are untouched.

There were six bugs, one in each of six files:

- **`catalog/search.py`**: it imported `normalize` from a module that doesn't exist, `catalog.nonexistent`. I pointed it at `catalog.text`, where `normalize` actually lives. Because of the broken import, the search tests couldn't load at all, which is why the first run reported 15 tests and this one reports 16.
- **`catalog/books.py`**: `parse_book` kept the year as text (`'1965'`). It now converts it to a number.
- **`catalog/factory.py`**: `sample_books()` was missing the third book its docstring promises. I added `Book("Emma", "Austen", 1815, 1)`. The author, year and copy count are my choice; the tests only check the title.
- **`catalog/fees.py`**: the late fee added the daily rate to the number of days (`days_late + DAILY_FEE`) instead of multiplying them. One day late now costs 0.25 and four days cost 1.00.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`. I also made it return nothing when `n` is 0 or less; without that, `recent(0)` would return the whole history.
- **`catalog/members.py`**: the borrowing limit was set to 3, but the comment above it and the tests both say 5. A subagent investigated these failures, and I applied the fix it identified.
