- **`catalog/inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`, and an empty list when `n` is 0 or less.
- **`catalog/members.py`**: the borrowing limit was set to 3, while the policy comment in the file and the tests both say 5. I set `MAX_BORROWED = 5`.
