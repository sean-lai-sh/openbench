Fixes:
- **`catalog/search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). I changed it to import from `catalog.text`, where `normalize` is defined. This was why one test file failed to load.
- **`catalog/books.py`**: `parse_book` kept the year as text (`'1965'`). It now converts it to a number (`int(year)`).
- **`catalog/factory.py`**: added the missing `Book("Emma", "Austen", 1815, 1)`, so the sample catalog has the three books its docstring describes.
- **`catalog/fees.py`**: the fee was days late *plus* the daily rate. It's now days late *times* the daily rate (`days_late * DAILY_FEE`).
- **`catalog/inventory.py`**: `recent(n)` returned one event too many (`[-n-1:]`). It now returns the last `n` events. I also made `recent(0)` or a negative `n` return an empty list; without that guard, `[-0:]` would return the whole history.
- **`catalog/members.py`**: the subagent found that the borrow limit was set to 3, while both the comment and the tests say 5. I changed `MAX_BORROWED` to 5.
