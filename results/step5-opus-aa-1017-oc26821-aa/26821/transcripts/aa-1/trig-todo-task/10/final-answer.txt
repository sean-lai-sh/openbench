The whole suite now passes: `python3 -m unittest` runs 16 tests with no failures. I only changed files in `catalog/`; the tests are untouched. Before the fixes it ran 15, because `tests/test_search.py` couldn't be imported and its two tests counted as one error.

I sent `tests/test_search.py` to a subagent. It found one bug, a bad import. Its other files were already correct.

The six fixes:
- **`catalog/search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports from `catalog.text`.
- **`catalog/books.py`**: `parse_book` left the year as text. It now converts it to a number, so `year` compares correctly and `age()` works.
- **`catalog/factory.py`**: added the missing `Emma` (Austen, 1815) to the sample books, as its docstring says.
- **`catalog/fees.py`**: the late fee was days plus the daily rate; it's now days times the rate.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many. It now returns the last `n` events, and an empty list when `n <= 0`. Without that check, `recent(0)` would have returned the whole history.
- **`catalog/members.py`**: `MAX_BORROWED` was 3; it's now 5, which matches both the comment and the tests.
