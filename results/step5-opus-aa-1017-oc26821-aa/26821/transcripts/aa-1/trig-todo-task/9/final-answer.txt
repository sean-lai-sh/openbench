The whole suite now passes: `python3 -m unittest` runs 16 tests with no failures. At first only 15 tests ran, because `tests/test_search.py` couldn't be imported. I didn't change any tests.

I fixed six bugs in `catalog/`:

- **`books.py`**: `parse_book` kept the year as a string, so `age()` crashed when subtracting it. It now converts the year to a number with `int(year)`.
- **`factory.py`**: `sample_books()` was missing `Emma`. Its own description lists three titles, and the tests expect all three.
- **`fees.py`**: the late fee was days *plus* the daily rate, so one day late cost 1.25. It now multiplies days by the 0.25 daily rate.
- **`inventory.py`**: `recent(n)` returned one event too many. It now returns exactly the last `n`, and an empty list if `n` is 0 or less.
- **`members.py`**: the borrowing limit was set to 3, but the comment beside it says five and so do the tests. I changed it to 5. A subagent looked into this test file and found the cause.
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`, where the function is defined.
