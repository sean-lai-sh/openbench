All 16 tests now pass with `python3 -m unittest`. The first run counted only 15 because `test_search` couldn't be imported at all. I didn't change any tests.

What I fixed in `catalog/`:

- **`search.py`**: it imported `normalize` from `catalog.nonexistent`, a module that doesn't exist. It now imports it from `catalog.text`.
- **`books.py`**: `parse_book` left the year as a string. It now converts it to a number with `int(year)`.
- **`factory.py`**: `sample_books()` was missing the third demo book that its docstring mentions, `Book("Emma", "Austen", 1815, 1)`. I added it.
- **`fees.py`**: the fee added the daily rate instead of multiplying by it. It's now `days_late * DAILY_FEE`.
- **`inventory.py`**: `recent(n)` returned one event too many. It now slices `[-n:]` and returns an empty list when `n` is 0 or less, since `[-0:]` would return the whole history.
- **`members.py`**: `MAX_BORROWED` was 3, but the comment above it and the tests say members can hold five books. It's now 5. A subagent investigated the `test_members` errors and found this cause.

I tracked the work in the todo list throughout.
