The whole suite passes now: `python3 -m unittest` ran 16 tests, all OK. I didn't touch the tests. The first run reported 15 tests because `test_search.py` couldn't be imported and counted as one error; once it loaded, its two tests ran too.

Fixes in `catalog/`:
- **`search.py`**: it imported `normalize` from a module that doesn't exist (`catalog.nonexistent`). It now imports it from `catalog.text`.
- **`books.py`**: `parse_book` left the year as a string. It now converts it with `int(year)`.
- **`factory.py`**: added the missing `Emma` (Austen, 1815) to `sample_books()`, which the docstring says should have three titles.
- **`fees.py`**: the fee was `days_late + DAILY_FEE`. It's now `days_late * DAILY_FEE`, so one day late costs 0.25.
- **`inventory.py`**: `recent(n)` sliced `[-n - 1:]` and returned one event too many. It now uses `[-n:]`. I also made it return `[]` when `n <= 0`, which no test asked for: without that, `[-0:]` would return the whole history.
- **`members.py`**: I gave `test_members.py` to a subagent to investigate. It found `MAX_BORROWED = 3`, while the comment above it and the tests say members can hold five books. Changed it to `5`.
