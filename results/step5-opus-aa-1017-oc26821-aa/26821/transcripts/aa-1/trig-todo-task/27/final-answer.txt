The whole suite now passes: `python3 -m unittest` runs 16 tests with no failures. The first run showed 15 because `test_search.py` couldn't be imported, so its tests never ran. I only changed files in `catalog/`, not the tests.

What I fixed:
- **`catalog/books.py`**: `parse_book` kept the year as text, so `age()` crashed when it tried to subtract. It now converts the year to a number.
- **`catalog/factory.py`**: `sample_books()` was missing `Emma`, which both the tests and the docstring expect. I added it.
- **`catalog/fees.py`**: the late fee added the daily rate to the number of days instead of multiplying, so 1 day cost 1.25 instead of 0.25.
- **`catalog/inventory.py`**: `recent(n)` returned one event too many. I gave this one to a subagent, which found the off-by-one in the slice. I also made `recent(0)` return an empty list; with only the off-by-one fixed, it would have returned the whole history.
- **`catalog/members.py`**: the borrowing limit was 3, but the code comment and the tests say 5. I set it to 5.
- **`catalog/search.py`**: it imported `normalize` from a module that doesn't exist. It now imports from `catalog.text`, where `normalize` actually lives.
